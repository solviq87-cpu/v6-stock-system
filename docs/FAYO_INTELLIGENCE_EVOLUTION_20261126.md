## 原生入口与可运行接口

桌面 `/`、移动 `/m` 共用 `#/lab/evolution`，从“回测 → 研究进化工作台”进入；首页按已保存优先顺序展示研究卡。沿用原身份、主副角色和设备授权，不新增账户体系。

以下源码路径均相对 `V6_BO/`：`src/core/intelligence-evolution.js` 汇总原短线档案与研究链；`evolution-market-evidence.js`、`evolution-research-statistics.js`、`evolution-workflow.js` 分别负责市场、统计、工作流；本轮 `evolution-operating-evidence.js` 只读原运行回执，`evolution-model-causality.js` 复用原模型审计；前端为 `public/nova/evolution-view.js`，接口为 `src/server/evolution-http.js`。

- `GET /api/research/evolution?symbol=600001&horizon=5`：返回 `market`、`similar`、`statistics`、`workflow`、来源及指纹。
- GET 仅允许 `symbol`、`asOf`、`horizon`、`export`，重复或额外字段拒绝；代码为六位，`asOf` 为不晚于当前时间的 13 位 Unix 毫秒，`horizon` 仅 `1/5/20/60`，`export` 仅 `0/1`。
- `export=1` 重新鉴权读取同一报告，前端下载 JSON；响应为 `private, no-store`。GET 不接受请求体，接口不接受用户提供的文件路径、行情、模型脚本或历史矩阵。
- 原鉴权后的 `readQuote(code, asOf)` 仅读取 `S.lastPx.get(code)?.wireQuote` 原行；HTTP 与报告层限制报价所属股票和可知时间。原日 K、`S.stocks`、检查快照或前端价格计算不能代替当前报价。
- 未提供原报价（包括未来报价已被历史截断排除）时，可读取原 `plan-observations` 的当时回执；原私有目录与完整链校验失败则 `unavailable`，不新建或修复原回执。原观察的 `canTrade:false` 原样保留。

POST 同一路径，不带查询参数，JSON 请求体最多 64 KiB；`requestId` 为 8—100 位字母、数字、下划线或连字符。

```json
{"action":"preferences","requestId":"evolution_layout_0001","expectedRevision":0,"value":{"selectedCode":"600001","search":"","status":"all"}}
```

这是合法最小示例；实际保存先 GET，再将完整现有 `workflow.preferences.value` 修改后提交，避免遗漏原分组与布局。`expectedRevision` 必须等于当前版本；同 ID 同内容重用原回执，同 ID 异内容拒绝，陈旧版本返回冲突。
允许字段为 `groups/templates/columns/search/status/activeGroup/selectedCode/sectionOrder/homepagePriority/expanded/scrollTop/density`；最多 20 组、每组 200 只及 20 个模板，严格校验代码、引用分组与栏目白名单，首页风险信息保留。

```json
{"action":"diagnostics","requestId":"evolution_diagnostic_0001","symbol":"600001","horizon":"5"}
```

诊断只允许 `action/requestId/symbol/asOf/horizon`；可选 `asOf` 和 `horizon` 在 POST 中须为字符串。诊断从服务器原档读取输入，`horizon` 传入原持有策略的 `holdDays`。副本可读取，不能保存偏好或诊断。

## 真实证据与统计解释边界

### 历史时点与行情

工作台合并 workspace 行情时，首次服务端 receipt 是 `knownAt` 下限，保留供应商原时点及原事件 hash；事后一次导入多年历史不会变成当年已知信号。相同回执去重，冲突身份隔离；后到的可选字段不附着到较早回执上，正式与教学样本分区。

分钟、日、周、月同时检查取得时间、闭合时间、来源和价格口径；周月由日线推导须覆盖日历中全部应有交易日。所有存在的 `knownAt/receivedAt/recordedAt` 都受截止时点约束，不能用较早别名掩盖较晚取得时间。添加未来基准、未来频率或未来报价不能改变旧报告的可见结论；不同周期不是独立胜率样本。

### 收益、竞争、基准与融合（36 / 45 / 46 / 62 / 63）

单笔收益以原分币结算成本复算，原模拟与人工申报已对账分源。模拟计划偏差须匹配成交前原冻结计划指纹及买入事件；事后同 ID 改计划不能改写纪律。MFE/MAE 只有在全部实际持有时段行情覆盖有效时给出；部分覆盖只列已观察极值或上下界。日 K 包含入场前/离场后价格、同根 K 线同时触及目标与止损时，不推断先后或可成交性。
