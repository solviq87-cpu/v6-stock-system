## 首屏和联动

首页仍是天气一句话、最多 3 张合规卡与执行清单。买区、止损、目标与仓位仍由后端的原行情、`computeLevels` 与原模拟账户预算产生。无合规卡继续显示“今天空仓，等待信号”。

板块资金新接口只做数据投影，没有联网采集或入库副作用。旧 `sectors.json` 与市场展示快照可作为明确标注日期的已有证据；主实例原板块采集完成时额外留存当日完整展示快照。不同日期、冲突、无法确认的时间及单位均不能混为同一条资金证据。

点卡仍通过原选择事件同时更新详情、板块与模拟盘预填。返回保留滚动、已展开证据和板块选择。PR #347 的 `homeReferenceDay` / `review.date` 兜底函数保持原字节。

## 因子定义、审批和时间

完整规则面板保存 95 项的条件状态、目录/设置版本、源记录范围和指纹，不把没有观察的条件当失败值。含未知条件的规则不能进入完整数值向量。原研究输入、原始观察日与实际创建时间各自保留。

共享校验器要求个股原料和可信收盘快照属于同一股票，日期范围不越过信号日；市场、指数、板块及同板块同伴保留明确的上下文身份，不能改写为当前股票。显式演示、测试或合成标记不能参与真实因子证据。六类战法模板消费同一完整 95 项面板；有效面板中的未知条件保持未知，损坏面板不会借展示 top 8 补过门禁。

作战台冻结以原 `card.calculatedAt` 为证据截止，优先核对获批排序中的原 `sourceCheckId`，否则只选择已归档的同日或原日历确认的相邻前日观察。准备阶段没有匹配、或所选记录在锁内复核失效时，不换绑后来出现的检查。原权限在持久化前再次核验；提交时撤权不能保存。成交成熟后，训练只消费与冻结引用完全一致的原观察，不能利用同 ID 事后改写、缺失引用或补采时点增加样本。

数值模型与旧 boolean 标签权重分开。数值训练仅使用事前已冻结观察、真实成熟成交及已核对净费用的收益。原模拟结算的成本分母按原权威回执核对。常数和线性冗余因子被排除；可用特征的选择与参数拟合仅使用训练段。数量不足、定义冲突、标签晚到、没有独立验证/留出窗口时不生成有效模型。

模型参数、定义、系数、阈值与验证记录有完整指纹。原验证的训练、时间外、样本外、成本和风险五项均通过后，才能由原审批入口建立版本。中心调权沿用同一已批正交基底；每次新候选依旧经过原验证。自动送验模块没有批准、交易或通知接口。

首页模型排序同时要求：

1. 模型在原信号出现前已被批准，训练标签在批准前成熟，训练截止不晚于批准。
2. 原日历在原信号时点已经确认相邻下一交易日；信号日保持 `signalDay`，今日为独立的 `targetDay`。
3. 完整同定义数值、原观察时点、实际评分时间、模型版本与指纹一致。
4. 同共振组全部具备可比的同一模型分，才使用这一排序依据。缺分时整组回退原精选排序，避免混用两套比较规则。

模型分使用训练净收益模型的尺度，不是首页 0–100 精选分，也不是上涨概率。排序不绕过报价、日期、天气、账户预算、原候选和成交门禁。

## 执行日报和私有数据

清单首屏只读内存，后台每分钟读取原计划/条件意图/账户状态，不能因每 5 秒的采样覆盖计数变化就反复失效。创建计划、挂单、撤单、持久成交或新的风险事实才立即使缓存失效。冷缓存和断线直接显示未知；私有清单不对只读观看身份提供。

日报后台在北京时间 15:15 后处理已收盘日期。全局最短 5 分钟、每天最多 108 次；单目标日最短 15 分钟、每天最多 36 次。优先最新收盘日，再轮转原计划和成交中发现的历史日期。持久记录每次尝试，重启和并发不能绕过额度。17:30 等收盘后迟到结算仍可追加新报告版本。

每版报告包含评分、清单、来源版本、真实记录时点、输入指纹、前版哈希和当前哈希。原报告不覆盖；缺少连续观察的评分项保留未知。部分卖出不等于已清仓，稀疏的止损触发不等于全天观察完整。“已复盘”表示有对应证据的持久核对，不表示纪律全部符合或满分。

新增私有路径：

| 路径 | 内容 | 写者 |
| --- | --- | --- |
| `V6_BO/data/decision-sector-history/` | 每个交易日的完整板块展示快照 | 原主实例的原板块采集保存流程 |
| `${V6_SHORTLINE_DIR}/execution-reports/` | 按日不可变执行日报版本和调度回执 | 已启用中心的原主实例后台 |
| `${V6_SHORTLINE_DIR}/feedback-runs/` | 自动反馈送验尝试和结果哈希链 | 原研究主实例后台 |

没有设置 `V6_SHORTLINE_DIR` 时继续使用 `V6_BO/data/shortline-research/`。这些目录必须随原私有卷备份，不能公开为静态资源。报告和提案的 GET 只读，不因用户打开页面而写报告、创建候选或下单。

## 继承且保持的功能

PR #350 的后复权多源历史采集、落选股票的次日成熟补齐、财报核验、六类战法、成本压力、复合中文筛选、九维雷达、原条件意图引擎与部分批次跟踪全部保留。

原 `paperBuy`、`paperCheck`、`paperSell`、`savePaper`、`followSystemPicks`、逐票 15 秒报价门禁、T+1、原费用、权威账本、账户权限、设备授权和主副角色函数保持。附加中心 Q 与模型排序不修改这些准入规则。私密飞书仍由原计划观察器负责，条件意图不重复发送；未配置 webhook 仍显示未配置。

## 验证与上线界限

本轮验证记录见 [验证目录](validation/fayo-closure-20261125/README.md)。全量回归、原真实隔离 HTTP、双端浏览器、函数对比及最终提交 CI 分开记录，旧版本的通过结果不能代替本轮结果。

代码可计算完整规则观察、IC、正交和样本外结果，不等于已取得 95 项真实统计有效性。历史存量不能补造过去的信号时点，真实独立窗口和成熟成交须由原实例逐日积累。候选模型也不会被本轮代码自动批准。

下列运行条件仍需原实例的真实证据：

- 当前市场的合规原始报价、独立多源一致性、足够的真实历史与成熟成交；没有证据时继续空仓或显示缺项。
- 跨市场原始数据和共同日期覆盖。只有 A 股证据时不声称已完成跨市场验证。
- 资金的真实来源与去向。已有板块净额不能推断实际资金转移，缺流向明细时仍展示净额与缺项，不绘制示意桑基链。
- 四视角会商使用可解释规则并注明证据覆盖置信度；当前未运行外部语言模型智能体，也不把规则视角宣称为独立 LLM 推理。
- 原私密 webhook 与实际送达回执，以及目标设备的正式双端首屏时延和账本读回。

## 备份、部署与回滚

本轮改前完整源码 Git bundle 已验证，SHA-256 为 `54f6585fcb344e8ee4c45f3c911a6065828e0ab4a42d2d5d4fa3be7e5dca9d7b`，基线为 `d3585ff2e03300d303f502e3126d029650b0cdc6`。工作区没有挂载生产 `data`、`durable` 或账本；源码备份不能替代用户要求的整套生产冷备。

正式切换按 [HANDOFF](../HANDOFF.md) 当前检查点执行：停止原节点及同卷所有写者，冷备程序、私有数据、配置、设备授权、账本和外部私有挂载，验证校验和与账本可读；记录旧 SHA、端口、域名和启动方式。按最终通过 CI 的同一 SHA 安装完整程序，保留原权限、主副角色和卷。

升级后先核对版本与 `/`、`/m`，再核对空仓、合规计划、联动、只读权限、日报历史及原账本。失败先停止新写者并保全升级后的流水、条件意图、研究证据和报告，再回切旧完整程序。禁止用旧备份覆盖升级后新产生的成交；旧版可以不使用新增派生报告，但要保留它们供追溯。

若升级后已人工批准新数值模型，回切前还须在隔离副本验证旧程序与该研究档案的兼容性；不能把新数值系数按旧标签权重解释，也不能为回退删除新的模型版本、观察引用或日报。
