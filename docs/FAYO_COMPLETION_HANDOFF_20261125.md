## 可直接交给部署软件的五步任务

请在现有 V6 实例上原地升级绯曜 FAYO。仓库、精确发布 SHA 和目标版本按上表及本轮交付回执执行。保留现有域名、端口、账户、设备授权、主副角色和全部数据卷。

1. **先完整冷备，再切程序。** 读取并记录当前 `/api/lock/status`、当前安装提交、程序位置、启动方式、端口、域名和所有挂载。停止本节点以及同卷的全部 V6 写者，冷备整套当前程序、`data`、`durable`、配置、凭据、设备授权、研究档案、模拟账本、原推送流水及外置私有目录。生成并核验备份校验和，试读原权威账本。备份和凭据仅保存在部署节点私有位置。工作区源码 Git bundle 不能代替这份生产冷备。

2. **自动识别当前版本，按同一 SHA 升级完整程序。** 当前为 `20261123aa`、`20261123ab` 或本轮之前的首页修订时，一律沿用仓库既有完整 `V6_BO` 更新流程；禁止只覆盖 `public/nova/`。若已是 `20261125ac`，仍核对精确提交和前端修订，不能凭相同版本号跳过核验。使用原安装器在独立目录验证包内 `source.json`、`manifest.json` 和 `SHA256SUMS.txt`，原子切换程序后按原方式启动。挂载原私有数据目录，不用仓库空数据覆盖现有卷。研究来源使用原选配 Python 环境，`V6_PYTHON` 应指向已安装原固定 `baostock==0.9.4` 的解释器（依赖见 `requirements-research-sources.txt`）；未设置时使用 `python3`，不会自动发现其他虚拟环境；未安装或源站失败时应显示明确缺项，不能跳过双源门禁。

3. **验收电脑 `/` 和手机 `/m`。** 读取 `/api/lock/status`，实际 `appVer` 应为 `20261125ac`；两端页面 `meta[name="frontend-revision"]` 应为 `center-20261125-2`。顶栏品牌及浏览器标题应为“绯曜 FAYO · 投资研究空间”，切换栏目后仍一致。用既有编辑者身份检查天气、最多三张合规决策卡和执行清单，记录两端实际首屏用时；无合规候选显示“今天空仓，等待信号”。卡片的买区、止损、目标、仓位来自后端，缺源、旧价或日期不符时不得生成可执行计划。Mini K 的代码、前复权口径、来源、日期和实际取得时点可读。

4. **验收日期兜底、研究证据与原模拟链路。** 打开首页“更多研究”，在没有 `review.date` 时核对市场主线、涨停板块分类能采用真实涨停池或行情快照交易日；板块资金仅展示日期一致且人民币单位明确的记录。点击决策卡，核对详情抽屉、板块资金和模拟盘预填的股票及日期一致，返回恢复滚动及展开。读取与预填不成交；用户明确确认后才能建立条件意图。条件单后台每五秒复核原候选、原报价、原预算与当前授权，唯一买入入口仍为原 `paperBuy`。在部署节点既有模拟验收流程中核对重复请求/重启不重复成交、撤销和撤权停止、午休暂停、同日 14:57 到期、账户重置后旧意图失效、原 T+1 与退出规则不变。止损/目标观察接原私密飞书；未配置 webhook 时保持“未配置”，`queued` 不是已送达。研究档案只采用实际取得时间的后复权双源证据；样本不够、财报不全或缺真实资金去向时显示缺项。复盘反馈仍经原验证和人工批准，不自动替换生产权重。

5. **回报实测结果，失败按原流程回滚。** 回报精确源码 SHA、实际 `appVer`、双端修订、标题、首屏用时、日期兜底、卡片联动、条件单门禁、账户/权限/账本摘要及私有冷备位置。将未能在现场验证的条目标为“未验收”，不能用隔离测试代填。失败时先停止新程序和所有新写者，保全升级后账本、条件意图、研究回执和日志，再切回升级前完整程序并沿用原卷。恢复旧数据前必须核对升级后新增成交，不能直接以旧冷备覆盖新流水。新条件意图保留审计，但旧程序不会运行新条件单引擎；再次升级时按现有授权、日期、原账户期次及原成交去重恢复，不重放旧成交。

### 新增私有目录及运行限制

- `V6_CENTER_HISTORY_DIR`：默认 `data/intelligence-center-history/`。后复权原始回执、准入/隔离结果、原日历和新冻结观察；不写旧行情执行缓存。单次研究读视图最多 20 个代码、每股 400 个交易日，省略范围在报告中列明。待成熟信号另行分页扫描，今日落选不会取消次日标签采集。
- `V6_PAPER_CONDITIONAL_DIR`：默认 `data/paper-conditional-orders/`。只保存意图、原成交引用、观察与通知状态，不保存另一套现金或持仓；设备仅存签名摘要，不存明文 token。原账户账本仍在原目录。
- 财报继续使用原 `V6_STOCK_OBSERVATIONS_DIR` 及原 evidence 路径。新缓存只读档案，并不迁移、删除或重建原始回执。
- 研究采集仅主实例、原交易日运行，每分钟最多一个任务；完整财报采集成功后至少六小时再复采，连续失败最多三次且间隔至少 15 分钟。后复权同票同日持久限制最多三次，当日采集不早于北京时间 16:00。财报读取缓存为 30 秒，原始档案校验在单个有界工作线程内执行。
- 新增自动历史采集覆盖沪深 A 股；通用对齐逻辑保留跨市场日期交集能力，本轮没有把其他市场的真实历史来源称为已接入。
- 条件单不会改变原 A 盘跟单、原 ATR/移动止损、止盈或 T+1 规则。计划止损触发观察不能被称作一定成交。

## 不得混淆的验收结论

代码已打通的模块，只能在真实来源返回完整且合规证据时产生对应结果。足够数量的前瞻冻结样本、真实多源 hfq、完整财报、资金实际来源去向、私密 webhook 和连续权益序列不能由测试数据补足。所有隔离截图和用例都明确是测试输入，未写入生产。

原 `paperBuy`、`paperCheck`、`paperSell`、`savePaper`、`followSystemPicks` 函数体相对基线已逐字节核对保持一致；`terminal-workbench.js` 的 `review.date` 兜底保持。历史恢复页的批准字节不变，正式 `/` 与 `/m` 共用本轮原生入口及缓存版本。

最终验证汇总见 [本轮验证记录](validation/fayo-completion-20261125/README.md)。该汇总记录本地首次失败及修复后的结果、环境限制、浏览器与源码边界；仓库合并/发布还须核对最终提交 CI。
