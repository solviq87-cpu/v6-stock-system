## 五项整改

1. 冻结输入原始决策时点必须为有效带时区时间，不能晚于实际服务器时点、不能早于数据截至日；每个研究分段使用原决策时点与分段原16:00边界中较早者。原生内部 splitDay 要求非负安全整数且严格在训练段截止索引之前。
2. 行业、指数权重记录按交易日与已知时点双重截断；结算记录先交原历史验证器全量检查，再按生效日和公布时点截断。证券成员表按起始日、获知时点及明确证券主数据可用时点截断；已声明但可用记录为空仍保留空表而非放开股票池。
3. 依照原参数标准化函数生成候选向量指纹，拒绝以不同候选ID重复提交相同配置消耗同一验证样本，不改变既有参数范围。
4. 对每段实际返回的 asOf、decisionAt、研究权限、券商连接状态、绩效范围及训练标志作明确核对。拒绝非法数值、隐式类型转换、矛盾边界及交易权限回执，防止形成假合格结果。
5. 公开 holdout 函数先复算原冻结验证结果再进入保留样本；已有注册器内部已完成复算的路径复用私有实现，避免额外重复计算。原同修订重试、已完成评估和样本外测试的幂等语义、研究参数晋级与回退保持。
