## 五项整改
1. 运行时钟：限定可表示的北京时间日期，预览和执行拒绝低于已持久化最后事件的时间，不允许通过回拨继续运行。
2. 事件语义：核对持久反思阶段、结果与状态、源日期与检查日期、失败后审计动作及事件时钟顺序，不仅核对外层摘要。
3. 决策证据：依据原行动、就绪状态与下一动作重算决策指纹；不因重新计算外层哈希而跳过约束。非独立签名，不能证明有权限重写整链者未篡改历史。
4. 私有日志：同一文件描述符有界读取、非阻塞打开、拒绝非普通文件/多链接/不当权限/读时变动，并严格解码；保留原16KiB上限、哈希链和失败确认。原原子写入短暂多链接窗口可能让并行状态读取保守拒绝，需组合验证。
5. 工作进程回执：同步或异步无效回执、缺失/重复独立影子阶段、与明确研究权限矛盾的完成回执改为可持久化失败并保持人工确认后才能重试；原真实阶段状态、原待审及权重不变。兼容旧隔离回执省略可选权限字段，不代表下游实际权威证明。
