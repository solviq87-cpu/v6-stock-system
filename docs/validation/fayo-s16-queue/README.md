## 可复现问题

## 调用与证据

- 初始审核沿用 prepareRecommendationDelivery 和原始行资格验证。原缓存 S.lastPx 中同证券、同一或更晚原时点的 wireQuote，须经原 quoteUseEligibility 判定可用于通知。价格不同会使带旧当前价的文案转为历史观察，保留原触发价格和时点并显示等待重核。
- 私密队列在实际尝试前复核该原行及现有报价。显式公开通道在排队、重试和邮件发送前也使用原快照与同一复核。任一行的价格表述失效时，整条涉及多行的冻结文案等待重新核实。
- 价格复核只用于判断原文能否继续使用“当前价格”。保留原候选的强弱判断及原证据。较新的报价不能补足缺失的原触发资格或延长原报价时效。早到旧时点、其他证券、未来、仅研究、禁止通知及存在来源冲突的输入无法作为新的当前价取代原文。
- 原候选二阶段是否仍有价值、查看推送详情时的同一决策重验、真实网关和设备回执仍须分别验证。没有可用于对照的新行情时仍执行原行的用途、时间和新闻门禁。本变更没有额外联网或写入模拟账户。
