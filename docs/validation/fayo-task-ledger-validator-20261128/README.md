## 原入口和使用方法

在仓库根目录，使用既有Python 3标准库，不需要openpyxl、Excel、pip或新增依赖：

```sh
python3 -X utf8 -I -B V6_BO/scripts/validate-fayo-ledger.py
python3 -X utf8 -I -B V6_BO/scripts/validate-fayo-ledger.py --repo . --expect-sha <实际40位HEAD>
python3 -X utf8 -I -B V6_BO/scripts/validate-fayo-ledger.py --workbook <明确工作簿路径>
```

Windows或原本地Python环境可用既有python解释器替代python3；保留-X utf8以固定JSON输出编码。普通结构校验不要求安装Git；无Git时仓库版本和versionBound明确为未知/false，不能绑定SHA。指定`--expect-sha`时，工作簿、工具自身及复用XML模块都必须与目标HEAD字节一致。工具不写工作簿、不创建本地缓存、不调用GitHub或任何网络；输出JSON只含结构、编号/状态、哈希和定位，不回显证据正文或URL。

状态`declaredComplete`仅表示台账声明，不是批准。`releaseReady`、`businessAcceptanceVerified`、`managerSignoffVerified`、`historicalOriginalTextsVerified`始终false。结构通过返回0，结构/版本错误返回1；`--strict`在结构通过时也返回2，因为本工具无权认证正式业务和总管签收。它不修改、替代或绕过原发布/人工批准机制。

## 证据超链接与安全边界

原台账含普通GitHub证据超链接。原股票导入器基于证券输入安全继续拒绝所有外链，代码未改。本工具只读允许普通HTTP/HTTPS文档超链接，解析后只计数、绝不访问，不将域名当已核验来源；外部工作簿/数据链接、查询连接、嵌入或宏仍拒绝。ZIP尺寸与XML深度/节点/文本采用明确限制，坏文件只输出固定错误类别，不泄露解析异常中的原始内容。

512KiB压缩文件、3MiB总展开、1MiB单项、最多256项、32张表、1000行/64列及4096字符单元格是工具容量边界，不是业务质量下限。超限应保留原证据、转为明确引用或重新论证容量，不静默截断、不丢历史。本工具只检查台账已声明的结构，不能验证链接内容、真实许可、收益、设备/网络、调用价值或批准真实性。
