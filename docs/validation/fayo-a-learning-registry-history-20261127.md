# A35 学习参数版本、历史复核与回滚隔离

日期：2026-11-27

## 范围及行为
基于 A34 候选 4bd8c8ee760fecc0a1fd2507e9a2c88504274e46，仅修改既有 learning-profile-registry.js，新增专项测试和验收记录。沿用原协议、研究参数白名单、验证及样本外复算、市场门禁、原子存储、进程锁和交易隔离，不新增注册器、不修改正式权重及其他组。

- 读写前复核原研究权限、阶段与修订号、训练验证结果及样本外结果的存在性；候选ID、顺序及规范化参数与冻结协议一致。
- 按原晋级/回滚事件逐条重放版本指针，核对事件类型、前后指针、连续修订号和最终active；拒绝只有当前指针而没有对应历史的状态。
- 启用 required-on-promote 的历史晋级回执必须保留原市场状态声明、日期、时间、来源、摘要及风险/样本保留标志；不重用当前市场时间去否定正常历史记录。
- 本批新增保守策略：一旦本冻结实验候选已回滚，不得仅凭同一旧验证和样本外成绩再次晋级。重新研究须创建新冻结实验。历史上原机制允许的、结构一致的多次晋级/回滚仍可读取；已激活版本的同修订幂等重试仍保持不变。不自动删除或迁移任何原档案。
