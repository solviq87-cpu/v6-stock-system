## 复现

在仓库根目录执行以下命令。将 `ARCHIVE` 设为本人有权使用的私有绝对目录。每份公开月报只在显式采集时请求一次。默认启动、历史回读和双端查看无需连接交易所。相同基金多次研究可复用同一份文件。

```bash
ARCHIVE="$(mktemp -d)"
node V6_BO/scripts/szse-etf-monthly.js capture "$ARCHIVE" 2025-03 W020250402560972808549.html
node V6_BO/scripts/szse-etf-monthly.js capture "$ARCHIVE" 2025-04 W020250513504907210876.html
node V6_BO/scripts/szse-etf-monthly.js compare "$ARCHIVE" 159915 2025-03 W020250402560972808549.html 2025-04 W020250513504907210876.html "$(node -p 'new Date().toISOString()')"
node V6_BO/scripts/fayo-deep-research-browser-check.js --etf-monthly-archive "$ARCHIVE"
node --test V6_BO/tests/szse-etf-monthly.test.js V6_BO/tests/official-background-archive.test.js V6_BO/tests/runtime-acceptance-view.test.mjs V6_BO/tests/data-source-lineage.test.js
```

浏览器复现沿用仓库已有的 Playwright/Chromium 专项环境。打开桌面与手机视口的研究页，读取当前证据，展开“官方背景档案”中的 2025-04 月报。网络拦截期间只允许连接本地服务，两个视口对同一份四月回执显示 159915、399006、6684564.1、净申购未知及交易主体未知。报告保留实际视口、HTTP 路由、响应哈希、布局溢出及错误。审批、物理真机、中国大陆实际线路、生产部署及长期观察由总管分别签收。

上游登记沿用 `szse-fund` 的授权审查状态。仅支持已识别的公开月报结构，单位或列位变化时报错。所有文件留在原始官方背景档案，新增记录标注上游 `szse`。回退时停止本批采集，恢复上一代码版本并继续挂载原卷。实测混合档案含两份真实 ETF 回执和一份隔离 ECB 对照。新读者可核验三个范围，回退读者跳过新的记录类型并核验同一份 ECB 原回执，三个原始文件均保留。账户和历史档案均无需倒卷。
