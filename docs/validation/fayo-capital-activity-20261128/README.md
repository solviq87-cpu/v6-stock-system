## 计算与消费合同

1. 仅在单一已登记证券与材料证券代码字段一致、事项类型明确时绑定金额；不从股票前缀或名称猜身份，不将关联证券当作已核实买卖主体。
2. 计划、累计、本期、已披露执行、未实施及混杂/未知分别输出。计划下限/上限仅从临近明确措辞标识；金额、股份、比例、每股价格、期限各保留原单位。未明确人民币不默认币种，港币不自动换算。累计声明去重但不相加，不跨版本自动差分。
3. 报告截止日只用明确“截至”声明。非法、冲突或未来截止要求复核；落款、URL日期、接收时间不充当报告期间或原始发布时刻。已到日期不确认执行。
4. “尚未实施完毕”与“尚未实施”不同；其他项目完成不替股份事项确认完成。完成状态始终是材料声明，`independentlyVerified=false`。撤稿、替代、移除关联和缺链停用；澄清、取消、终止等待复核。
5. 宏观逆/正回购、债券、国债、基金份额、再贷款等不混入股份执行口径。复核中实际用合成反例发现初版将逆回购误分类，补两项反例及排除边界后验证。
6. 有界检查100条去重语句，单条1600字符，最多12行输出；每段超过8个数量则保留未知，不展示部分数字为完整口径。受限时页面显示缺口。未提取不当作零。
7. `canQualify/canTrade/canTrain/canNotify/independentlyVerified=false`；本期增量与市场净流量为空。输出只进入原证据室研究展示，不改选股评分、持仓、通知或交易资格。
