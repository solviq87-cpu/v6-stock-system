# A33 冻结预测多进程竞争与异常恢复

日期：2026-11-27

## 范围与修复
基于 A32 候选 791e9637cce115c3080a1fa2c990ccb2e1ac43da，沿用原私有研究存储和进程锁，不修改公共模块、其他组、正式策略、交易权限、CI或部署。
1. 将新预测发布前的截止时点及当前时钟检查放入原存储 beforeCommitLocked 钩子，无外部授权回调时仍执行；锁内阶段及 fsync 后再次检查。
2. 同ID竞争的已发布记录按重放处理，复核原请求时刻、内容指纹、事件类型及档案语义；保留原授权回调，不因新发布截止而误拒绝合法旧回执。
3. 快速重放在授权回调返回后重新检查时钟。时间、授权及原请求错误按原错误码传播。不同内容竞争仍由存储拒绝，不能覆盖原记录。

## 边界
测试进程崩溃不同于主机断电或存储硬件故障；链接后目录未 fsync 的测试仅证明同一运行系统可重读，不证明断电持久性。原存储保留未清理的 .stage 临时文件，读档案忽略它们，未修改自动清理策略。确定性双进程竞争不是长时间高并发压力测试；时间检查发生在链接前，不宣称内核级绝对原子时钟截止。未执行全仓 CI、真实行情、HTTP、双端、学习闭环或生产部署。A33 依赖 A32、A31、A30，须组合审查，不独立合并。
