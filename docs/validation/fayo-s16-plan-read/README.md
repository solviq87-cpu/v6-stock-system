# S16、S35　从历史通知核对原计划与现价

父候选为 #566，代码版本为 `d8b49b53a0d483df0810cab8e15732587469b730`。本次覆盖经原模拟计划观察器归档、由原风险中心经私密通道发出的入区、止损和目标条件。适用任务为 F13.2、F23.1、F23.4 和 F48.4，关联 G02、G06。

## 业务入口与消费

1. 原风险中心预留投递时，将账户期次、投递 ID、触发 ID 及观察指纹绑定到原私密推送流水。服务器同时核对股票代码、触发类型和原报价时间。
2. 有编辑权限的用户在电脑 `/#/inbox/push` 或手机 `/m#/inbox/push` 展开「核对原计划与查看时状态」。同一 `GET /api/push-log?planNotice=<deliveryId>` 先取原始观察，再按其唯一冻结计划、决策版本和账户期次复核。只读复核复用原行情、原观察算法与原账户预检。每次最多处理一个计划，请求并发时显示稍后重读。
3. 返回原价、原分类阈值、决策及原预检依据。当前数据可核验时另列本次报价、时间、原预检原因和有效时间。原条件消失时转为等待。原观察器停用时可查看有权访问的归档。授权撤销、账户重置、跨日、同时间报价矛盾、过期与档案缺失分别处理。缺少投递绑定的旧条目仅显示已有历史。用户查看不会提交委托、生成新提醒或修改观察档案。

## 复现及结果

在仓库根目录运行下列命令。浏览器专项需要 Playwright 和本地 Chromium，可用 `V6_UI_BROWSER` 指向本地可执行文件。

```sh
node --test V6_BO/tests/decision-evidence-server-contract.test.js
FAYO_PLAN_NOTICE_QA_DIR=/tmp/fayo-plan-notice-browser node --test V6_BO/tests/decision-evidence-server-contract.test.js
```

- 修前在真实私密派发入口重现缺少投递与已归档触发的绑定。修后原有与新增服务器契约共 15 项通过。本批 20 个测试文件共 202 项通过。
- 同一合成决策原报价 10.00 元、原区间 9.80 至 10.10 元。两秒后原生报价采入 10.50 元，查看结果为等待，原模拟执行函数拒绝超出区间的请求。原账户文件逐字节相同，原观察档案相同，队列共一次。另测读取中撤权、同股另一计划、同一时点异价、过期和观察停用。私密传输使用隔离替身。
- 在临时全服务进程重放已归档的同一合成决策。1536 × 1000 和 390 × 844 两种 Chromium 视口均取得真实应用返回的原价、决策 ID 及休市历史状态。普通查看者与匿名访问均无法读取。两端记录的外部请求及业务写入为零。浏览器输出目录含两张实际运行截图和 HTTP 回执。
- 盘中价格变化由原生隔离契约复验。浏览器打开旧消息的截图取自隔离服务休市时段。交易日级真实行情样本、私密网关实送与手机真实接收、原总管组合与签收需各自留存回执。
