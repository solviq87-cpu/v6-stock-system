# CN07、CN12　首次安装后断网重开两端入口

复查 F03.6 指数异动持续性接入后，原启动链 `app.js → market.js → index-continuity-view.mjs` 增加一个同步导入。原服务工作线程首次安装缓存缺少这个本地文件。专业候选 #562 父版本为 `de099bd9d8f03c06ba641edd048cb948992ab426`。含总管 #563 及研究候选 #564 至 #567 的隔离组合首次全量回归 8,099 项，其中一项失败，定位到该文件。

## 实际改变

补入该公开显示模块的本地资源地址，并更换原应用外壳的缓存版本。原工作线程继续从服务端请求私密接口。此前已安装的浏览器沿原服务工作线程安装、激活与旧缓存清理流程取得新版本。

## 实际复现

从仓库根目录运行。浏览器命令使用 Playwright 自带 Chromium，或使用环境变量 V6_UI_BROWSER 指向本地已安装的 Chromium。

```sh
node --test V6_BO/tests/fayo-product-contract.test.js
FAYO_OFFLINE_ENTRY_QA_DIR=/tmp/fayo-offline-entry node V6_BO/scripts/fayo-offline-entry-browser-check.js
node V6_BO/scripts/ui-cache-upgrade-browser-check.js
```

- 修前原依赖图契约失败。实际浏览器首次安装工作线程、关闭本地服务再打开应用，超过 8 秒仍未出现登录界面。
- 修后原契约覆盖全部同步导入及受权限保护的 API。两个未打开过应用的新浏览器上下文仅在线安装原工作线程，随后关闭提供文件及业务数据的服务，再分别打开电脑首页与手机入口。
- 两端均显示登录和离线提示，读取原 `/api/state` 得到 503 及明确的断网标记。检查所有已安装缓存，私密 API 条目均为零。桌面宽度 1536、手机宽度 390，均无水平溢出。输出目录含真实浏览器运行截图与 JSON 结果。
- 原缓存升级浏览器脚本另行验证旧工作线程被取代、同 URL 资源刷新、旧缓存清理和撤权。上述证据覆盖 Linux 上的 Chromium 与本地服务中断；实体手机、Windows 宿主、大陆网络和盘中行情分别待验。
