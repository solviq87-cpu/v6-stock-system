## 已复现与修复
- 排队后时钟倒退或抛异常时，旧采集器仍被调用。现于调用采集器前再次采样共享高水位时钟，无效则直接拒绝，保留原失败冷却与合并读语义。
- 任务排队延迟超过采集间隔时，旧实现按排队时点冷却，成功或失败后均可能过早重新发起。现以实际采集调用时点作为冷却起点；仍保留原换档规则、完成时钟检查以及底层403/429 governor。
- 不修改实时行情15秒门禁。采集时点不充当供应商行情时点。
