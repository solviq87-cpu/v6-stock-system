## 已修复的验收发现

- 原市场时钟八位交易日必须在 observer 边界归一，异步读后统一观察/预检/写入时点。
- 中心反馈按需加载，旧私有研究读取不依赖新中心配置。
- 北交所候选不会进入仅支持沪深的采集批次；未覆盖标的明示。
- 只处理当日计划与仍由原买单关联的持仓，保留全部旧档案。
- 新复核组合到原私密发送入口上游；原防外泄静态审计没有修改或放宽。
- 此运行环境 `/var/tmp` 是符号链接。原发布者安全校验保持，完整回归使用真实临时目录 `RUNNER_TEMP=/tmp`。
