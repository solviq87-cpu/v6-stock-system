# F03.2 个股收盘后五分钟同时段成交额

原总管基线 `b936ebdddb8c11948dd0e63f95332898dd5c1cf5`。原短线研究工作簿在一次成功的 `v6:sync` 中冻结个股原始分钟条与当时收到的时间。此变更将成交额比较存入同一工作簿的 `v6Observation.windowTurnover`。编辑者通过原 `GET /api/research/shortline` 和两端共用的「自动战法校验」读取。策略评分、选股、通知、模拟与实盘权限沿用原机制。

## 计算与范围

- 分别计算北京时间 09:30–09:35、13:00–13:05、14:55–15:00 的人民币成交额。左端开放，右端闭合。五根原生一分钟条或一根原生五分钟条组成一个观察窗。窗口可见时间为实际收到并归档完整盘后资料的时间。
- 以原研究日历的目标交易日及其之前连续 20 个开市日为样本。按证券、窗口、原生周期、供应商和单位匹配。中位数取第 10 与第 11 个值的均值。保存日历指纹、股票身份、原生周期、每一日的来源、原文哈希、收到时间、完整入档时间及三个窗口金额。每笔计算最多读取两个当日分片和二十个历史分片，只在同步时运行。比较器只读取本地资料。
- 每个分片须有完整的 240 或 48 根分钟条，来源与原生周期匹配，全部来自同一回执。当前已核实的成交额口径是东财一分钟、新浪五分钟。新浪适配器另核对独立日K。原换手金额算术核对适用于每根条。观察到的零成交保留零，历史中位数为零或历史缺一天时倍数留空。日历覆盖受已配置交易所及日期限制。
- 分片保存首次完整时间和首次已知争议时间。分片出现价格、数量或金额冲突时，从该截点起整日退出比较。原始条保留，历史截点仍按当时事实读取。旧格式缺少争议历史的分片继续供原用途读取，此比较列为未知。覆盖整组样本的节前分层及特殊交易时点还需验证。
- 此版只覆盖收盘后现有个股工作簿。盘口告警、ETF 及板块窗口、股票池覆盖、独立误报预算、真实历史正例及前向业务增益仍待验证。倍数没有默认交易阈值。
