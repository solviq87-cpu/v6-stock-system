# Codex 研究终端功能借鉴边界

用户 2026-11-08 补充：可以参考 Codex 网页版的有价值功能并集成，但**绝不能改动用户提供的两张手机/电脑参考图所规定的界面**。

## 不可更改
- 两张参考图是手机和桌面视觉及信息架构的唯一目标，不允许以 Codex 研究终端 UI 替换。
- 不因添加功能删减原图的顶部/侧边/底部导航、指数卡、情绪与风险卡、AI 信号、策略排行榜、K 线、买卖解释。
- 新增功能应融入原图既有模块、二级页或弹窗，保持主仪表盘 1:1 视觉目标。

## 可参考功能（逐项评估，非默认全部接入）
- 条件式选股、历史数据导入、选股研究概览
- 策略联动分析、因子诊断、模型对比、观察列表
- 来源/时点/证据解释与浏览器本地研究能力

## 接入门禁
1. 先核对现有 V6_BO/V6_WEB 是否已有对应能力，避免重复实现。
2. 数据必须有来源、时点和状态；不把研究模拟信号冒充真实交易信号。
3. 不改现有四套策略、风控与模拟盘门禁；新增能力走测试和审计。
4. 每个新增模块同时核查手机与桌面，必须与原图主界面一致。
5. 视觉未逐图验收前，不宣称已做到完全一致。
