## 本批八项
1. 直接风险行将不满足原状态合同的已解除标签归为未知。
2. 原规则占用数值不能替代明确布尔超限结果与有效策略版本。
3. 完整退出展示要求原计划买入批次、零剩余数量、不再观察、当前原执行回执、实际原账本成交时点与无冲突订单证据。
4. 当前计划观察与原约束报价的价、来源、时点及观察时间保持一致；无条件证据不视为未触发。
5. 当前持仓的止损/目标触发声明须与原冻结价位几何关系、剩余数量及原批次一致。不调整原价位。
6. 仅同计划、证券及对应批次的已核验退出或更新有效观察可覆盖此前原预警；未入场预警保留原同计划已进入批次的适用转换。旧预警存档不删。
7. 合并同根因展示时原有效否决不被许可覆盖；不同证券/对象归为冲突，不确认动作许可。
8. 总览把无法评估的风险计入未知覆盖，即使原始证据标签写作available。
