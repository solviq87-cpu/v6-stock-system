## 运行状态扩展

新增只读 `/api/system/readiness`，仅原编辑身份可读；双端复用 `/api/state` 的私有 `systemReadiness` 字段及已有状态刷新，不新增计时器。JSON 顶层包含 `schemaVersion: 1`、`protocol: "fayo-system-readiness-v1"`、`asOf`、`version`、`components`、`dependencies`、`readOnly: true`。已有接口及字段保留。

每个 component 提供 `id`、`label`、`status`、`reasonCodes`、`missing`、`affects`、`lastAttemptAt`、`lastSuccessAt`、`nextAction`。缺少可靠历史时间时返回 `null`，不能把本次 GET 当成最后正常时间。运行正常不表示数据足够，不表示允许成交。原始内部错误、私有路径、账户余额、模型参数和凭据不进入该摘要。

| `status` | 界面含义 |
| --- | --- |
| `normal` | 该项已有符合其职责的实际证据 |
| `missing-data` | 已识别的数据或覆盖缺项 |
| `unconfigured` | 必要配置未提供或该能力未启用 |
| `failed` | 最近实际运行失败；保留此前正常时间 |
| `historical-snapshot` | 有可核对历史快照，不能作为当前执行报价 |
| `unverified` | 未执行、尚无验证回执或接口未提供 |

各组未交付的扩展通过 `dependencies` 返回 `ready: false` 和缺项。不能因为旧接口存在而宣称本轮新增接口已完成。配置了通知通道不等于送达，排队/受理也不等于有确认回执。仅有模型目录或配置不等于完成推理、校准、审批或衰减验证。

## 时间、来源和用途

新增事件及背景数据使用 `schemaVersion: 1`、`protocol: "fayo-event-data-v1"`。时间为 UTC epoch 毫秒，缺失为 `null`；保留 `timezone` 的 IANA 名称和上游日期/精度。禁止把不带时区的本地字符串默认为 UTC，禁止将发布日期的午夜伪造为精确发布时间。

| 字段 | 含义 |
| --- | --- |
| `source` / `upstreamGroup` | 实际取得渠道 / 原始上游；同上游转载不算独立证据 |
| `sourceUrl` | 可核实公开来源，不含私密查询参数 |
| `publishedAt` | 上游精确发布时间；日期粒度另留日期与精度 |
| `effectiveAt` | 事件生效或观测归属时间，不替代发布时间 |
| `firstObservedAt` | 本系统首次实际取得该版本的时间，持久化且重试不刷新 |
| `quoteAt` | 供应商原始报价时点，不能来自接收/页面刷新时间 |
| `sourceRevision` / `localRevision` | 上游修订标识 / 本地不可变修订序号 |
| `usage` / `canTrade` | 展示、研究、执行用途；本组事件与背景数据固定研究/不可交易 |
| `quality` / `missing` / `conflicts` | 可核验质量、缺项与来源冲突，不消解未知或冲突 |

历史信号取用需同时满足 `publishedAt <= asOf`、`firstObservedAt <= asOf` 和适用的事件生效规则。未来已公布事件可以作为当时已知的日历风险，不能当作已经发生的财务/市场事实。晚到数据与新修订不得回写成过去已知；旧版本必须可追溯。未知时点从历史合格证据中排除。

金额、价格、评分和统计量不以缺失补零。只有真实观测的零才保留 `0`；分母为零或覆盖未齐的统计值保留未知。排序把未知置于有据数据之后，不能让未知超过真实负值。资金需记录币种、单位、日期、统计范围、供应商口径；没有真实来源和去向明细时，不从板块净额生成资金转移链。
