# 天枢智策 · A 股短线研究台

> 部署与接手请先打开 [部署交接](DEPLOYMENT.md)。启动、更新、目录、静态服务和普通云服务器步骤集中维护在同一份文档。

一套基于手工证据的 A 股短线策略校验工具。内置原需求的 95 项规则与 363 个条件，分别覆盖战法、风控和全A指数环境。浏览器本地计算与保存，Node 服务提供静态资源和可选的无状态评估接口。应用不包含券商接口、行情拉取、自动下单或资金账户。

## 运行

需要 Node.js 20 或更高版本，启动无需安装 npm 包。

- Windows 双击 `start.cmd`。
- Linux、macOS 在目录内执行 `sh deploy.sh`。
- 或在项目目录运行 `npm start`。

浏览器打开 `http://127.0.0.1:8787/`。也可以仅托管 `public/`。部署到服务器时可沿用同样的源码，前端资源均由站点自身提供。大陆公网可达性以服务器、域名及网络实际配置为准。 [部署与 HTTPS 步骤](DEPLOYMENT.md)

## 如何分析一个案例

1. 进入 **证据录入**。填写同一观察日期的六位股票代码、简称、题材、全A与相关指数、涨跌家数和成交额。成交额使用亿元，涨跌幅与仓位使用百分数，同口径比较盘中和盘后数据。
2. 切到 **模拟仓位与纪律**。按总资产百分比填持仓，明确录入当日连续亏损笔数与连续亏损日。未持仓或无亏损时填 0。展开更多字段可指定单标的、题材、非主线和退潮期上限。
3. 在 **因子校验** 搜索编号或名称、展开规则。手工标记符合、不符合或待核实。能计算的条件显示依据，数值与手工证据冲突时显示冲突并采用计算结果。改证券或日期会清除与原案例绑定的字段及手工证据，已存复盘保留。
4. 回到 **分析总览** 查看匹配战法、高亮风险、市场广度与量价信息。明确禁止条件优先，关键证据不全时暂不开仓。模拟新增仓位是把指数情景、总仓位及个股和题材额度同时约束后的剩余额度。
5. 点 **保存复盘**。复盘页可补填实际观察涨跌幅和笔记，查看近期分布，并导出 CSV 或 JSON。观察均值采用已填写结果的等权算术平均。导出后如用 Excel 查看，请将股票代码列按文本导入，以保留前导零。

可点击 **载入示例** 查看自动匹配与指数分化提示。示例和用它继续编辑的记录会保留模拟标记。切换浏览器、域名、协议或端口会使用另一份本地存储，变更前可先导出备份。

## 判断口径

- **规则结果**。同一分支按全部符合或任一符合判断，多个分支分开显示。缺失信息不计作通过。
- **指数环境**。有全A点位和 MA5、MA10、MA20 时检查均线排列，同时核对录入趋势、涨跌分布、成交额比值和跨指数分化。未提供必要数据时显示待核实。
- **阈值**。用户原需求中的定性条件保留为手工核实。示例阈值集中在引擎中的 `THRESHOLDS`，默认仓位上限在 `DEFAULT_CAPS`。这些是规则校验口径，没有经过收益验证。
- **提示**。模拟开仓校验的结果是复盘研究输出。实际观察结果由用户录入，工具不估算实际收益或交易胜率。

## 源码导航

| 文件 | 内容 |
| --- | --- |
| `public/rules.mjs` | 95 项编号、条件、分支和提示 |
| `public/schema.mjs`、`public/engine.mjs` | 输入元数据、数值校验、规则引擎和模拟风险输出 |
| `public/index.html`、`public/style.css` | 页面入口和手机、电脑布局 |
| `public/app.mjs`、`public/ui.mjs` | 交互和可视化组件 |
| `public/records.mjs`、`public/demo.mjs` | 浏览器存档导出、模拟数据 |
| `server.mjs` | 静态文件、健康检查、无状态评估 |
| `tests/` | 内置 Node 回归测试 |

运行 `npm test` 验证规则、存储和 HTTP 服务。每次修改代码时，同步更新部署交接中的相关入口、依赖与验证说明。 [完整目录和部署交接](DEPLOYMENT.md)
