# V6 模拟盘回放证据图完整性审计开发报告

日期：2026-11-05

## 本轮目标

在离线模拟盘回放报告生成后，增加独立、只读的证据图审计，验证“历史信号 → 模拟盘订单”的引用关系没有断链、篡改或错误授权标记。

## 实际修改

- 在 `src/core/paper-replay.js` 新增并导出 `auditPaperReplayProvenance(report)`。
- 对每条信号重新计算 SHA-256，检查信号载荷是否被修改。
- 检查信号 ID 重复、数据集指纹不一致、行情来源不一致。
- 检查信号与订单执行日期关系、订单引用是否存在。
- 检查订单来源、数据集指纹、离线类型及 `canTrade=false` 标记。
- 检查报告级证据汇总数量、数据集指纹和禁止交易标记。
- 回放报告生成时自动附带 `provenanceAudit` 审计结果。
- 审计函数只读，不修复、不改写订单或账户数据。

## 验证结果

- `node --check src/core/paper-replay.js`：通过。
- `node --test tests/paper-replay.test.js tests/signal-evidence-chain.test.js`：20 项通过，0 失败，0 跳过。
- 新增 5 项证据图审计测试，覆盖完整报告、孤儿订单引用、信号载荷篡改、重复 ID、来源/指纹不一致、交易授权标记和缺失证据。
- `node --test tests/*.test.js`：运行环境在约第 321 个子测试后达到执行时限，未取得完整汇总；因此不宣称全量回归通过。

## 边界

此审计针对离线回放报告，不等同于所有原生策略出口和所有模拟盘 HTTP 订单入口已经强制接入证据链。当前回放模式继续保持 `canTrade=false`，不连接券商、不启用真实交易。
