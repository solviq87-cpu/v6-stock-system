# V6 策略信号证据链开发报告

日期：2026-11-05

## 本轮范围

新增 `src/core/signal-evidence-chain.js`，为策略信号创建可校验的来源证据封套，并允许将其绑定到模拟盘委托意图。该模块当前是独立的证据与校验能力，不代表已接入所有真实策略执行入口或模拟盘下单入口。

## 实现内容

- 记录策略系统、证券代码、信号日期、观察截止日期、生成时间、评估器版本及行情来源。
- 要求严格行情门禁通过，拒绝过期、模拟或非严格模式行情。
- 要求风控检查通过后才可创建证据。
- 使用 SHA-256 对证据载荷生成指纹，可检测事后字段篡改。
- 将证据指纹绑定到模拟盘委托意图，并校验证券、日期、方向、数量和限价。
- 绑定结果明确 `canTrade: false`，不提供实盘交易能力。
