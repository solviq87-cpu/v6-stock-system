# V6 第53批：三轮合并工程集成报告

## 目标与范围
按用户要求合并推进核心量化引擎、策略表现/模拟交易、双端产品化与发布验证；本批完成一条实际运行的**离线数据→每日研究排名→持久化模拟账户→电脑/手机共用 HTTP 页面**链路。保留原有策略阈值、API 与数据结构，不提供真实下单。

## 代码修改
- `src/core/daily-research.js`：新增经过 OHLCV 与交易日验证的每日研究快照，提供数据指纹、候选排名、风险证据、策略证据状态、上线门禁。未单独评估的策略显式标记 `not-evaluated`，禁止伪造绩效。
- `src/core/paper-monitor.js`：同源只读接口 `GET /api/research/daily`，复用账户内已校验的历史数据；响应式桌面/手机监控页面增加每日研究排行榜和门禁原因。
- `tests/daily-research-integration.test.js`：新增 3 项行为测试，覆盖数据质量、研究禁交易、HTTP 令牌隔离、页面与模拟账户共同工作。

## 启动
参照 `scripts/paper-monitor.js`，设置 `V6_PAPER_VIEW_TOKEN`，使用本地经过校验的历史行情 JSON 与账户 JSON：
`node scripts/paper-monitor.js ./account.json ./history.json`
仅监听回环地址；`GET /api/research/daily`、`GET /api/paper/report` 需 `Authorization: Bearer <token>`。无真实下单接口。

## 风险原则
模拟、导入和离线行情不宣称实时；研究排名不等于买入建议；未验证的独立策略不写虚假分数或收益。私密飞书消息不回退公共群，不接入真实短信。
