# V6 板块 H5 收益标签：固定规则、时间隔离及成本压力研究

2026-11-10。本模块独立读取已成熟的 `sector-shadow-gross-h5-price-label-research` 结果，**只计算研究评分，不训练、不接模拟成交、不改正式权重**。与已合并的 PR #100 衔接；不修改 PR #101/#105 正在处理的板块成员身份指纹相关模块。

## 研究入口

`evaluateSectorH5WalkForward(entries, {tradeDates, asOf, roundTripCostBps})`

- 输入必须为 **24～80 个不同信号交易日**的 `{preflight, labels}`，每个交易日提供当天所有已经排名的行业 H5 成员收益标签。少一个行业，或单个成分股缺价/停牌/公司行为未处理，拒绝当日样本；不允许只选前几名赢家。
- 每份行业标签必须沿用既有 H5 模块的完整协议：已冻结日、明确未来第5个交易日、原始报价源、行业代码/分类版本、冻结得分、完整且不重复的成员股票、SHA256指纹、全体成员的已观察毛收益。重新计算各成员收益的平均值与中位数，拒绝不一致的已发表标签。
- 同一交易日只对 **行业** 比较，按当天已冻结的排名（至少3个行业）选第一名与最后一名；同时计算第一名对**当天所有行业的等权均值**的价差。不混淆概念板块、行业指数、正式交易组合、资金流与因子真实收益贡献。
- 仅消费按序导入的显式 A 股交易日历（150～1200日）。相邻两个信号日必须相隔至少6个交易日，因此任何5日观察窗口均不重叠。不能把高频重叠信号当成多个独立样本；日期缺失或未来标签未成熟就拒绝。
- 固定的时间切分：最初至少12个非重叠信号日为训练研究段，随后6个为验证研究段，最后6个为保留测试研究段。三段时间严格正序，验证与测试不参加初段选择；该切分不根据收益改变。**已经查看过的保留测试并不是真正可以重复使用的未污染样本。**
- 固定往返成本敏感性：默认 `roundTripCostBps=30`（=0.30个百分点），可设0至500基点；只从**第一名相对当天所有行业等权毛价差**中减去假设性成本，得到 `AfterCostStressPct`。这不是券商费率，也没有考虑滑点、印花税、冲击成本、涨跌停成交性和可实现仓位，绝不称已计算实盘净收益。
- 输出三个时间段的日数、平均第一名对全部行业毛价差、成本后压力差值、第一名对末名毛差值、成本后正日比例及最差单日。未做参数搜索、权重更新、历史最优回填或交易回测。

## 固定安全状态

`status='descriptive-walk-forward-unverified'` **只表示研究字段可比较，不表示模型预测有效**。`outOfSampleValidated:false`、`priceSourceAuthorized:false`、`prospectiveCertified:false`、`eligibleForResearchPromotion:false`、`canTrain:false`、`canTrade:false`、`autoPromotion:false`、`weightsChanged:false` 在所有路径恒成立。样本不足与来源/版本、收盘时间、成员、价格冲突都会得到阻断状态。

即便测试段显示正收益，也不自动建议正式选股权重或账户动作。真实改进至少还要：第三方可核验的当时冻结时间与数据许可、交易所日历/公司行为复核、交易成本与可成交性、更多不同年份与市场环境的**新鲜独立样本外数据**，以及单独审批的影子模型实验协议。
