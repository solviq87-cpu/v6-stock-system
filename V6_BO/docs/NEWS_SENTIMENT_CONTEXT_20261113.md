# 新闻语义与有效期增量优化

基线：`004676cbef5be11763ffcbb7de8a4f6db0b24361`（dev，2026-11-13）。参考用户提供的《新闻渠道与利好利空评判体系.md》，逐项核对当前源码后增量修改。东方财富 101/104、三日归档、假期缓冲、修订撤稿证据、持仓/选股联动原已存在，本批不重建它们。

## 最终行为

| 场景 | 原行为 | 本批行为 |
| --- | --- | --- |
| 标题中标，但摘要第 90 字之后有监管函 | 可能只看短摘要判利好 | 分类使用供应商完整摘要；面板摘要仍 90 字，原因显示监管函 |
| 出售已回购股份、终止回购或重组 | 前者已有特判，后者可能误判利好 | 统一反转规则，利空优先 |
| 终止减持、解除质押、未被立案 | 可能直接命中利空 | 对明确被否定/解除的事件作中性处理；其他独立负面事件仍保留 |
| 传闻、否认、澄清 | 可能按回购/中标等词加分 | 中性待核实，不把传闻当作正面催化 |
| 只有涨停、大涨、创新高等价格表现 | 可以作为新闻利好 | 不把价格表现再当作独立新闻利好加分 |
| 新闻断更或凌晨跨日 | 集合可残留旧代码并继续影响决策 | 消费时检查来源发布时间：北京时间今天及前两日，未来/未知时间拒绝 |
| 启动时一个栏目失败/游标反复 | 可使整次播种终止或重复翻页 | 已取得的页面保留；继续另一栏目，重复游标停止，每栏目最多 3 页 |
| 新规则启动纠偏 | 只把部分旧利好移到利空 | 用绑定原文双向纠偏，包含假期缓冲；不重写证据，不重发历史利好 |

`src/core/news-sentiment.js` 为有界纯规则模块，保留原词表并输出规则版本、类型、命中词、原因、限制说明。输入最多标题 1000 字、供应商摘要 50000 字，与证据入口的限额一致。它不是大模型、不是新闻真实性认证，也不输出或校准收益/涨停概率。原有策略权重、行情新鲜度门禁和交易授权要求保留。

`server.js` 采集、历史重分类、当前决策与共享新闻状态使用同一规则。消费时还核对最新证据版本与类型，防止把利空行塞进利好数组后变成正面支持。规则结果按已验证的证据 hash 缓存，证据链变化时失效，不让每个候选重复扫描完整摘要。新增模块进入信号规则源码指纹清单。

过期新闻退出当前新闻面板、选股支持/排除、持仓提示、板块警示、即时利好推送和埋伏归因；有显式日期范围的假期摘要仍可引用保留的历史新闻。发布时间不由收到时间替代。不可绑定证据的旧缓存保留为未知，不凭短摘要补成合格新闻。归档修复不改原追加证据字节。

## 运行限制和回滚

仍是一个新闻供应商的两个栏目，没有新增付费来源或提高轮询频率；栏目之间不是独立来源互证。复杂歧义、历史对比、主体归属等仍需人工核实，不能把规则覆盖的案例数量当成语言理解准确率。本批验证使用隔离数据，未向飞书发送测试消息，未把静态网页发布当作 Node 后台上线。

回滚使用 `git revert` 本批提交；保留 `news.json`、私有新闻证据链和冻结信号，不删除历史或用旧 ZIP 覆盖主线。恢复后下一次正常采集按恢复版本重建当前投影。
