## 页面和操作

入口仍是 `/research.html#researchWorkspace`。读取研究记录后，概览下方显示一张“大盘 → 板块 → 个股”卡，原来的八个视图保留。

1. 顶部显示本次明确封存的基准、数据日与来源；“数据时点与口径”展开原始窗口和快照时点。缺少同窗收益时，只单独显示已封存的指数日行情，不拿它代替同窗基准。
2. 左侧显示本次指数的行业拉动/拖累前列；展开可见有效权重覆盖和统一单位的残差。板块涨幅、供应商领涨股和资金净额都不能补成贡献点数。
3. 右侧通过板块选择框或行业/概念分别列出的本批相对表现切换板块。显示涨跌平/缺价、有效覆盖、上涨集中或扩散等描述，行业与概念不混排成全市场名次。
4. 成员按钮只切换卡片内的同一快照，不发网络或写请求。成员中可分别看到当期相对位置、成交核心观察、五日持续性及有证据的分时顺序；“判定依据”展开样本分母、版本和原始时间。
5. 另点“查看该股研究”才复用原工作区GET及跨六分区股票联动。保留原历史时点、批次、同股所选版本；没有该股档案仍显示缺失，不代选另一股。

电脑左右列，手机单列；主要结论直接可见，时间、成员身份、对账和判断细节折叠。沿用深蓝底、红涨绿跌、44px按钮。两张锁定主页、正式策略与评分、账户、报价15秒门禁都不改。

## 两条真实输入路径

**已有封存记录**：兼容未包含新字段的旧研究，从其中的日期化板块、完整成员及已知同快照个股日K提取可用观察。没有验证板块与个股跨源/窗口可比性时，板块报价和个股位置分开显示，不推断相对收益；无有效权重时指数贡献未知。

**可选补充证据**：沿用“补充原生评估证据”60KB JSON入口，新增根字段 `marketLinkageEvidence`；卡片附近可下载空模板。补齐真实资料后导入，再明确点击“比较已存股票”，服务端校验后与该研究一起冻结。该操作不执行上传代码、不按上传URL抓数据、不采购数据，也不把当前成员回填旧版本。

模板只预填现有股票身份和可由明确交易日历得到的窗口，收益、权重、价格和已知时间均留空。尚未填写的模板不能通过服务端校验，不生成可用示例行情。没有适用的指数权重、连续历史或分时记录时，卡片相应位置明确保留未知；本批没有新增权重供应商或全市场自动采集。

## 补充证据契约

函数为 `normalizeMarketLinkageEvidence(input,{asOf,tradeDate,provider,symbol})`。只接受列明字段、有限数字、六位股票代码和有界数组；规范化后复制字段，额外token、路径、URL或其他字段拒绝。收益和权重使用**小数**（1%填0.01），时间为Unix毫秒。价格收益口径可填 `price`、`unadjusted` 或 `price-return`；全收益为 `total-return`，不能跨口径比较。

| 部分 | 字段与约束 |
| --- | --- |
| 总体 | `provider,symbol,tradeDate,knownAt,returnBasis,window{start,end}`；股票/来源/日期匹配已存观察，窗口结束及所有已知时间不晚于研究时点 |
| 基准 | `benchmark{provider,code,name,methodologyVersion,return,startValue,knownAt}`；单一明确基准，收益/点位可空；不根据股票代码前缀猜指数成分 |
| 分类 | `classification{provider,version,knownAt,effectiveAt}`；版本及成员在窗口起点已知且生效；行业互斥、概念允许重叠 |
| 方法 | `methodology{weightsKnownAt,weightsEffectiveAt,noCorporateActions,completeConstituents}`；权重在区间起点已知/适用；布尔声明仍为提供者输入，不能认证其真实性 |
| 板块 | `boards[]{code,name,category,members,membersKnownAt,membersEffectiveAt,return,knownAt}`；category仅industry/concept，成员无重复；同批全部板块均可查看，并不只留下当前股票所属项 |
| 个股 | `stocks[]{symbol,return,weight,indexMember,primaryIndustry,turnover,knownAt,activation?}`；weight可空；非指数成员不给权重；primaryIndustry须与明确的互斥行业成员归属吻合，未知行业贡献单独保留；turnover约定为同窗成交额（人民币元），不是换手率 |
| 分时事件，可选 | `activation{at,confirmedAt,knownAt,definitionVersion}`；事件及确认都在同一收益窗口内，确认时间不早于启动，证据已知时间不早于确认、不晚于快照；同板块需同一事件定义及足够覆盖 |

当前纯函数上限为100个板块、5000条股票、100KB；前端原生文件60KB限制更严格。接口和私有研究档案原有容量及权限限制继续生效。持久化、导出只在原有用户明确操作时发生。

## 计算和角色的实际含义

### 指数贡献

同窗 `c_i=w_i×r_i`，行业为已核验互斥行业中成分贡献之和；概念不会进入行业贡献加总。小数贡献×100为百分点，乘基准起点值为点数。收益残差为 `R_index−Σc_i`；点数残差为 `I_0×(R_index−Σc_i)`，不混合单位。

缺权重不填0、不重归一；已知部分仍可显示部分估算。有完整成分声明、无公司行为/调整声明、权重覆盖与收益残差均在固定1e-6容差内时，标“口径匹配的研究估算，来源未认证”；其余标部分或未知。固定容差是当前实现的研究对账容差，不是供应商/交易所认证。

本批实现单期固定成分/适用权重计算，没有跨调样、除权或股本调整的精确分段及多期链式贡献。出现这些情形保持部分/未知，不能通过勾选声明绕过真实证据责任。并未声称获得完整官方权重或指数授权。

### 板块与个股

- 板块收益减同窗基准；个股收益减同窗板块。有效成员至少5且覆盖80%才给当期相对位置，名次允许并列；没有强制龙一/龙二。成交核心是相对成交参与，不证明主力身份或正向带动。
- 板块广度数涨/跌/平，缺价另计；前两只正涨幅占比是等股票涨幅集中度，不能冒充市值贡献集中。上涨扩散、集中上涨、逆势、相对抗跌并列描述，抗跌仍可能绝对下跌。
- 五日持续性另由 `enrichMarketLinkageHistory` 计算。只接受明确连续交易日中的前收盘→当日收盘快照、同股、同来源/口径、同基准方法/分类及精确相同成员；取每个允许时点内的最新版本，缺日或最新版本不兼容不会回退挑有利旧版。
- 五日收益复合计算；相对板块为正且至少3/5日处于前20%时标“持续前排候选”；相对为负且至少3/5日在后段时标“相对弱势观察”。其余分化或未知。这些是明确研究规则，未经过收益验证，不是胜率、交易或学习权重。
- 分时顺序须至少5个、覆盖80%的成员有同定义事件，按已封存启动时点标最先/并列最先/随后观察到异动。只有日K则未知；该顺序不认证谁带动谁，也不以同日相关替代因果。

尚未实现并仍明确留缺口：剔除自身的真实权重板块参照、20日持续角色、板块主线的独立样本外认证，以及分时事件从真实源自动识别。旧 `classifySectorRoles` 和其评分消费者完全保留，新研究结果没有写入旧score或正式权重。

## 时点、版本和隐私

新增投影绑定所选run及数据时点。未来记录、晚于所选序号的同刻修订、窗口后才知道的成分/分类/权重不能参与当前计算。历史交易日历可包含已知的未来排期，只取不晚于所选交易日的连续窗口，不接收未来行情。

原加载、失败、切股、时间/来源变化、页面隐藏、离线、401/403会清空卡片可见私有结果；迟到回复不能恢复。卡片选择还包含研究股票和run身份，防止同一时点A换B后仍显示A。来源/基准/窗口/分类/成员变化会使原板块选择失效。公开资料库URL不增加任何私有研究字段。
