# V6 策略绩效回撤时序修复报告

日期：2026-11-05  
基线：V6 统一 Python 三轮策略研究流水线（477 项历史回归）

## 本轮发现

此前独立策略样本外统计的最大回撤，是按证据输入顺序逐笔复利计算。证据通常按股票分组输入，同一日期不同股票的交易可能交错；因此输入顺序会影响回撤路径，而且重叠交易被误当成先后发生的独立资金投入。

## 本轮修改

- `src/core/strategy-evidence-replay.js`：改为按实际退出交易日分组，将同一退出日多只股票的纸面交易收益聚合为等权日收益，再按日期排序计算描述性回撤。
- 每个策略窗口增加 `dailyPortfolioReturns`，记录日期、当日等权收益和交易笔数，便于复核。
- 明确标记 `drawdownMethod`：这是按退出交易日聚合的等权纸面组合日收益，不是真实资金曲线。
- `profitFactor` 在无亏损样本时保持 null，不再把“没有观察到亏损”误写成有限的有效因子。
- 新增 `tests/strategy-evidence-drawdown.test.js`：验证证据输入顺序不影响回撤路径，以及同日重叠交易按日期聚合。
