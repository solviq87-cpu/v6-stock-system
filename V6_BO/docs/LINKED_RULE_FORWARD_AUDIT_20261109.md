# V6 新增3套研究战法未来表现验证（2026-11-09）

## 从研究命中到时间隔离结果
原 `public-rule-forward-audit` 默认仍只验证先前公开研究的两套指标策略，不改变历史调用结果。新版本显式指定 `includeLinkedRules:true` 后，加入：
- `donchian20_liquidity`：唐奇安20日放量突破。
- `narrow_range_expansion`：窄幅蓄势后放量启动。
- `sector_market_relative20`：大盘—板块—个股20日相对动量。

每种战法分别在1、5、20、60个交易日窗口计算*逐信号*次日开盘价假设收益；保留原先冻结规则、不在验证阶段拟合阈值、研究费用/滑点/卖出税、T+1、涨跌停、停牌与ST、公司行为核对、亏损和无法成交记录。**没有真实订单、真实交易收益或独立供应商绩效证明。**

## 调用
已授权的综合研究入口 `POST /api/research/complete-run` 接受：
```json
{
  "validatePublicRules": true,
  "publicRuleAuditOptions": {
    "includeLinkedRules": true,
    "windows": 2,
    "testDays": 25,
    "gapDays": 2,
    "horizons": [1, 5, 20, 60],
    "linkedSeries": {}
  }
}
```
实际请求还需要原 `history` 数据结构和开发者权限。网页研究页也有“同时验证新增3套战法”复选框；默认关闭，以避免额外计算和兼容旧调用。

## 板块相对动量的严格输入
`linkedSeries` 是可选的证券代码到两套历史序列映射（最多20只证券），示意结构为：
```json
{
  "600001": {
    "source": "imported",
    "provider": "声明的历史来源名称",
    "market": {
      "id": "shanghai",
      "source": "声明的历史来源名称",
      "bars": [{"date":"历史交易日","close":3000}]
    },
    "sector": {
      "name": "板块名",
      "source": "声明的历史来源名称",
      "bars": [{"date":"历史交易日","close":1000}]
    }
  }
}
```
这里 `bars` 只表示必要字段示意，**实际要给出与股票相同逐日日期的足够完整历史序列**。每个信号日只读取截至当日的21个交易日；未来记录虽可出现在整体已导入历史文件中，但不会传给当日因子计算。若来源不一致、缺少连续对齐的21日或市场代码不属上证、深证、创业板，则相对动量不产生任何匹配信号。A50仍为额外参考，不强行代替境内指数。未提供 `linkedSeries` 时可验证其他技术形态，但相对动量的结果是0个有依据的命中，不代表行情中没有机会。

## 统计解释与保护
- 每条规则分别输出折次、交易时段、每个周期信号数、可建模数、无法成交/未核实分类、模拟净收益均值、历史胜率、最差结果；这些都是**有限时间窗口、固定参数的假想模型**。
- 新增3战法还逐日输出 `ruleInputDiagnostics`：条件真的命中、确实不命中、输入缺失及风险阻断分别计数。缺少板块指数历史时，报表应展示**数据不足**，而非只把0个入选当作策略失效或市场没有机会。
- 即使正收益，也不自动改变正式四套策略、因子权重、模拟账户账本或实盘权限；多个同股/同日信号相关，不能当独立样本。
- 模拟/上传数据、未复权价、历史公司行为与涨跌停口径仍需要独立核对；没有数据质量凭据，不虚报胜率。
- 系统性急跌的所有样本都保留；急跌时冻结研究参数晋级的既有门禁不被绕开。
- GitHub CI 和合并不意味着 Workbuddy 网站同步、国内公开行情稳定可用或界面完成1:1视觉验收。
