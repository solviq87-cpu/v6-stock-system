# V6 策略统一行情严格门禁报告

## 本轮改动

- 在 `src/strategy/strategy-service.js` 增加 `enforceFeedGate` 严格门禁选项。
- 启用 `requireFeedValidation: true` 与 `enforceFeedGate: true` 时，候选必须同时满足行情来源受支持、行情质量有效、行情未过期且不是模拟行情，否则 `pass=false`、`feedBlocked=true`。
- 输出 `feedGateMode`，明确记录 `strict`、`strict-compat` 或 `evidence-only`，避免调用方误判门禁实际模式。
- 保留旧默认行为及 `blockUntrustedCandidates` 兼容性，避免静默改变现有调用方行为；生产调用方需显式启用 `enforceFeedGate`。

## 测试

- `node --test tests/factor-feed-integration.test.js`：11/11 通过。
- `node --test tests/*.test.js`：412/412 通过，0失败、0跳过，约31.3秒。

## 接入注意

本轮提供统一严格门禁能力，但没有声称所有策略 HTTP/API 入口均已默认启用。实际生产调用路径应显式传入：

```js
factorOptions: {
  requireFeedValidation: true,
  enforceFeedGate: true
}
```

模拟行情/导入行情可用于研究或回测场景，但不得因此被标记为真实实时行情。UI 未修改；未接入 CMR 或多模型服务。
