## 本轮代码修改

1. 排行榜顶部四个原本仅用于跳转的标签改为真实筛选控件：全部、重点关注、买卖信号、策略表现。
2. 新增排序选择器：综合评分、涨跌幅、最新价；排序基于接口返回字段，不生成缺失值。
3. 排行榜行支持键盘 Enter/Space 激活 K 线加载，并增加焦点可见样式。
4. 股票名称、理由、策略来源、风险等级在插入 HTML 前统一转义，避免行情/策略文本进入 DOM 时形成 HTML 注入。
5. 四套策略数量不再从混合候选列表按字符串猜测；仅在接口明确返回 strategyCounts 时显示计数，否则显示“待独立统计”。
6. 更新页面 CSS/JS 缓存版本，避免浏览器继续使用旧资源。

## 本轮真实修复的问题

- 发现原有排行榜只有静态标签外观，没有筛选行为；已接入真实客户端筛选。
- 发现原有“综合评分排序”按钮无实际排序行为；已替换为可用排序选择器。
- 发现策略看板把综合候选按来源字符串猜成四套策略数量，可能误导用户；已改为只读取显式 strategyCounts。
