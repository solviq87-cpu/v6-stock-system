## 本轮代码改动

1. `server.js` 新增只读接口 `GET /api/reference-indexes`。
2. 接入腾讯公开行情快照代码：上证指数 `sh000001`、深证成指 `sz399001`、创业板指 `sz399006`、科创50 `sh000688`。
3. 服务端只在当前价和前收盘价均为有限正数时输出指数报价，涨跌幅由当前价/前收盘价计算；缺失、异常或超时的数据明确放入 `missing`，不使用静态演示数字填充。
4. 首页刷新流程并行请求指数接口，更新四张指数卡片及数据源连接状态。接口失败时显示“指数源未连接/指数数据暂不可用”。
5. 更新参考首页 HTML 资源缓存版本至 `20261105r5`。
6. 新增 `tests/reference-dashboard-indexes.test.js` 四项回归测试。
