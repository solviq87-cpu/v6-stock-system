# V6 行情跨数据源连续性审计开发报告

## 本轮变更
- 新增 `src/core/kline-source-continuity.js`，提供跨行情源历史 K 线连续性审计。
- 要求调用方提供交易所交易日历 `expectedDates`；不通过周末/工作日猜测交易日。
- 校验主源和备用源日期合法性、重复日期、OHLC 几何关系及成交量安全整数。
- 按预期交易日检查缺口，输出未覆盖日期，不伪造 K 线。
- 主源缺失时允许从备用源补齐，并逐条标注来源、fallback 标记和来源切换点。
- 同一日期两源均有数据时比较收盘价差异，超过阈值直接拒绝，避免复权口径或价格口径混杂。
- 输出始终标记 `verifiedLive:false`、`canTrade:false`，审计结果不能直接放行交易。

## 测试结果
- 新增连续性审计专项：12/12 通过。
- 历史数据验证、跨源安全、历史质量专项：12/12 通过。
- 新模块 `node --check` 通过。
- 本轮未执行全量 `tests/*.test.js` 回归，因此不宣称全量通过。

## 集成边界
本轮新增的是可复用审计模块及测试，尚未将其强制接入所有行情刷新、策略、回测和模拟盘入口。生产接入前必须由上游提供可信交易所日历，并完成各行情源复权口径、单位、字段映射验证。当前不能据此宣称真实行情已验证或可交易。
