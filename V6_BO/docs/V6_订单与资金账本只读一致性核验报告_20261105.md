# V6 模拟盘订单与资金账本只读一致性核验

## 本轮实现

- 新增 `src/core/paper-ledger-reconciliation.js`，读取订单事件存储记录与模拟账户账本，分别校验订单日志哈希、事件归约状态指纹、账户账本指纹。
- 对账结果明确区分：订单成交缺少账户流水、账户存在无订单依据的孤儿流水、订单与流水字段不匹配、重复事件。
- 任一差异均判定 `ok=false`；输入结构或哈希校验失败直接拒绝生成可信报告。
- 新增 `scripts/reconcile-paper-ledger.js` 与 `npm run reconcile:paper-ledger -- <orders.json> <paper-account.json>`。输入拒绝符号链接、非普通文件及超大文件；退出码 0 表示一致、2 表示发现业务差异、1 表示输入/校验错误。
- 只读核验，不修复、不写回订单、账户、资金或持仓，不连接券商。

## 测试

- 模拟盘专项组合：32/32 通过（账户账本、订单状态机、订单持久化、恢复、账本一致性核验）。
- 新增账本一致性测试：5/5 通过。
- 全量 `node --test tests/*.test.js` 本轮运行至第 367 项时达到 120 秒执行时限，进程被工具终止；未取得全量最终汇总，故不宣称全量通过。
