# V6 统一基线合并说明
本轮优先合并历史工程、冻结主线和回归验收，**不增加新战法**，遵守“先合并、再开发、最后加战法”的顺序。

## 合并处理
- 审计全部可访问的43份历史 ZIP，逐项比对工程内文件名与 SHA-256 内容。
- 以最近一次完整工程 `联网历史行情刷新_设备权限与回测综合联测` 为统一运行主线，保留其原有策略、研究工作台、设备审批、历史行情和回测功能。
- 历史工程中存在31个路径的版本差异，**不能盲目将旧文件覆盖新文件**。逐项记录在 `V6_历史版本合并审计.json`。
- 历史版本独有3个文件（system-kline-bridge、其旧测试、cache-bridge），已放到 `legacy_sources/` 保存源码，不在正式运行路径中自动启用。旧系统 K 线测试依赖现主线不存在的旧 API，不能误称已通过。
- 修复 `feed-scan-backtest.test.js` 旧测试夹具的日期问题及对收益曲线长度、买入字段的过时预期；没有修改该测试所覆盖的回测引擎。
- 新增 `node tests/run-baseline.js` 一键执行全部28个现行JS测试套件。

## 回归结果
- 28/28 个测试文件通过，包括隔离环境真实 HTTP、开发者/只读审批撤权、24小时离线、行情刷新适配、缓存、策略、战法和T+1回测。
- 未开展真实行情供应商联网、生产多设备、短信真实送达、真实历史样本外回测；不构成生产验收。
- `legacy_sources` 为归档资料，不计入28项当前回归。
