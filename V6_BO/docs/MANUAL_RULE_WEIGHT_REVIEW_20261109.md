# V6 新研究战法的升降权人工复核证据（2026-11-09）

## 为何要单独设立评审层
用户希望系统可以解释因子/战法“为什么要升权、降权或保持不变”。
但是原四套正式策略和15因子不能根据一次回测自动改写权重。短期收益、连续多天同一股票命中、同家族的重复证据、暂停/跌停无法成交、公告未对账和大盘冲击都可能让简单胜率失真。

本批引入 `src/strategy/research-rule-weight-review.js`，是**新增公开研究战法的人工复核优先级分档**，不是正式15因子在线自动调参系统。
仅在 `validatePublicRules:true` 且 `includeLinkedRules` 或 `includeQualityRules` 明确启用的冻结历史审计返回 `weightReviewDiagnostics`。
仅评估预先固定的**未来5个交易日**观察口径；其他1/20/60日模型仍照常存在，不作为本批权重裁决的替代。旧两规则默认响应不变。

## 四种解释
- `manual-up-review`：在严格证据门槛满足后，成本化模型收益及多个冻结测试窗口方向一致，**可以优先人工复核升权假设**；不代表正式批准。
- `manual-down-review`：同样严苛条件下成本化结果持续偏弱，**可以优先人工复核降权假设**；仍不剔除历史失败样本。
- `hold-mixed-evidence`：证据量达到要求但结果方向不一致，保持现状继续观察。
- `insufficient-evidence`：证据不足、来源不可信、重叠信号过多、市场环境缺失或成本风险比例过高，**保持现状**，逐条显示拦截原因。

## 固定研究门槛（未经统计校准）
评审必须基于显式声明 `imported` 的历史数据；这只是来源**声明**，仍未经供应商独立认证。
至少3个冻结样本外窗口，且每窗口至少8个可建模事件；同一规则至少40个原始信号、30个可建模结果、15个按5日分段的非重叠观察。
不能忽略阻断记录：无法建模比例须≤20%；同家族同日重复比例≤30%；市场阶段未知比例≤20%，并覆盖至少两种已说明市场阶段。
每笔净收益已由原模拟成交引擎计入费用、滑点和印花税；回测结构要求最低费用/成本门槛、训练/测试时间隔离、未做训练参数优化；重新核对原事件与聚合统计不矛盾。

“可复核升权”：模拟净收益均值≥0.8%，模拟胜率≥56%，且每个冻结窗口净收益均值均为正。
“可复核降权”：均值≤-0.8%，模拟胜率≤44%，且每个冻结窗口均值均为负。
否则保持不变。以上阈值是研发中的**人为规则**，并非具备可信显著性或优化后的投资建议。

## 恒定边界
- 返回 `weightsChanged:false`、`autoPromotion:false`、`recommendedDeltaPct:null`、`statisticallyCertified:false`、`canTrade:false`，不提供具体升权百分点。
- 只读解释网页逐规则展示“优先复核 / 保持 / 证据不足”、阻断原因和非重叠分段，不添加权重写入API。
- 连续交易日的分段数不是独立统计样本量；不同家族也可能相关，还需要独立数据来源核验、市场多阶段验证、时间外追加测试、多重比较修正及真实交易容量/费用核验。
- 本批不修改正式四策略、15因子、模拟盘权威账户、交易门禁、行情获取、真实推送或国内服务器部署。
