# V6 影子学习旧模型校验与正常跳过分离（2026-11-10）

## 问题
旧实现将历史已接受模型的指纹/因子包/供应商血缘异常与“训练时间窗没有更新”组合在同一错误字符串中。Worker 仅根据字符串中的“未增加新的训练时间窗”将异常转为 `ok:true, skipped-no-new-training`；因此一个虽然自洽但不属于当前因子包的旧档案会被误判为正常等待，而不是显式阻断。

## 修复
- 旧模型 SHA、模式、版本、因子包、供应商、研究不可交易标志等不一致：**抛错、拒绝研究学习**。
- 旧模型日期晚于当前冻结数据：**抛错，拒绝回滚或重播旧历史**。
- 合法旧模型的训练末日或最后观察日与当前完全相同：保持原有 `skipped-no-new-training`，不新增模型档案。
- 增加原始模型正常跳过、重新封装但因子包不匹配、历史时间倒退、Worker 不能吞掉旧模型异常及锁释放的合成测试。

## 验收与限制
要求检查 `node --test tests/factor-shadow-evolution.test.js`、仓库完整 CI 与网页 CI。所有验证仅针对合成研究证据；不接行情网络、不改正式权重、四套策略、模拟盘、账本、锁定主页或生产部署。
