# 来源复盘池与公告消费补齐

在 #312 / #314 集成界面之上补齐旧 #281 尚未消费的只读数据，不重放其旧行情客户端或覆盖新终端。`market-evidence.js` 保留 `projectDecisionBrief`，追加来源池、消息列表、扫描原因和语义失败适配；`review-pool.js` 只负责展示。

## 展示行为

- 原「今日复盘」保留，追加可折叠的「来源涨停复盘」。独立消费服务端 `ztReviewPool` 与元数据，没有该字段时才兼容旧策略池；明确的只读空池不回退、不补造。报告未生成也可以查看已取得的来源池。
- 代码/名称/完整原因全文搜索、行业及概念多标签、明确 ST 范围筛选、每页 25 条。关联股由完整同日去重池构造，不能把前 12 / 200 条或报告样本当作供应商全集。多标签数量不能相加作为股票总量。
- 显示每来源声明数量、实收数量、原始日期、保留状态和原接收时点；保留记录不能标为本次仍封板。原因只在其自身日期与来源匹配时展示为「同日来源原因已匹配」，不称真实事件已经认证。
- 矛盾双日期行隔离；同代码重复记录选择完整同日原行，不拼接价格与原因。明确异日的后台联动记录不混入；只有名称不猜代码。
- 资讯列表补充 `dashboard.riskEvidence.news` 中来源明确的巨潮记录：合法 HTTPS PDF 地址、有效完整原始时刻且不在未来、合法股票代码；重复公告去重。既有策略事件保持独立，风险页仍只消费原风险列表。
- 空 `hit` 不遮蔽其它独立原因；股票池失败/未就绪不能显示为成功空池。保留已取得的旧结果和错误原因。

## 范围及验证

无新增供应商、自动采集、私有账户、下单或通知调用。原 15 秒报价、新版资金三日期门禁、前后台新闻推荐审核及权限保持。公开壳缓存增加新模块并更换壳缓存代际；私有 API、凭据查询和 Authorization 仍只走网络，不写离线缓存。未扩大受控源码发布白名单。

新增 `fayo-source-review.test.js` / `fayo-data-consumption.test.js`；`fayo-source-review-browser-check.js` 显式接入现有 UI CI。浏览器在 320 / 390 / 1440 CSS 像素用 97 只合成记录验证四页全部可达、末页检索、ST 与多标签、48 只完整同板块关联、保留状态、源日、公告去重及两条同股不同策略事件，禁止外部请求。截图为隔离合成数据，不是线上或真机验收。

本批与现有原生模块定向回归 97 项中 96 通过、0 失败、1 项 PowerShell 不可用跳过；缓存回归 10 / 10。最终完整回归与远端 CI 以根发布分支的精确 SHA 为准，不能把这些专项数字相加或视为生产发布证明。

恢复时仅 revert 本批代码，不回退服务端来源并集或覆盖账户/历史。真实发布仍须受控应用管理入口、旧版本备份和逐文件读回，静态源码或 CI 通过本身不是上线回执。
