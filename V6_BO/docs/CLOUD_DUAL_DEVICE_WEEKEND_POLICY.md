# V6 云端双端刷新与休市新闻规则｜2026-11-09

## 用户确认的不可回退需求

- **云端优先**：电脑网页和手机网页是同一个 V6 云端权威状态的客户端；不会因为只有某一台手机或电脑在线，就把其浏览器 `localStorage` 当成权威账户、资金、观察池、审计或历史资料。
- **两端均可刷新**：电脑版提供「云端刷新」，手机提供顶部和底部刷新；两者都只 GET 各自已有的同源服务端数据接口，自动按网络情况继续同步。任意一端在线，都能独立打开并读取最新共享数据；另一端稍后上线，也从同一云端获得共享版本。关闭其中一个客户端不停止另一端刷新。
- **云端任务不依赖浏览器**：新闻采集、交易日行情刷新、策略扫描等只能由受控的服务端调度，不能因为浏览器窗口开着就由某台设备重复启动两个采集器。真正的跨设备共用**前提**是两端连接同一部署、云端服务正常运行且有持久化数据卷；目前指定 WorkBuddy 国内目标文档返回 401，**本次仅交付源码，不声称实际云端永久运行**。
- **不增加付费**：不为 TinyFish 充值，不擅自购云服务/付费行情；只用已获授权的免费或现有资源，遇到资格不明的公开数据不绕过 403、不碰灰色协议。
- **休市不伪造行情**：周末及法定休市日，盘面价格/指数/涨跌/资金/涨停和当日选股卡片保持最后已核验的真实交易日快照，附快照日期、休市状态、未经认证说明。不能把界面刷新时刻写成市场价格的原始报价时点；旧价禁止触发模拟盘新成交或盘中风险判断。
- **新闻仍更新**：周六、周日和长假，新闻、公告独立更新并允许重新加载；日常新闻和周末汇总的服务端调度不以 `isTradeDay` 为开关。对新闻本身按实际发布时间展示，不能因为新闻是今日发布就把周五盘面升级为今日实时行情。

## 运营与验收边界

1. 国内部署目标仍是 `https://acd98a1c1a46e6ce4.app.workbuddy.host`，接手先看 `CHINA_WORKBUDDY_WRITE_TARGET.md`；其 `/api/ai/doc?id=ai` 是**文档**，不是已认证的写入 API。
2. 正式部署需确认：云端持久化卷、重启恢复、唯一主任务实例、HTTPS/登录权限、手机/电脑均能通过外网、两端数据一致、周五收盘—周一开盘时间点边界、节假日日历及新闻数据源合规。
3. 需要现场测试「手机单独在线」「电脑单独在线」「两台同时在线」「任意一台从后台恢复」「两台同时点击刷新」「周末新闻更新而盘面仍显示周五 `snapshotDay`」「云端 502/断线恢复」。本次 CI 模拟网络并检查 DOM/接口契约，不证明云端服务稳定或行情已获交易所认证。
4. **本批只读页面补丁没有修改四端 `APP_VER` 常量**，避免对未触及的服务端/客户端协议做不完整升级；新 HTML 由下次页面载入获取。旧的已打开标签页需重新载入才能获得新增按钮。若日后变更应用运行时版本，必须同步 server/index/mobile/sw 四端常量并通过 `research-cache-version-parity` 全量门禁。
5. 不改四套正式选股策略、不开放真实委托、不将用户持仓私密数据写到浏览器缓存作为唯一存储。
