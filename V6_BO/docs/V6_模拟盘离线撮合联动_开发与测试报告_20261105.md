# V6 模拟盘离线撮合联动开发与测试报告

日期：2026-11-05

## 本轮交付

新增 `src/core/paper-intent-simulator.js`，把已生成的只读策略委托计划与行情快照、模拟盘账户摘要连接为离线纸面撮合结果。

新增命令：

```bash
npm run paper:simulate-intents -- <intent-plan.json> <market-snapshot.json> <account-summary.json> <new-result.json>
```

输出文件采用独占创建，不覆盖已有文件；输入文件要求为普通文件且限制大小。模块不连接券商、不发送真实委托、不写回原账户。

## 撮合约束

- 首先复用 `paper-execution-preflight` 的数据指纹、日期、停牌、涨跌停、行情完整性、参考价、整手与预估现金校验。
- 进一步要求有效开盘价和成交量。
- 按配置的滑点、佣金和成交量参与率计算模拟成交。
- 费用后现金不足时拒绝成交，现金不得为负。
- 生成买入批次、平均成本、资金流水及结果指纹。
- 通过意图指纹实现幂等保护，避免同一计划重复计入成交。
- 买入持仓明确标记 T+1，不允许在本模块中当日卖出。

## 边界与未完成项

这是离线模拟撮合，不是实盘执行。当前仅覆盖委托计划中买入意图；完整卖出撮合、逐批 T+1 可卖数量、交易所实际涨跌停价格计算、部分成交队列、公司行为、完整税费参数仍需后续完善。成交量参与率、滑点和费用均为模拟假设，不能声称等于真实市场可成交结果。原始账户文件不被本模块修改，结果写入新的独立文件。

497项通过是本次代码库自动化回归结果，不代表十一大工程全部生产验收完成。
