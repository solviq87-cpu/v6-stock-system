# V6 十一大工程统一主线：集成运行与可核验归档

## 本轮实装

- 新增 `src/core/integrated-run-bundle.js`：统一调用既有原生逐日策略、历史回放、研究排行榜与模拟账本，生成不可变离线研究档案。
- 新增 `scripts/integrated-run-bundle.js`：`run`/`verify` 两个子命令。
- 归档包含历史行情、同日因子快照、Python 三轮证据、完整统一报告、manifest。所有文件记录 SHA-256 和字节数；运行 ID 绑定全部输入、输出和 Python 脚本哈希。
- 先运行完整验证再写输出；临时目录写入、fsync 后原子重命名；重复运行 ID 禁止覆盖；拒绝符号链接输出路径；原生 Python 和导入证据不能混用。
- 研究报告始终 `canTrade=false`、`verifiedLive=false`；不得把模拟账本当作真实交易。

## 运行

```bash
node scripts/integrated-run-bundle.js run /absolute/history.json /absolute/research-runs
node scripts/integrated-run-bundle.js run /absolute/history.json /absolute/research-runs --snapshots /absolute/snapshots.json --evidence /absolute/python-evidence.json
node scripts/integrated-run-bundle.js run /absolute/history.json /absolute/research-runs --python-script /absolute/trusted-three-round.py
node scripts/integrated-run-bundle.js verify /absolute/research-runs/<run-id>
```
