# V6 学习参数晋级市场急跌门禁（2026-11-09）

## 解决的问题
已有 `market-shock-learning-gate.js` 和因子健康报告只输出“暂缓学习调参”建议，并未拦截真实的研究参数晋级。本批在实际注册表指针变更处增加**冻结计划可选择的强制门禁**。

## 启用方式（仅新冻结方案）
在研究方案 `plan.json` 添加：
```json
{"marketGateMode":"required-on-promote"}
```
其余冻结计划字段（schemaVersion、version、trainEnd、validationEnd、holdoutEnd、gates、candidates）仍按原规则提供。该字段会与方案一起冻结并加入完整性指纹，后续不能为绕开急跌保护而从冻结计划中删改。既有旧方案**不自动改变晋级语义**，避免历史恢复兼容性被破坏。

在实际晋级时：
```bash
node scripts/learning-profile.js promote /absolute/registry/path --expected-revision 3 --market-context /absolute/market-context.json
```
环境输入应为当次研究评估时点近90分钟内、同一中国市场日期的导入市场观测，包括来源标签、覆盖比例不低于80%、上涨家数比例、上证/深证/创业板至少两项指数跌幅等，格式与 `src/core/market-shock-learning-gate.js` 的 `assessMarketShock` 相同。

## 门禁动作
- 未提供市场证据、标记模拟、来源不一致、时间过期、覆盖不足或指数不够：拒绝晋级，不修改注册表状态或修订号。
- 至少两项境内指数跌幅≤-3%，市场上涨家数比例≤25%，且证据同日/时效合格：拒绝晋级，记录为“系统性急跌暂缓学习”，仍然保留回测亏损、已有因子诊断、持仓风控与审计。
- 规则未触发急跌且时点条件满足：仍然**必须**先通过原训练段、验证段、冻结样本外以及成本压力复算门禁后才能晋级。启用市场门禁并不豁免任何旧验收。
- 真正晋级成功时，注册表审计事件仅记录市场状态、时点、来源标签及证据哈希，不包含完整市场原始数据。
- 已晋级指针重复晋级是无操作；风险降低所需的回滚仍不受市场急跌限制。

## 边界
这是**研究参数注册表**保护，不是主系统所有自动学习模块的统一开关。旧冻结计划不会被静默改写；新冻结计划启用此功能才会强制检查。市场数据仍是使用者声明的来源、**未由交易所独立认证**；不能凭跌幅断言“不可抗力”，也不自动判断任何因子真正失效。

未部署的网页无法实时自动提供该证据；在没有可校验市场观察的日子，新方案将拒绝晋级，已有参数、回测与风险监控可继续使用。任何向正式策略或生产交易晋级仍需额外验收。
