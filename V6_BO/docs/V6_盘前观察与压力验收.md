# 盘前观察、行情切换及回测压力验收
## 复现
在 v6_release 执行以下两条命令，示例文件为显式标记的合成样本。
```sh
node tools/research-runner.js preopen examples/preopen-stress-simulated.json
node tools/research-runner.js stress examples/preopen-stress-simulated.json
```
盘前命令以调用者给定的 tradingDates 找到 targetDate 的上一交易日，至少需 27 根已收盘 K 线。沿用原风险过滤和平台突破放量条件，排除当天已封板和断板观察，不使用目标日的开高低收、竞价及成交。输出候选与原因，不给出涨停概率。此为前收盘筛选，竞价端尚未验收。来源仅限 imported/simulated。历史因子如提供 factorsPublishedAt，须为带时区的时间，晚于该历史日北京时间15:00或无法解析则不使用。旧数据未提供时间时沿用当日收盘分配假设，真实验收仍要核对供应商发布时间。

压力命令：splitDay 为留出首日，end 为末日。用同一策略和空仓初始现金独立运行基准、双倍佣金、双倍滑点和两者同时加倍，卖出税率一致。可传 strategyId（见 strategies/research-playbooks.json），例如 platform_breakout、trend_pullback、leader_sector；逐日只从该战法信号通过的标的中选择。策略、窗口及参数应在查看留出结果前冻结。前端未新增控件。
收益包含期末持仓市值；胜率按平仓笔数计算。无平仓时 winRatePct 为 null。blockedSells 为受阻委托次数，不是受阻股票数。压力入口对 OHLCV、日期对齐做校验，已声明前后复权价或区间有 corporateAction 的样本暂拒绝计算；尚未实现分红入账和拆并股对账，未标注公司行为的输入仍需外部核验。
示例产生 1 个盘前观察标的；连续跌停两日、再停牌一日，四档各记录 3 次卖出受阻、1 个期末持仓、0 笔平仓。此结果只用于检验记账行为。

## 行情与外部验收
C01：使用 curl 限时请求 push2his.eastmoney.com 的东方财富日 K 线端点，本环境收到 HTTP 503，未取得可核验真实行情；供应商授权未验收。C02/C04：本机双 HTTP 端点、2 个模拟代码、3 轮刷新实际执行。正常时不请求备用源、主源 503 时重试并切源、双源 503 时失败可见且原缓存可读取。此测试通过研究模块直接编排，不证明线上路由已配置独立授权源，也不证明全市场长稳运行。修复前新增来源断言实际失败，修后模拟缓存读回保留 simulated。
