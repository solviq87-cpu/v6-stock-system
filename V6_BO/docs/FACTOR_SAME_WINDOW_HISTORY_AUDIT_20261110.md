# V6 自动学习研究：未新增交易日仍必须审计历史证据

## 缺口
此前自动学习在收到上一次通过的影子模型时，先比较训练截止日与最新观察日。即使当前数据日历未变化，只要已有的历史成熟价格或报告被替换，仍可能提前返回“未增加新的训练时间窗”，由 Worker 误判为正常 `skipped-no-new-training`，未触及原有 `observedFingerprints` 血缘对账。

## 修复
本次保持已有训练/验证/样本外划分和正式策略完全不变：先核验已接受模型指纹、因子来源、旧权重和所有过去已消费的 `[featureFingerprint, marketFingerprint]`，**核验通过后**才允许对日期完全不变的情形返回正常跳过。日期倒退继续拒绝。

## 验收
- 合成研究输入：56个冻结信号日，首次通过的 `shadow-updated`。
- 相同56日、原数据不变：`skipped-no-new-training`，不增加归档。
- 相同56日、只替换一份**自身签名有效**、但历史行情结果不同的成熟报告：核心显式拒绝，Worker 不吞错误，不写新档案，仍释放单写入锁。
- 仓库自动运行全部 Node / 网页及集成测试。所有合成测试都不构成真实市场收益、实际数据授权或正式策略认证。

## 范围和回滚
只改 `src/core/factor-shadow-evolution.js`、`tests/factor-shadow-evolution.test.js` 与本研究说明。未接外部接口、未启动云端进程、未动两张锁定主页/正式四套策略/模拟盘/账户。若出现回归，回退本PR提交而不得用旧压缩包覆盖整仓；原历史研究档案保持不动。
