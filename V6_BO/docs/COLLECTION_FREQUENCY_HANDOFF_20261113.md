JavaScript、请求页面 API、点击扫描、修改记录或部署。下载正文含分享凭据，仅保存在私有目录，
不进入 Git 或公开交付。该页不等于本仓库 BO/V6_WEB 的源码版本。

静态源码显示：全市场目标每5秒一轮、500只/批、2 worker；5578只为12个请求，健康快速轮约
144次/分钟，加关注行情约156次/分钟/页面，日线另算。日线2在途、起步间隔180ms，存在同腾讯
多路径尝试，10分钟缓存期限短于5578条首次采集仅起步间隔所需的约16.7分钟。每页独立启动，
隐藏页未主动停采，手机和电脑会叠加。这些是静态上界/节奏推导，不是实际服务器访问日志。
公开行情请求使用 `credentials:'omit'`，不带行情登录 Cookie；仍可能被限流或封 IP，不能承诺不封禁。

分享链接只用于只读核验，不自动成为源码写入或发布入口。当前线上页面的独立补丁及离线验收
须单独交付；在实际替换前，本仓库补丁不能保护该页的浏览器直采。

## 本仓库界面刷新修复

- 原 `public/assets/app.js` 每次开电脑主页都会 POST 全部刷新，并在15秒内追加2.5秒轮询。
  现在开页只读取既有云端状态，保留原定时读取和手动按钮，不再因多开页面自动启动重采。
- `/api/refresh` 的 global/ext 共享一个真实采集任务，去掉同一次操作的两次 global 获取。
  手动全局走只更新显示的路径，不调用会触发模拟预选买入的调度函数，联动推送也不因该路径发送。
- 手动重采按服务端模块共享冷却（global/板块/竞价等60秒，新闻120秒，较重模块更长），
  重复调用返回缓存状态和剩余时间；不能用另一个浏览器或 global/ext 别名跳过。
  sectors 任务名与定时器 `sectorsZT` 对齐，已有忙锁也复用。
- 这层是面板入口预算；逐 wire 供应商间隔、重试和限制冷却由共享 governor 处理。
  单主进程与持久卷的运行条件不能由本机测试代替。未改两张锁定主页的任何字节或视觉布局。

新增专项直接执行两份真实开页启动块、真实 HTTP 路由、真实联动函数和冷却模块；所有网络使用
本地 fixture/mock。严格出站拦截后20/20通过；早期夹具/拦截器失败单独保留，不算通过。

## 验收与一次执行失误

前一轮2622项是离线回归，不是2622次供应商请求。本轮排查曾误运行旧
`_test_datasource_fallback.js`，其中包含真实公开探测。发现后立即中断，退出130，无残留该脚本或
curl子进程。可证请求尝试下界12、结构上界21，实际到达次数未知；不能宣称本轮全会话零出站。
事故原命令、原输出和停止证据单独保留于交付证据，不以其结果认证数据源或测试通过。

后续专项加载拒绝真实网络和非允许子进程的 preload；需要本地 HTTP/Node 子进程的测试只放行
回环地址、Node测试进程、只读本地Git与描述符文件锁。强禁脚本拦住本地夹具不能算业务失败，
但也不能将被拦住的测试写成通过；最终结果以固定提交的完整回归与CI原始日志为准。
