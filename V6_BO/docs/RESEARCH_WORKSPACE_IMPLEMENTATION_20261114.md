# 八类研究功能闭环实现

本轮以#223的核验报告为起点，按用户“做完不要重复提交”的要求落实运行功能。基线`a3071443f277ed8118419b17892125ef54b6b8c1`，工作分支`feat/research-closure-20261114`。当前验证状态及最终合并SHA见本文末尾，未以旧报告或上游项目的能力代替本轮实现。

## 使用入口

完整V6后端的`/research.html`→“研究记录与复盘”。先填写原有编辑令牌，采集股票、运行原有研究扫描，或点击“比较已存股票”；再读取封存记录。八个页签共用股票、研究版本、筛选批次和北京时间回放时点。两张锁定主页没有修改。

读取记录、回放与导出不联网采集、不修改账户、不发通知。历史时点只读；当前设置保存使用预期版本，旧设备不能静默覆盖新约束。来源真实性、可成交性和预测可靠性各有门槛，界面不会把研究分数改名为胜率。

## 八项实际功能

| 用户目标 | 实现与可核查行为 | 仍由实际数据决定的部分 |
| --- | --- | --- |
| 统一证据卡 | 每条条件绑定证据ID、实际值、门槛、支持/反对或缺失原因、来源原始时间/覆盖期/可得时间/接收时间、内容指纹与原文链接。原时刻缺失保留未知，原文链接剥离查询参数 | 不能从接收时间推造供应商发表时刻；不认证供应商原文真实性 |
| 判断变化时间线 | 不可变研究run逐证券/来源/价格口径比较数值、状态、门槛和规则版本；区分观察变化、同日证据版本变化、规则改版，显示体系前后结论、目标日期和实际分页总数 | 不同目标日的差异不解释为同一预测反转，也不推断涨跌因果 |
| 四体系分歧 | 同一封存股票的十四条/八字/GPT五策略/Python三轮分别列支持、反对、缺失。直接调用原引擎，策略版本由原源码/参数包哈希标识；八字维度“有评分”不作看多票 | 缺少原生Python运行证据、GPT实际因子或竞价封板信息时保持未知；可明确导入带身份与时点的原生结果，不执行上传代码 |
| 筛选淘汰过程 | 三个原扫描入口封存全部items、原排序和漏斗。按股票/批次/状态/最低分检索、分页；首次移出仅计一次，同时保留其他原因。区分本轮未评估、已被当前过滤隐藏、缺数和未达标 | 输入范围来自本轮扫描，不扩张成全市场；保存失败会在原响应给出失败回执 |
| 市场—题材—个股 | 同日指数方向作为描述性环境；显式选择板块的成员/时间快照，至少连续3个同成员交易日计算升温/降温；至少5个已观察成员且覆盖80%才显示相对位置 | 不把相对前排改名“龙头”；缺成员历史/同日覆盖就未知，不用今天成员回填昨天 |
| 策略成绩单 | 策略×源码版本×环境×来源×1/5/20/60交易日；首次信号冻结，次交易日开盘入、持有对应交易日开盘出；完整保留拒绝/未知/待成熟/缺价/成交证据不足。提供明确成本假设、同开盘口径基准和费用压力比较 | 非权威账本收益；无盘前交易状态/公司行为证据、零量/一字板或事后才封存的信号不输出净收益。缺同口径基准不补超额；独立日/股票/非重叠窗口不足不排名、不自动调权 |
| 持仓防守 | 读取原PAPER账户，不另建账本。逐股原报价年龄、成本变化、完整估值集中度、锁仓/静默、买入前已封存依据与当前失效/未知条件、共同题材暴露 | 真实券商未接入；缺买入时证据不借用今天结论补写；任一持仓原报价不满足原15秒门禁，估值权重保持未知，历史回放不借当前持仓 |
| 会话记忆与任务诊断 | 私有服务端保存研究目标、周期、排除股票/板块、集中度关注线、未完成事项；有版本、CAS、恢复、筛选模板与撤销。采集/原始保存/分析复访/工作区保存记录阶段；超时保留最后阶段；研究目录、历史回放、证据导出和配对版本检查 | 模板与偏好仅约束研究视图/关注线，不修改正式策略；失败后不能从不存在的成功记录继续，也不重复交易/通知 |

## 实现边界与恢复

- 核心文件：`src/core/research-workspace-{store,decision,analytics,diagnostics}.js`和`research-workspace.js`；页面资源`public/assets/research-workspace.js`；服务路由`/api/research/workspace`。
- 私有目录由运维设置`V6_RESEARCH_WORKSPACE_DIR`，默认`data/research-workspace`，拒绝public目录/符号链接。GET不创建目录。0700目录/0600事件，进程锁、原子不可覆盖发布、哈希链、幂等ID和设置CAS；2000事件、单事件2MiB、总128MiB硬限。达到容量必须保留原档案后离线归档，不循环删旧数据。
- 自动捕获仅在完整后端已有采集任务运行时增加研究封存，不另起后台抓取、不改变预算或发布owner。保存失败不会丢弃原始股票/扫描响应；回执明确失败。
- 导出包括当前选择的研究与证据、成本/版本/时间、分页范围和约束；不含实际持仓/成本、认证令牌、私有文件路径。导出分页范围明确，不谎称单页就是全部历史。
- 回退：对最终功能提交执行`git revert`；私有工作区保留可恢复。基线归档`base-a307144.tar` SHA256 `184f336ea77ac8b1b460bc8a9429a496dec5a61ef62b27aaabfd81efc0501724`存于本轮工作区Artifacts，不上传私有运行数据。
- WorkBuddy唯一目标/发布者及严格哈希门禁不变。其单HTML托管无法运行Node/Python；没有可信既有发布运行时与读回回执时，不宣称后台已上线或自行替换发布者。
