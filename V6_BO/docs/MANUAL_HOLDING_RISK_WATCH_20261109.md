# V6 手动持仓风险观察 · 本机只读集成（2026-11-09）

## 用途
在既有 `paper:monitor` 本机模拟盘监控页新增“自选持仓风险观察”区。
用户可将股票代码、持仓成本、数量、申报仓位放在自己电脑的**独立私人JSON**，配合外部明确时间和来源的报价快照。
该模块仅进行**只读风险观察**；不会更改模拟盘权威账本、四套正式策略、研究权重、真实/模拟资金、持仓历史或下单门禁。

这是本地数据读取功能，不是持续行情供应商接入、真实盘中交易认证或外部推送渠道。
没配置行情文件生成器时不会自动获得最新价格；不保存文件到 GitHub、公共网页或云端。

## 独立输入样例（仅作协议示范，均为虚构数据）
将以下JSON保存在本机私有路径，例如 `C:\\V6-private\\holding-watch.json`，请使用自己的真实数据替换；**不可提交仓库**：

```json
{
  "schemaVersion": 1,
  "mode": "manual-holding-watch",
  "positions": [
    {"symbol": "600001", "name": "示例持仓", "cost": 10, "shares": 100, "weightPct": 25}
  ],
  "quotes": [
    {"symbol": "600001", "price": 9.2, "quoteAt": 1794205800000, "quoteSource": "declared-public-source"}
  ]
}
```

`quoteAt` 必须是**与该价格同一行**由数据提供方明确给出的原始Unix毫秒时点（不能用文件写入时点、抓取时点、系统当前时间、其他报价行或网页加载时间代替），且评估时不得超过15秒、不得指向未来、不得跨北京时间日期。上述示例时间和报价不代表当前行情。
`quoteSource` 仅为来源声明，即便满足时效也显示 `recent-provider-unverified`，不等于交易所或商业数据许可认证。排除明显模拟/缓存/代理/备份、停牌或不合格状态的报价。

在 Windows PowerShell 配置运行，例如：
```powershell
$env:V6_PAPER_VIEW_TOKEN = "本机自行创建的至少24字符私密令牌"
$env:V6_HOLDING_WATCH_FILE = "C:\\V6-private\\holding-watch.json"
npm run paper:monitor -- "C:\\V6-private\\account.json" "C:\\V6-private\\history.json"
```
该示例并不会启动新行情源；用户需自己提供及更新报价文件。该文件和令牌不得公开、不得用于版本控制。

## 风险提示规则（本轮固定观察阈值，尚未做历史校准）
- 来源和逐票时间有效时：相对手动成本浮亏达到8%提示普通风险，达到15%提示高风险。仅为风险观察，不能把该净值当作券商实际市值、盈亏或成交价。
- 用户明确填写 `weightPct` 时：申报权重达到30%提示集中风险，达到50%提示高风险。仓位缺失不记为0%，也不因当前行情缺失而删除已有手动集中度风险。
- 报价缺失、过期、未来、非当前北京时间日期或来源不可信时：**风险未知**、不计算最新浮亏、不发送价格报警、不使用最后一笔旧报价补零。
- 相同证券同类提醒具有稳定 `id`，供未来通知系统去重；本轮 `canNotify:false`，**没有外部实际提醒投递**。

## 页面和安全
- 本机 `/api/paper/holding-risks` 仅接受GET，并沿用现有至少24字符令牌认证；本机监控只绑定 `127.0.0.1`/回环地址，无跨域公开数据接口，网页仅用文本显示。
- `V6_HOLDING_WATCH_FILE` 可选：不设置显示“未配置”；文件不可读、JSON错误、越界/重复或符号链接均返回“不可用”，并**不复用上次计算的风险结果**。文件上限1MB，只读，不含任何写入逻辑。
- 刷新页面每次重新读取私有文件，不能保证15秒内准实时更新，更不保证通知送达。模拟盘独立账户校验/行情重放仍遵循原有逻辑。
- 不要将真实账户号码、API密钥、口令、真实持仓或可识别隐私写入测试夹具、仓库或公共Issue。
