# V6 第52批：行情文件监控 + 持续模拟盘 + 双端共用页面

## 交付内容
- `src/core/paper-monitor.js`：本机只读 HTTP 服务、响应式桌面/手机账户看板、定时输入轮询、验证历史数据、只追加持久化账户。
- `scripts/paper-monitor.js`：独立启动入口。
- `src/core/paper-service.js`：修复原报告读取不存在的 `openPositions`、`trades` 字段，改用实际账本 `positions`、已成交 `orders`。
- `tests/paper-monitor-e2e.test.js`：HTTP 授权、桌面手机同源看板、账户续期、防重复、异常数据隔离、禁止交易及回环监听。

## 运行方式
1. 准备满足 `scripts/paper-session.js` 所用数据结构的历史行情 JSON，必须包含可信来源、日期和 OHLCV。不得将测试样本当真实行情。
2. 设置环境变量 `V6_PAPER_VIEW_TOKEN` 为至少 24 字符的随机令牌，可选 `V6_PAPER_PORT`（默认 8765）、`V6_PAPER_POLL_MS`（默认 60000）。
3. 运行 `node scripts/paper-monitor.js ./account.json ./history.json`。
4. 本机浏览器访问 `http://127.0.0.1:8765/`，输入令牌。手机浏览器可用相同响应式页面，但本版本服务**仅绑定回环地址**，不会为了手机局域网访问而放宽认证；手机真机跨设备连接需另行设计受认证的 HTTPS 网关。
5. 更新 history.json 后，服务自动验证追加数据并更新账户。重写旧交易日、损坏输入或数据来源变化均不会覆盖已有账户。

## 明确限制
- 数据输入是本地文件，不是已经验证的实时 A 股公网行情。尚无行情供应商连通性、延迟和交易日历实测。
- 轮询服务是运行时持续更新；没有 Windows 服务安装、自动重启或跨设备 HTTPS 发布。
- 同源看板支持桌面和手机尺寸，但未执行真实浏览器截图对照及 iPhone/Android 真机验收。
- 仅供纸面研究，不执行券商交易，不会把离线收益当真实策略有效性证明。
