# 天枢智策 V6：公告、优势、风险与选股战法联动交接

更新：2026-11-07。此文件标记“已实现”和“尚未完成”，不可将历史提交、研究信号或单次 CI 通过误写成已部署实时告警。

## 用户确认的目标
中国A股；一套完整战法命中即进研究观察池，不要求所有战法同时命中。多战法命中可以提高研究关注度，但重复同源信号须去重，看跌风险不能被看涨数量抵消。个股必须显示命中条件、源数据、时间与原因；真实持仓仅辅助监测和推送，不连接实盘券商、不自动实盘交易。模拟盘可独立自动运行。公司公告、利好利空、经营优势、行业与市场环境须一起联动，并以回测检验负优化。

## 已落地：第一阶段“上市公司公告 × A股战法”（只读研究）
- `src/strategy/issuer-event-linkage.js`: 以六位股票代码、公告原文 PDF 地址、发布时间为证据边界；强制限定巨潮资讯 `static.cninfo.com.cn/finalpage/YYYY-MM-DD/<ID>.pdf`；拒绝异股、未来日期、无效/过期日期、非法链接；同文档去重；按标题关键词标记“风险线索、优势线索、相互矛盾、中性待核实”。任何标题归类都是**未经正文核实的研究线索**，不能当作可靠利好或盈利保证。
- `src/strategy/universe-scanner.js` 和 `research-v2-universe-scanner.js`: 每只股票增加 `issuerEvidence`、`issuerLinkage`；另外新增“公告风险核对池”“公告优势线索池”“公告矛盾待核对池”；不改原来 `tradable`、`score`、`finalScore` 与排序。可读取已有可选巨潮公告资料；无源文件/无可选配置时**必须正常扫描**，不得把“没读到公告”当作“无风险”。
- `public/research.html`、`public/assets/research-workbench.js`: 研究池列表、单股标题分类、已核验时间、原始 PDF 链接、风险/看涨冲突提示。
- `src/core/dashboard-view.js`、`public/assets/terminal-dashboard.js`、桌面/手机 HTML：在原有个股详情新增只读公告线索，保留原 K 线形态和策略解释。链接严格限定巨潮 PDF，HTML 特殊字符转义，切换股票/失去访问/断线必须清除无效信息。
- 自动化回归：`tests/issuer-event-linkage.test.js`、`tests/dashboard-issuer-linkage.test.js`、`tests/terminal-dashboard.test.js`、`tests/stock-provider-links.test.js`。包括跨股票混入、防未来数据、防恶意 URL、同股票公告只出现在本股、源缺失不中断旧接口、双端页面及切换股票安全。
- 上述为**代码入库和可验收的研究展示**，不等于全市场公告已经自动接通，不等于有正式的公司优势估值模型，不等于手机已持续推送或线上部署。

## 未完成：下一阶段执行清单（按顺序、每项有验收门槛）
1. **公告真实采集和可靠性**：复用可选 `scripts/optional-research-sources.py` 及 `src/core/optional-research-view.js`，核查实际接口授权、限速和历史覆盖；把公告ID、股票代码、交易所、发布时间、首次获知时间、正文PDF和摘要写入不可篡改的研究归档。覆盖失败显示数据缺口，不能假称已覆盖全A。
2. **公告正文证据与风险/优势分类**：从公告正文区分“计划、进展、终止、已完成”，财务与经营数据须带报表期、审计与公布时点。关注回购、分红、中标、业绩预增，也关注立案、减持、质押、诉讼、财务恶化、退市等；**关键词仅用作线索索引**，真正的影响级别须正文/数值/上下文交叉验证。
3. **大盘 × 行业 × 个股**：与现有上证/深证/创业板/A50 市场环境、行业涨跌家数、成交资金相结合，区分已核验与未经核验来源。设证据状态 `unknown/stale/observed`；不要给缺失数据暗中填0分。
4. **候选池生命周期与分级提醒**：新发现→观察→重点关注→转弱/风险核对。普通技术信号用摘要、重要已核实风险单独提醒；保留原有命中任一战法即可入观察池的 OR 逻辑。强提醒需要数据质量、消息去重、静默/恢复、权限和手机送达测试。
5. **真实持仓盯盘（只通知，不下单）**：复用 `holdings.js` 成本价/股数/仓位/锁仓/静音/私人通道，先显示公告与形态风险证据，再做可配置的持仓提醒。严格测试没有公告的未知状态、旧行情、节假日、锁仓/静音及保密。**无持续服务器/行情推送源不得承诺24小时实时告警**。
6. **独立回测/自动学习**：冻结每个选股信号发生时的数据与公告已知时点；对比旧V6基线的1/3/5/10日收益、回撤、误报、不同市场环境；样本外验证有效才能申请调整正式评分。不得把未来披露文件或事后公司信息塞回过去训练。

## 防负优化规则
- 一切新增公告分类为 **research-only**，不把“公告标题提示”变成自动买卖决策，也不改变旧正式评分；新分数只能通过独立样本外证据逐步升级。
- GitHub 修改每批必须先回归；原独立 HTTP 环境不含 `config/data-source-catalog.json`，因此未配置公告源时必须不调用相关可选读取器，避免破坏旧选股扫描。
- 旧的股票切换测试 `stock-provider-links.test.js` 必须保留并在新增公告渲染函数后持续执行；防止异步K线迟到覆盖当前股票、公告跨代码串票。
- 不能用“仓库提交成功”代替“线上部署已完成”；交付需标明 git SHA、CI、具体入口和未覆盖功能。
