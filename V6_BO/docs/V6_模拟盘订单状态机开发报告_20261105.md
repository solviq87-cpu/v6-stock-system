# V6 模拟盘订单状态机开发报告

## 本轮实现

新增 `src/core/paper-order-state-machine.js`，以事件归约方式实现离线模拟订单生命周期：

- `pending`：待成交
- `partial`：部分成交
- `filled`：全部成交
- `canceled`：撤单（允许部分成交后撤销剩余数量）
- `rejected`：拒单（仅未发生任何成交时允许）

成交事件校验整手数量、正价格、剩余数量上限；多笔成交计算加权成交价；事件序号必须严格递增；事件 ID 重放幂等；终态订单禁止继续变更。输出显式标记 `paperOnly=true`、`brokerConnected=false`、`accountMutated=false`。

## 测试

- 专项：`npm run test:paper-order-state`，12/12 通过。
- `node --check` 对新增状态机和现有撮合 CLI 通过。
- 全量 `node --test tests/*.test.js` 本轮执行达到运行时限，未获得最终汇总；因此不宣称全量通过。

## 边界

本轮新增的是确定性订单状态机纯模块，尚未把状态事件持久化接入现有账户数据库，也未提供订单管理 HTTP API。它不连接券商、不提交真实委托。
