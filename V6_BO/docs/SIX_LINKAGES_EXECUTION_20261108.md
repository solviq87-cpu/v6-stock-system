> 产品边界：中国A股辅助选股、观察池、真实持仓只读风险提醒、独立自动模拟盘；
> **不接券商实盘、不自动实盘下单**。完成GitHub提交≠已部署服务器≠及时手机通知。

## 总体处理路径
发现机会 → 多维度核对 → 自动入池 → 个股解释 → 及时提醒 → 持续跟踪 → 历史验证

研究阶段采用 `OR`：命中**任意一套完整战法**即可进相应研究观察池；
**单个战法内部必要条件仍需全部满足**。不同战法多命中会提高研究关注度，
但不能把高相关的同源指标当成多份独立证据无限加分；
所有看跌、公告风险、资料缺失、行情过期**独立标识，不允许被看涨数量抵消**。

## 当前新增联动的数据接口（只读研究）
在原 `scanUniverse` 的 `market` 研究参数中，可以可选提供：
```json
{
  "market": {
    "linkage": {
      "market": {
        "tradeDate": "2026-02-04",
        "observedAt": 1770191700000,
        "source": "数据源名称（需说明真实来源）",
        "breadthScore": 72,
        "coverage": 0.92
      },
      "sectors": {
        "600001": {
          "tradeDate": "2026-02-04",
          "observedAt": 1770191700000,
          "source": "数据源名称（需说明真实来源）",
          "name": "所属行业名称",
          "relativeStrengthScore": 85
        }
      }
    }
  }
}
```
这些字段是**输入格式示例**，不是当时真实行情或某只股票的事实。评分必须有来源，
且同交易日、采集时间不超前、有效时限内；不满足就为 unknown 或 stale。
研究联动同时显示市场支持、板块支持和独立风险；**不改变已有 `score/tradable`**。
“市场板块同向观察池”和“多维风险核对池”只是研究分类，不推送交易指令。

## 具体交付门槛
1. 每批修改先写独立测试，再查 GitHub Actions 的**最新 SHA**是否全绿；
   防止修一个问题引入一串问题。
2. 核心负优化测试：原有分数、候选判断、仓位、模拟盘交易、权限和私密数据
   不因新研究字段发生隐式变化。
3. 数据缺失不得补0，也不得伪称行情实时、公告已核实、覆盖全A股。
4. 研究页与手机端必须显示：来源、时点、命中条件、相互矛盾的证据及状态；
   用户能点击到相应股票/研究池。
5. 只有正式链路可用、自动通知跨设备验证成功后，才能说“持仓盯盘正式上线”；
   聊天里的助手本身不会持续后台监控市场。
6. 每轮发布附 Git SHA、CI 状态、测试数据量、上线状态、已完成和未完成项；
   **不能用提交成功冒充全部六项完成**。


## 2026-11-08 追加：六项联动研究闭环的实际实现

**本节覆盖上面旧状态表的完成情况**。GitHub提交与自动测试说明“代码可回归”，不等于自动采集、真实手机送达或正式上线。

- **股票池状态机**：`src/strategy/signal-pool-lifecycle.js`，两套 `universe-scanner.js` 现在返回 `lifecycle` 和各股票状态；`public/research.html` 与 `public/assets/research-workbench.js` 显示新发现、连续确认重点、风险核对、转弱。来源缺失/过期不允许升级；单一完整战法命中仍可先进入研究观察。跨会话持久性由下述离线运行器负责。
- **持仓K线风险联动**：`src/strategy/holding-signal-evidence.js` 与 `holdings.js` 对接。持仓卡可显示看跌K线研究证据，符合**同日、收盘后15:10、60秒内、非模拟/非代理且来源明确**等约束时才能追加仅提醒不下单的`形态风险`动作；继续沿用原有静音、去重、私密推送和锁仓门禁。正式行情源及推送端到端仍未认证，不能宣称全天候实时盯盘。
- **信号冻结与结果记录**：`src/strategy/signal-outcome-journal.js` 对股票代码、日期、策略版本、命中规则、当时收盘价、来源和观察时间生成不可重复的研究事件；未来有合格日线才更新1/3/5/10交易日收益与最大逆向波动，不生成尚未出现的结果。只用于研究，不自动修改正式权重。
- **离线闭环运行器**：`src/core/six-linkage-research-runner.js`、`scripts/run-six-linkages.js` 和 npm 脚本 `research:linkages`。使用说明：
  `cd V6_BO && npm run research:linkages -- /绝对路径/数据快照.json /绝对路径/研究归档目录`。
  输入需包含 `asOfMs`、`stocks`、可选 `market` 的可信日期和行情来源。归档采用原子替换及哈希校验，重复数据不制造重复信号；旧文件损坏拒绝覆盖。**还未配置云服务器的定时作业和真实全A股数据，所以实际自动运行仍需要部署及数据源。**
- **专项测试**：`tests/signal-pool-holding-linkage.test.js`、`tests/six-linkage-persistence.test.js`。全量GitHub CI（commit `06b81cb09c`）**1,169通过、0失败**；113项独立HTTP检查通过。这个结果属于GitHub隔离测试环境，不代表真实行情与推送认证。
