# V6 断聊恢复说明（请优先阅读）

**用户已确认的主线**：V6 统一主线“行情刷新超时并发加固与29套回归”。此后先后增加 HTTP 慢请求保护、Content-Length 超限提前拒绝、chunked 流式超限即时拒绝。本包在上述最新文件基础上新增**恢复检查点**，没有擅自合并旧分支。

## 下次聊天断掉时如何接续
1. 上传或引用本 ZIP；让助手读取 `docs/V6_恢复检查点.json`、`docs/V6_后续开发任务大纲.md`、`docs/V6_本批_修改与测试记录.md`。
2. 运行 `python scripts/verify-recovery-checkpoint.py` 校验核心代码 SHA-256；再运行真实测试。
3. 只以验证过的最新完整 ZIP 继续开发，不能仅按文件时间、文件数量或聊天记忆判断。
4. 每次交付新的完整 ZIP 时，更新检查点、父包、代码 SHA-256、测试结果、未完成任务；保留上一版 ZIP，不覆盖用户配置与授权。
5. 对话历史无法由此恢复；该机制保护的是**代码、进度和任务信息**，不保证聊天记录不丢失，也不代表服务器已经部署。
