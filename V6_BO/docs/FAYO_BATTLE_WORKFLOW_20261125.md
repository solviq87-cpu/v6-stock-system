## 2. 候选、天气和缺值

候选沿用 `system-picks.mjs` 原精选条件与理由，核对同日原始报价、接收时点、来源和连续竞价状态。原始报价超过 15 秒、错日、未来时点、只读历史来源或封板记录不能进入买入卡。天气为空仓时暂停候选展示。

天气使用市场宽度、同批涨跌停数和同日封板率，按页面“判断依据”所列阈值给出“可做多 / 谨慎 / 空仓”。缺项待核验，不能跨口径拼接分子、分母。天气与抽屉结论均不产生执行许可。

卡片含代码、名称、原评分、理由、共振、题材及计划。区间、止损、目标、仓位缺失显示“待计划 / 待核验”。mini K 复用 `/api/kline`，核对股票、回执和日期，展示截至所选日的最近 20 根有效原始日 K。

未取得状态显示读取中；无合规候选显示“今天空仓，等待信号”。休市保留研究快照及原日期，刷新时间不能代替报价时间。无信号、断线或缺计划均不填示意数据。

## 3. 共振与同股同日联动

精选、竞价引力、一进二各策略每股每天最多计一次，按共振数优先排序，再按原精选评分排序，取前三只。同一策略重复行不加分，竞价观察明细不冒充策略入选；一进二仅在现有编辑者权限范围内读取。

点击卡片建立深冻结选择快照，统一代码、交易日和原行证据；内外身份冲突则拒绝。详情、板块及草稿共享选择，资金须为同日、明确人民币元的记录。晚到 A 回包不得覆盖 B，跨日不得重贴日期。离开路由注销订阅，返回恢复滚动及展开状态；选取失败不能打开旧草稿。

## 4. 加入模拟盘：一次提交、原执行器

“加入模拟盘”先预填，**此时没有订单、成交或冻结研究计划**。编辑者核对买入区间和账户规则后，调用现有 `/api/paper`，使用新增 `action: "submitDecision"`，账户限定为 A·跟单盘 `pool`。

`src/core/paper-decision-command.js` 前置校验主实例、北京时间交易日、连续竞价、唯一当前精选候选、新闻风险、账户启用与修订、重复持仓或当日买入、原始报价和区间。规则载入后，最终校验至原 `paperBuy` 之间无异步等待。报价越界即拒绝，**不创建自动挂单队列**。

仓位与止损来自服务端 `policy`，提交逐项核对及校验指纹。每票预算沿用 `98 / maxPos` 百分比规则，股数仍由现金、整手、费用和原执行器决定；基础止损、ATR 放宽、收益保护、目标规则及 T+1 保持原行为。策略止损、目标与仓位仅供参考，不能覆盖账户参数。接口拒绝自定义成交价、股数、仓位或止损。

仅在权威账户中核对本次股票、日期和成交事件回执一致后显示成交。超时、缺失或矛盾回执保留“未确认”，暂停重复提交并提供核对。适配不另写买入逻辑或账本；原权限、主副角色与执行门禁继续生效。

## 5. P2 的可用范围

**一句话选股。** 支持精选评分及今日、近 1、3、5、10 个交易日主力净流入排序，返回前 1–10 只，可带题材，例如“近5日主力净流入前5的芯片股”。不支持的条件返回说明。范围限当前同日候选池，保持权限边界，不宣称全市场问财。

资金优先用已有同日来源证据；编辑者可串行读取 `/api/research/stock-observations` 归档，一次至多 20 只。五日须有明确交易日历及连续五个交易日金额，不能用今日数或五根 K 线替代。缺档、单位不明、重复或错日列出缺口；覆盖不足不宣称完整前五。查询只读，不触发采集写入、下单或通知。

**执行评分。** 收盘后读取正式主档案，隔离演示、测试和命名账户。结算样本核对成交、成本、时点、事前冻结计划及纪律；当日未平仓买入使用对账通过的流水及原成交证据核对买价。投影缺少计划或战法绑定时说明限制；仓位、止损缺证据及流水截断均保留待核验。证据未齐不生成总分，盈亏、点击、当前估值不能补分。收益曲线沿用原 `realizedSeries` 已实现收益投影。

**飞书。** 仅 `feishuSecReady === true` 显示私密通道已配置，否则“未配置”；无编辑权限显示权限要求。复用原设置和投递记录，不创建 webhook、不自动发消息、不改发公共通道。送达以原投递回执为准。

## 7. 完整升级与回滚

必须部署同一 Git SHA 的完整前后端，包含新增模块、服务端适配和缓存版本；仅覆盖 HTML 会缺少 `submitDecision` 或账户规则回执，前端应停在未知状态。核对两端应用版本与 `frontend-revision`，并验证旧缓存升级后实际载入的新脚本。

升级前停止写者，冷备运行目录、私有配置、鉴权、研究计划、账本与推送流水。源码可从基线或备份分支恢复；数据使用节点冷备，源码备份不能替代账本备份。切换后读回 `/api/state` 与原账户，核对权限、角色及持久化记录；回滚见 [SAFE_AUTO_UPDATE_OPERATIONS.md](../../SAFE_AUTO_UPDATE_OPERATIONS.md)。
