# V6 本轮开发：模拟盘独立重放审计

## 新增功能
- `src/core/paper-audit.js`：只读审计已落盘的模拟账户，重新运行纸面撮合并比较完整报告内容。
- 核对 `revision`、历史行情最后日期、备份账户完整性、上一版本与当前版本的追加连续性及交易参数一致性。
- `scripts/paper-audit.js`：命令行审计工具，审计失败时以非零退出码结束，可用于本地运维检查。
- `tests/paper-audit.test.js`：正常账户、同步篡改报告和哈希、损坏备份三种测试。

## 运行
```bash
npm run paper:audit -- ./data/paper-account.json
npm run check
npm run check:strategy
V6_MODEL_PYTHON=/opt/pyvenv/bin/python3 bash scripts/run-full-regression.sh
```

## 限制
独立重放可发现自洽重新计算哈希的伪造报告，但无法防御同时重写全部行情、报告及备份的高权限攻击；如需强防篡改，应将外部签名/只增审计日志保存到独立可信存储。模拟账户不代表真实成交，未经真实行情和生产环境验收。
