# V6 自动学习第八阶段：冻结因子的共线性与重复研究增权保护

## 风险与目的

一个行业强度指标与另一个龙头指标若长时间产生几乎相同的股票横截面排名，直接分别为它们正向加权可能把同一份市场信息重复认作两份预测证据。V6 已有冻结信号、5日成熟观察、训练/验证/新鲜测试隔离和原始基准三版本对照，本阶段新增**只使用训练期冻结分数**的因子冗余判断。

只修改独立自动学习研究层，不改变已发布15因子包、四套核心策略、模拟账户、行情接口、电脑/手机主页，也不会自动交易。

## 规则

1. 仅从既有 `selectNonOverlappingMaturedCrossSections` 产生的研究训练日读取信号**发生时的冻结因子分数**。同一股票重叠的成熟结果不重复参与研究。禁止使用验证、保留测试或未来因子值计算冗余系数。
2. 对每对已登记因子，在各训练日已有至少5个同一横截面可比较股票时计算 Spearman 秩相关；分数必须全部有限且在0～100。常数分数无法产生相关性，只记为缺失证据，不构造 0 或假相关。
3. 至少15个可比训练日、覆盖整体训练日75%以上，中位秩相关≥0.92、训练前后半段平均各≥0.90，且≥80%的可比日相关≥0.90，才把两个因子识别为稳定同向高共线。**两因子还必须都通过先前可靠性门禁、训练平均因子IC均≥0.03**，才可以自动进行研究增权保护。
4. 多个可相互替代的可靠正向因子中，训练IC较高者保留当轮正常学习建议；较弱者不再因同一组信息取得正向增权，并在当轮对其**影子研究权重最多缩减2%**。正式因子权重不动，且仍由原先±8%每轮、50%～150%总体限制约束。归属关系按可靠IC和因子ID稳定排序以便复现。
5. 高度反向秩相关（例如因子A高分时因子B低分）可能是相反信号、不同尺度或高度重复，但不能仅凭负相关确定两者的风险/收益关系；只记入报告 `strong-inverse`，不自动缩减，避免误伤原先正负IC用途不同的因子。
6. 诊断报告 `factorRedundancy` 输出训练天数、要求覆盖天数、每对因子正负相关强度、前后半段、有效比例、是否支持抑制、被抑制因子与相对保留因子。报告随影子版整体SHA封存；即使某个因子被压低，新的研究组合仍必须通过既有时间隔离验证、新鲜测试、原始基准三版本对照和冷却门禁，否则原研究版保留不动。

## 未证明的事情

训练期因子共线不意味着其中某个因子在不同市场风格下完全无用；此处抑制的是**进一步自动增权**，不是删除功能或证明因果贡献。前后分段与固定阈值只属于保守探索规则，尚未针对真实授权A股样本或行业中性/市值中性/成本收益做长期外部检验。股票间的市场共振与迭代多次试验依然可能影响统计判断。

若学习数据不足、因子缺失、未经事先冻结或研究回报无法核验，禁止对外宣称已有有效自主进化或可以实盘使用；代码运行通过只说明研究逻辑通过相应测试。
