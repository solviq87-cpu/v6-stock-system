# V6 双端 UI 参考图二次对齐报告

日期：2026-11-05

## 本轮目标
针对用户提供的桌面端和手机端参考图，修正上一版只统一深色配色、未落实页面信息层级和导航构成的问题。

## 代码修改

### 电脑端
- 新增 `public/assets/v6-reference-precision.css`，建立深蓝黑终端视觉、霓虹蓝边框与卡片层次。
- 新增首页参考图总览区域：品牌/系统状态、行情连接、市场情绪、精选池、策略研究、风险中心五张状态卡，以及智能选股、策略研究、回测、模拟交易、行情、风控快捷入口。
- 状态卡通过 `v6-reference-precision.js` 绑定现有 DOM 状态：`mkt`、`tickinfo`、`moodBox`、`poolInfo`、`pool`、`strategySummary`；不填入虚构指数、价格或收益。
- 保留既有业务模块 DOM ID、API、角色权限、策略逻辑和原始页面模块。
- 大屏采用顶部业务导航、左侧固定工作台导航，较窄桌面/平板自动切换为无侧栏布局。

### 手机端
- 将顶部标题区调整为 V6 品牌标识、搜索/消息/账户快捷入口。
- 增加吸顶横向功能导航：首页、智能选股、策略研究、回测分析、行情中心、模拟交易。
- 底部导航调整为七项：首页、自选股、行情、AI研究、模拟交易、风控、我的。
- 保留原有登录门、角色权限、数据加载、刷新、原有概览/市场/计划业务区及 API。
- 保留 iOS 安全区、触控尺寸、窄屏折行和横向表格局部滚动规则。

## 数据真实性
新增桌面摘要只读取既有应用状态节点。当前接口无数据时显示“等待数据/未连接”，不生成示例行情数字。用户提供的两张图片已作为 UI 参考文件放入 `docs/ui-reference/`。
