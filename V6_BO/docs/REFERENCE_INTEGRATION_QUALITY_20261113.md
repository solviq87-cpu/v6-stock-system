只使用目标日期唯一日K及该条/缓存的收盘后 receivedAt；缺失、重复、接收时间未知、未来或盘中缓存不能算最终收盘。涨停标志不明保持 null，涨跌与涨停分别使用已知分母。统计最近30个有观测日期；收盘上涨率相对前收盘，不是推送后收益、成交胜率或净收益。当天收盘特征不作为当时预测输入，feat=null、trainEligible=false。实际因果学习继续走既有冻结信号链，不把这个描述统计自动回灌。

新文件使用互斥锁、私有权限、fsync及原子替换。同一日期/股票结果可重复生成但不重复追加；已存结果改变则报错并保留原文件。数据缺失不以“0条成功”抹掉历史。不读入参考上游同步凭据，不扩大训练或交易权限。
