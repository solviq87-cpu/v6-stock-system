# V6 本批真实修改清单 — A股市场日期及行情质量门禁

基线：`V6_统一主线_可信代理与设备持久化_完整工程_20261105.zip`。仅改动行情数据质量及时间边界，不修改任何交易规则、组合权重、买卖逻辑、持仓和用户数据。

## 修改或新增的行情源码（6个文件）

1. 新增 `src/core/a-share-calendar.js`：按北京时间（UTC+8）计算A股日线日期；不推断交易所开市、收市或法定交易日。
2. `src/core/market-data-center.js`：外部历史 `asOf` 未来日期验证改为A股市场日；`validateImport` 新增可注入时间方便确定性边界测试。保持原始历史严格单调和来源检查。
3. `src/core/market-breadth.js`：快照日期与分析 `asOf` 统一到北京时间；`minCoverage` 必须是有限数字，阻断 `NaN` 绕过覆盖率门禁。
4. `src/core/eastmoney-market-snapshot.js`：按市场时间给请求日标记；无有效市场编号或全空白涨跌幅的股票不再视为真实零值；超时时间限制100–60000ms。
5. `src/strategy/cached-kline-adapter.js`：日线的未来日期判断改用A股市场日，而不是UTC日；仍验证日期递增、数据结构、缓存年龄。
6. `src/strategy/research-v2-cached-kline-adapter.js`：统一使用同一市场日期辅助函数，消除两个适配器的重复时间实现。

## 新增测试（3个文件，10项）
