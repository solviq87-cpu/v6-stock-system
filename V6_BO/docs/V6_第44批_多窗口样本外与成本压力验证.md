# V6 第44批：离线多窗口样本外验证与成本压力评估

## 交付范围
- 新增 `src/core/research-validation-suite.js`：对已校验的对齐 OHLCV 进行连续样本外窗口重放，窗口前设置隔离期，每窗口独立从空仓起算；执行基准成本和双倍手续费/滑点压力测试。
- 新增 `tools/validation-suite.js`：独立离线 CLI，输入 JSON 数据集及可选配置 JSON，输出包含 SHA-256 数据指纹、逐窗口表现、汇总和局限性的 JSON。
- 新增 `tests/research-validation-suite.test.js`：覆盖可复现性、窗口约束、公司行为、价格基准、数据质量、参数边界。
- 原有四套选股规则、生产排名、接口和飞书安全隔离均未修改。

## 运行
`node tools/validation-suite.js 历史数据.json [配置.json] > 评估报告.json`

数据结构：`{ "source":"imported", "provider":"数据供应商", "asOf":"2026-11-05", "stocks":[{"symbol":"600000","bars":[{"date":"YYYY-MM-DD","open":10,"high":11,"low":9,"close":10,"volume":10000}, ...]}]}`。至少32条对齐记录，实际所需长度取决于窗口参数。

## 不得虚报的验收边界
- 多窗口回测不等于完成真实历史数据接入、样本外训练/调参验证或模拟盘对照。
- 该评估复用既有研究扫描器与持仓账本，尚未把四套独立体系全部作为可回测选股信号贯通。
- 尚无真实行情供应商连通性验收、桌面/手机真机验收及生产部署验收。
- 研究输出 `canTrade=false`、`productionEligible=false`，不得自动转为买卖建议。
