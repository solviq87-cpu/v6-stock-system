# V6 模拟盘事务状态校验加固与核心回归报告

日期：2026-11-05

## 本轮范围

本轮仅修改模拟盘资金安全与事务协调代码，不修改电脑端/手机端 UI、HTML、CSS、页面布局或界面资源。

## 修改内容

1. `src/core/paper-transaction-coordinator.js`
   - 对事务日志状态实施白名单校验，仅允许 `prepared`、`committed`。
   - 即使日志指纹被重新计算，未知事务状态仍会被拒绝。
   - 对事务 ID、订单方向、六位股票代码、订单与成交事件关联关系增加入账前校验。
   - 对交易日期增加严格日历日期校验，拒绝如 `2026-02-30` 这类会被 JavaScript 日期解析器归一化的非法日期。
   - 所有新增校验均在写入 PREPARED 日志前执行，非法输入不会留下事务记录。

2. `tests/paper-transaction-coordinator.test.js`
   - 新增未知事务状态且重新计算指纹的拒绝测试。
   - 新增非法日历日期拒绝测试。
   - 新增订单 ID 与成交事件订单 ID 不一致拒绝测试。
