## 本轮发现并修复的可复现缺陷

| 编号 | 缺陷 | 影响 | 修复 | 回归证据 |
|---|---|---|---|---|
| BUG-01 | 历史指标使用 Number(null)、Number('')、Number(false) 将缺失成交量转换为0 | 伪造有效成交量，可能污染技术指标及策略输入 | 指标入口统一使用 `completeOHLCV` 验证，拒绝缺失、空白和布尔值 | `market-feed-input-integrity.test.js` |
| BUG-02 | 历史指标遍历 null K线直接读取属性 | 输入异常可触发运行时错误 | 在字段读取前验证行对象与完整性 | 同上 |
| BUG-03 | 行情质量校验的 `now` 或 `maxAgeMs` 接受 NaN/Infinity/负数 | 新鲜度门禁可被异常参数绕过 | 校验有效时间和非负有限延迟，失败时拒绝使用 | 同上 |
| BUG-04 | 快照收盘价为 null、空白、布尔值、NaN 或非正值时比较可能跳过 | 快照与历史K线不一致时可能误判可用 | 显式校验收盘价，非法值拒绝 | 同上 |
| BUG-05 | 行情质量函数在 `stock=null` 时直接访问属性 | 非预期异常而非安全拒绝 | 使用安全空对象并返回不可用 | 同上 |
| BUG-06 | 行情时间戳可为 Infinity 或超出 Date 可表达范围 | 时间字段失去可信含义 | 有效有限正数和Date范围检查 | 同上 |
