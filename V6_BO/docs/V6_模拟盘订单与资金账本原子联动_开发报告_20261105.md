# V6 模拟盘订单与资金账本原子联动

## 本轮实现
- 新增 `src/core/paper-account-ledger.js`：独立离线纸面账户账本。
- 成交事件在单一账户文件事务内同时更新现金、持仓批次和事件日志，采用独占锁、临时文件、fsync 与原子 rename。
- 买入按成交金额与费用扣减现金并新增批次；卖出按批次扣减，仅允许卖出日期晚于买入日期的批次（T+1），按净回款增加现金。
- eventId 幂等；相同 ID 不同内容拒绝；账户指纹校验；并发写入拒绝。
- 新增 `npm run paper:account-ledger:test`。

## 验证
- 订单状态机、订单事件存储、账户恢复和新账户账本共 27 项定向测试通过，0失败、0跳过。
- `node --check src/core/paper-account-ledger.js` 通过。
- 本轮未执行全仓完整历史回归，因此不宣称全量测试通过。

## 边界与待办
- 本模块是独立纸面账本，尚未与现有生产模拟盘服务/API 完成端到端接线；不能把它视为现有账户已自动迁移。
- 单文件原子提交保证本账本文件内现金、持仓、事件一致；订单事件库与账户账本是两个独立文件，跨文件事务/崩溃恢复协调仍需事务 outbox 或统一数据库完成。
- 交易日历、费用规则、税费差异、真实盘口成交和券商接口仍需按实际市场与配置验证。
- 不连接券商，不执行真实交易。
