# 人工执行、对账与复盘闭环

本批起点 `dev@01661416b76a3065de78cde708060c4738aba4cf`，功能分支 `feat/manual-decision-loop-20261116`，正式应用版本 `20261116ab`。用户在参考闭环架构后明确要求实施。入口是绯曜「资产 → 执行复盘」，手机与电脑使用同一服务端私有日志，不依赖另一设备在线。

## 实际行为

1. 从现有归档研究选择一个版本，冻结其编号、内容摘要、原代码版本、四策略选股证据、行情判断和当前原持仓风控配置。计划股数及买价上限由用户填写；仓位模型明确标为人工计划、未验证。原策略、账户和风控配置不被此流程改写。
2. 明确记为未执行并保存原因，或按实际时间登记买卖成交、唯一成交编号、数量、精确价格和全部费用。这里没有下单接口，不连接券商，不发送消息。T+1、非开市日、早于建议冻结、超计划数量和价格偏差如实保留，复盘不能将其标成无偏差结果。只记录本建议从买入到平仓的多头交易，不导入既有未关联持仓。
3. 从另行保存的交割记录粘贴 JSON，逐字段核对成交编号、方向、数量、价格、费用、时间；不一致和之后的纠正都保留。来源由用户申报，逐字段一致不等于券商认证。不能用本记录证明独立账户真实性。
4. 全部平仓且对账一致，或明确未执行后，才能冻结复盘。价格采用万分之一元整数、费用采用分；每笔成交额以四舍五入到分计算，平仓净额扣全部申报费用，不猜测佣金或税率。未平仓及未执行均不估造收益；结果仅覆盖本建议，不是整个账户收益。
5. 复盘后提交有界研究参数候选及预注册训练/验证/样本外日期、样本数、回撤、收益、超额收益和成本压力门槛。训练末日不得早于候选冻结当天，验证与样本外在其后。各实验区间不得与既有有效候选或已检验候选重叠；重开复盘不能清除已窥看的样本外；不接受客户端数据文件路径、价格、通过标志、原风控参数或生成代码。样本外结束前拒绝运行。每候选只检验一次，结果为拒绝或研究验证通过；两者都不改变生产权重、交易许可和账户。
6. 录入错误通过追加作废记录纠正，不能覆盖原成交。已复盘需要先追加重开原因；旧复盘与候选保留，旧候选不能继续验证或用作当前有效结果。纠错后重新对账、复盘及预注册。

日志中的 `canTrade / canNotify / productionWeightsChanged / brokerVerified / accountWrites / autoPromotion` 始终为 false。冻结的风控配置仅供复核，缺少组合/实时行情等证据时状态为未放行，不能从研究建议跳到自动交易。没有凭此新增全局风控阈值，也未启用付费资源。

## 私有存储及运行

- 默认 `V6_BO/data/manual-decision-loop/`，可由服务端环境变量 `V6_MANUAL_DECISION_LOOP_DIR` 指定私有绝对路径；不接受浏览器路径。
- 复用现有研究日志：目录0700、文件0600、顺序哈希链、fsync、不可覆盖发布、内核进程锁、请求幂等和预期修订 CAS。单服务实例多设备共享同一修订；副本实例拒绝写入。跨主机多写者及恶意整体链回退仍需要外部可信存储/锚点，不能靠此日志自行证明。
- 单次 POST 最大64KiB；每建议最多100笔有效成交、10个候选；整体沿用2000事件、单事件2MiB、总128MiB限制。达到限额拒绝追加，不自动删历史；备份后按原档案运营流程维护。作废后的成交编号不能再次复用。
- `GET/POST /api/research/manual-loop` 仅原生编辑身份 Bearer；拒绝查询令牌和任意查询参数，原同源写入门禁保留，所有响应 no-store。GET不创建目录或账户。目录或链损坏会拒绝读写；原研究档案不可读时，已有执行日志仍可读，但新建议不能冻结。
- 工作在现有有界研究 worker：单飞、384MiB、55秒超时，主服务行情轮询不会同步承担回放和回测。失败不声称保存成功；超时后使用原请求ID及原内容重试，先读已提交证据再执行。
- 日历冻结自现有2026研究日历；范围外或休市成交记录标偏差，绝不以此声明生产交易日历认证。

## 验证数据接入

`V6_MANUAL_LOOP_VALIDATION_INPUT` 只能由服务器运维配置为私有绝对 JSON 文件，父目录0700、文件0600、无符号链接、最大8MiB。它采用现有 `adaptive-market-lab` 输入协议（参见 `src/core/learning-profile-registry.js`、`tests/helpers/adaptive-fixture.js`）；生产使用须由已授权真实研究数据生成，测试夹具不允许作为生产证据。

文件 `asOf` 必须等于候选预注册 `holdoutEnd` 且不晚于当前日。现有参数注册模块继续强制至少61天训练、20天验证、20天样本外、完整显式日历、原始未复权行情及因果证据；固定候选与基准分别运行训练、验证、样本外和额外成本压力。候选不能关闭市场/预测/回避门禁，不能降低统一研究费用基线；验证结果、输入摘要和协议摘要追加留存，不将文件内容或路径返回浏览器。未配置真实文件时明确等待，不制造通过记录。

此功能没有替代原学习注册表的生产运行授权，也没有自动激活候选。研究通过后仍需既有独立模拟、真实账户、实时行情、安全及部署门禁。未来数据尚未产生的候选应等待，不能以一次历史拟合证明新建议有效。
