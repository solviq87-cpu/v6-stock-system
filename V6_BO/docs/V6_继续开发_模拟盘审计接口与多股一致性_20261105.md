# V6 本轮集中开发记录

## 已实现
- 模拟盘只读 HTTP `GET /api/paper/audit`：沿用 Bearer 鉴权、只绑定回环地址；重放历史数据并核对报告，审计失败返回 HTTP 503；不更改账户文件。
- 模拟盘追加历史校验：对多股票追加的交易日数量执行一致性校验；继续保留旧历史不可改写、股票元数据不可改写及来源不可变更限制。
- 新增两项自动化测试，覆盖 HTTP 审计、篡改拒绝及多股票不一致场景。

## 运行
`npm run paper:audit -- ./data/paper-account.json` 可执行离线命令行审计。HTTP 服务通过 `createPaperService` 提供 `/api/paper/audit`。
