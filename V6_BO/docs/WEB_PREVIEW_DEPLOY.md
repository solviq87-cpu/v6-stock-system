# V6 网页版预览部署说明

## 当前状态

此目录提供容器构建入口，不代表已经部署成功。GitHub Actions 负责检查代码，不负责自动发布。

## 预览环境安全约束

- 预览与生产必须使用不同的数据目录、口令、推送配置和凭据。
- 设置 `QD_CLOUD=1`，禁止依赖 localhost 免密机制。
- 在独立的运行时 `config.json` 中设置 `"pushRole": "replica"`，防止预览实例重复向用户发送生产推送。
- 不允许将 `config.json`、`access.json`、持仓或 API 密钥提交 GitHub 或打入镜像。
- 生产上线前必须核验口令初始化、HTTPS、数据持久化、代理真实 IP 和外发推送行为。

## 构建

从 `V6_BO` 目录执行：

```bash
docker build -t v6-preview:dev .
```

在已配置独立预览凭据和数据卷的服务器上启动容器，并按实际服务器配置映射 8787 端口。不要直接把无口令的开发实例暴露在公网。

## 下一步

选择部署平台、绑定持久化卷与私有配置、设置 HTTPS 域名，然后进行网页可访问性与认证测试。CI 通过不等于已经上线。
