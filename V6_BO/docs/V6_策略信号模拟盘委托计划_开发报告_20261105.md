# V6 策略信号到模拟盘委托计划（只读建议）

日期：2026-11-05

## 本轮实现
- 新增 `src/core/strategy-paper-intent-plan.js`，将四套策略已审计回放中 `verdict=pass` 且具有下一交易日与可信参考价的信号转换为模拟盘委托建议。
- 增加资本、单票仓位比例、单股单日策略重叠上限、最大建议委托数校验。
- 缺失参考价、未知/失败策略证据、无效股票代码/日期、重复信号均拒绝生成建议。
- 同一股票同一执行日的跨策略重叠按风险配置限额处理，避免重复占用资金。
- 新增 `scripts/plan-strategy-paper.js` 与 `npm run plan:strategy-paper`，输出机器可读 JSON。

## 安全边界
- 输出 `mode=paper-order-intent-plan`、`canTrade=false`、`executed=false`。
- 不提交订单、不写入模拟盘账户、不连接券商，不触发真实交易。
- 该模块只产生待复核建议；真正模拟执行前，仍需执行器再次校验交易日、现金、持仓、T+1、涨跌停、停牌、费用、成交量及风控。
- 本轮未将事后策略证据伪装成已经驱动模拟盘，也未生成任何收益结论。
