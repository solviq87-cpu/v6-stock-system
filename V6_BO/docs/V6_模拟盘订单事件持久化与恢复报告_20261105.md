# V6 模拟盘订单事件持久化与恢复报告

## 本轮交付

新增 `src/core/paper-order-store.js`，为订单状态机提供离线持久化层：

- 按订单 ID 独立保存订单原始定义、事件日志、当前归约状态和事件日志 SHA-256。
- `create()` 独占创建订单文件；`append()` 使用独占锁防止并发写入。
- 追加事件前重新读取并校验日志结构；同一 eventId 且内容一致时幂等返回，eventId 相同但内容不同时拒绝。
- 每次更新先在同目录创建权限为 0600 的临时文件，写入并 fsync 后原子替换；尽可能同步目录元数据。
- `get()` 校验事件日志指纹，并从事件重放重建状态，与存储状态指纹比对，以发现日志或状态被篡改。
- 订单 ID 限定安全字符，订单文件拒绝符号链接、非普通文件及超大文件。

## 未完成边界

本轮只持久化订单事件，不是订单事件与现金、持仓批次、资金流水的跨文件原子事务。崩溃恢复可重建订单状态，但尚未完成账户账本的事务性投影、事件补偿及端到端长期运行验收。模块仅用于离线纸面模拟，不连接券商，不产生真实委托。
