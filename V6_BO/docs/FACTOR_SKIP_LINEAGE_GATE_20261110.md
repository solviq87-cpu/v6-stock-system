# V6 影子学习：正常跳过之前必须审计试验账本和冷却血缘（2026-11-10）

## 问题与修复

在旧逻辑中，已接受模型的训练截止日未变化，或观察截止日与已有模型相同，立即抛出“未增加新的训练时间窗”，Worker 将其解释为正常 `skipped-no-new-training`。此时上一轮消耗过的保留集试验（`previousTrial`）和衰减冷却记录（`previousCooldown`）尚未进行完整证据血缘核验。

假如某次候选在新增5个成熟交易日的保留集上失败并留下不可变试验报告，后来操作员误将清单恢复为只含较早批次，旧逻辑可能将“试验之后的资料倒退”报告成无害跳过，而不是拒绝恢复学习。冷却期警告也可能被这个提前分支掩盖。

现在先检查已接受模型及其冻结历史、**已消费的候选试验档案**和**衰减冷却档案**；全部通过后，才允许用“训练未变化”返回无害跳过。不改动影子因子的候选计算/晋级条件。

## 回归边界

- 56个合成日先生成已接受模型；另5日评估候选后因市场冲击暂停，但样本外保留日仍已消费；误将研究清单退回到只多1日的57日：应拒绝历史试验账本血缘，而不是正常跳过。
- 消费试验的报告修改试验编号而未重封签，也必须拒绝。
- 若另一条历史发生衰减并进入冷却，清单退回旧日，应拒绝冷却血缘。
- 仅有正常历史、训练确实没增加的情况继续正常跳过。

专项/回归在PR CI运行，不能把合成数据测试视作真实前瞻收益验证。

## 安全边界

所有修改仅涉及研究沙盒内的拒绝/跳过判断与测试，不自动接通行情、启动后台、发布策略或交易。只读历史审计依赖私有档案保存完整；若有人删除了**全部**本地档案，单靠本地 SHA 无法验证曾经消耗过哪些样本，仍需独立备份与外部审计。冷却和试验缺少证据时应人工核对，不能靠清除锁、改日期或更换目录绕开。
