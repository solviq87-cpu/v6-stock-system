# 研究工具使用说明
在 `v6_release` 目录执行：
```bash
node tools/research-runner.js scan /path/to/stocks.json
node tools/research-runner.js ledger /path/to/stocks.json
```
输入JSON示例结构：
```json
{"stocks":[{"symbol":"000001","market":"main","bars":[{"open":10,"high":10.5,"low":9.8,"close":10.2,"volume":1000000}],"feed":{"source":"imported","timestamp":1793810000000}}]}
```
扫描需要至少27根有效历史K线，行情时间戳需与运行时匹配。回测需要更多历史K线，支持 `start`、`end`、`initialCash`、`topN`、`holdDays`、`feeBps`、`slippageBps`、`sellTaxBps`。
**注意：仅用于研究，不提供自动交易；不能把模拟、导入或过期数据标注为实时行情。**
