# V6 模拟盘卖出撮合与 T+1 批次校验

## 本轮修改
- `src/core/paper-execution-preflight.js`：接受 buy/sell；卖出检查明确可卖数量；跌停卖出拒绝；预检决策带 side。
- `src/core/paper-intent-simulator.js`：增加卖出方向滑点、卖出印花税估算、净回款、已实现盈亏和持仓批次 FIFO 扣减。
- 同日买入批次不可卖出；若账户汇总可卖数量与批次明细矛盾，按批次证据拒绝撮合。
- `tests/paper-intent-simulator.test.js`：新增卖出成功和同日批次 T+1 拒绝两项专项测试。

## 验证结果
- `node --check src/core/paper-intent-simulator.js`：通过。
- `node --check src/core/paper-execution-preflight.js`：通过。
- `node --test tests/paper-execution-preflight.test.js tests/paper-intent-simulator.test.js`：9/9 通过。
- 全量 `node --test tests/*.test.js`：执行达到约120秒时限，日志停在第340项，未取得完整汇总。不能据此声称全量通过。

## 边界与未完成
- 本模块只输出离线纸面结果，不连接券商、不提交真实委托、不写回线上账户。
- 印花税、佣金和滑点使用配置假设，尚未接入券商/账户费率配置；过户费及最低收费规则仍需按账户配置。
- T+1 使用账户批次日期与明确可卖数量双重保护；跨节假日实际可卖日期仍需可信交易日历服务。
- 真实盘口队列、部分成交、集合竞价撮合、涨跌停排队规则尚未模拟。
