# V6 统一工程：确定性重放验证与后续验收

## 本轮已实现
- `verifyBundle(directory, {replay:true})`：先验证运行清单和 SHA-256，再从归档的历史行情、因子快照、Python 三轮证据与执行元数据重新执行统一研究引擎，严格比较完整 JSON 报告。
- CLI：`node scripts/integrated-run-bundle.js verify /absolute/path/to/run-id --replay`。
- 即使报告被篡改后重新计算清单哈希及 runId，重放仍会拒绝不匹配的绩效结果。
- 增加 3 项行为测试；全量 Node 测试 361/361 通过。

## 安全与适用范围
- 这是离线可复现性校验，不是第三方数字签名、可信时间戳或生产实盘验证。
- 重放以当前安装的研究引擎版本执行；如代码版本变化，应使用原始代码版本重新核验，不能把版本变化导致的差异当作数据篡改。
- Python 原生脚本不在验证阶段再次执行，重放的是已归档且校验过的三轮证据及执行元数据。
- `canTrade=false`、`verifiedLive=false` 不变；不提供真实下单。
