# V6 公开研究战法独立前瞻验证流程（2026-11-09）

## 已接入的研究规则
- `vnpy_boll_cci_atr`：布林上轨突破 + CCI14 + ATR14 + 成交量。
- `vnpy_atr_rsi`：ATR22 波动区间 + RSI5 上穿 + 20日均线。
- 来源、研究假设和非实盘边界见 `docs/OPEN_SOURCE_DAILY_RULES_20261109.md`。

## 实际计算流程
1. 导入来源标签及逐日日期完整的A股历史 OHLCV，完成数据结构和历史时点验证。至少提供每股明确未复权价 `priceAdjustment:{mode:'unadjusted',provider:'...'}`，历史证券板块、适用涨跌幅 `limitPct` 和公司行为对账声明 `corporateActionsVerified:true`。
2. 固定两套研究条件与阈值，不拟合、不调参，不将未来K线参与信号日计算；回放时每次只能看到信号日及以前的行情。
3. 先预留预热区、隔离期，再按时间顺序分离多个验证窗口，默认2个25交易日验证窗口、每窗口前隔离2交易日。评估窗口不互相随机混洗，也不使用未来数据入池。
4. 日线信号发生于当天收盘后，只能按下个交易日开盘构造假想进场；至少再隔1个交易日才能在开盘假想卖出。分别评估之后1/5/20/60个交易日的独立信号结果。
5. 模型费用默认双向佣金各8bps、双向滑点各10bps、卖出印花税5bps；低于这些研究基线的配置拒绝计算。适用涨跌停未知、ST/停牌、零成交、一字涨停无法买或一字跌停无法卖，全部在结果中记为单独状态，不假装成交。
6. 公司行为未验证或价格基准不明确时拒绝输出可比较净收益；亏损、无法交易、未知来源、市场暴跌相关样本一律保留。
7. 支持按交易日导入 `publicRuleAuditOptions.marketContexts[YYYY-MM-DD]` 的指数及市场广度。仅复用通过来源和时间验证的大盘急跌只读诊断，按 `systemic-selloff`、`not-systemic-selloff`、`unknown` 分组，市场证据不足绝不假定“正常”。
8. 回报每条规则的每段验证窗口、每个周期、市场环境下的信号数、可建模数、无法建模状态、净收益假设、胜率假设和最差模型净收益；同时包含全部事件记录，避免“只留成功交易”。

## 可调用入口
- 在受开发者权限保护的研究网页 `/research.html`，勾选“验证公开战法未来1/5/20/60日表现”，运行现有 `POST /api/research/complete-run`；新增结果字段为 `result.publicRuleForwardAudit`。默认不开启，不拖慢普通模拟盘研究流程。
- 也可在可信的离线 Node 环境调用 `require('./src/strategy/public-rule-forward-audit').evaluatePublicRuleForwardAudit(history,options)`。
- 单次交互式验证限20只股票、每只400根K线；大数据需要设计独立的分批流水线，不能自行放宽限制。

## 数据来源和结论边界
这些是**冻结参数的分时隔离事件研究窗口**，而非在训练段拟合新模型后通过真正样本外验证的模型；没有外部行情真实性认证，也没有真实撮合、订单簿与模拟账户回账。净收益是逐信号独立假想模型收益，不能累加称为组合实盘收益。重复触发会使样本相关性增加；没有统计置信度、基准超额回报或独立供应商核验时，不能宣称策略有效、上涨可预测或准许实盘。所有市场冲击结果不自动修改因子权重、原四套策略或风控，失败数据不删除。
