# V6 行情历史数据质量门禁加固报告

## 本轮改动
- 历史数据股票标识同时提供 `symbol` 与 `code` 时，强制二者均为六位代码且完全一致，避免静默优先其中一个字段造成标的身份错配。
- 日线成交量必须为非负安全整数，拒绝小数、超出 JavaScript 安全整数范围的值，降低股/手单位异常及数值精度损失风险。
- 若 K 线提供可选 `amount` 成交额字段，要求其为有限且非负数值。
- 原有 OHLC 几何关系、交易日期递增、跨股票日期对齐、截至日期及来源追溯校验保持不变。

## 新增测试
- symbol/code 冲突拒绝。
- 小数成交量拒绝。
- 超安全整数成交量拒绝。
- 负成交额拒绝。
