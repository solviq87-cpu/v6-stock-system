# V6 原参考图对齐，迭代 1（2026-11-18）

## 核心改变
不再使用大片粉紫色渐变冒充还原。保留数据和权限，优先实现原图的**紧凑密度、涨跌语义、复盘统计、三栏排行、逐股可操作表格**。
- PC：顶部缩紧 + 指数 4 张已有来源卡 + 8 项真实复盘统计 + 市场/机会/风险/下一步紧凑条 + 三栏排行 + 完整复盘清单。旧版空来源卡降低固定高度但不虚构数字。
- iPhone：压缩导航和重复解释；统计 4×2 两行首先出现，紧接判断与板块排行；原指数、全部 200 条复盘、股票研究入口继续可达。
- 颜色：深海军蓝主背景，蓝色选中、红涨绿跌、橙色风险，单一粉色强调源端涨停数。所有行情时间、未知和历史状态继续可见。

## 不包含
不是参考图 1:1，原图包含更丰富的多源指数、个股日K、资金/新闻等；当前只基于已认证字段，拒绝凭截图补假数。没有改变后端、账本、交易或账户；也未发布公网。
