## 本次实际修改

1. 移植参考复盘中的分批补历史思路，修复原先只补前 60 只的覆盖缺口。每批 60、并发 12、每轮最多尝试 180 只，避免涨停股较多时尾部长期缺少形态资料。
2. 单股请求失败不终止整个复盘；所有原涨停股保留，无法判断的形态字段保持 `null`。新增 `historyCoverage`，区分总数、待补数、尝试数、可用数、缺失数和本轮延后数。后续周期继续补取，不伪造完整性。
3. 补历史和行情快照期间，如果涨停池、数据日或板块输入变化，保留旧复盘并标记 held，等待后续重算；该轮不写混合批次复盘，也不触发后续接力调用。
4. 首板筛选及竞价回退不再把缺失、零或非数值板数默认成首板。接力输出明确 `level`/`targetLevel`，同分时按股票代码稳定排序，避免供应商返回顺序改变候选名单。

不调整策略阈值，不宣称提高收益或命中率。模型研究分数的现有用途边界继续保留。
