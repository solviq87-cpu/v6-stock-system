# V6 历史行情质量门禁与回测联动报告

日期：2026-11-05

## 本轮变更

- 在 `src/strategy/feed-quality.js` 新增 `validateHistoricalBars`，统一检查历史 K 线 OHLC 正值与高低价关系、成交量安全整数、可选成交额非负有限值、日期有效性及严格递增。
- 将质量门禁接入 `walkForward` 与 `ledgerBacktest`。历史数据不合格时在回测开始前拒绝执行，避免错误 K 线进入选股和资金曲线。
- 校验范围严格限定为本次回测实际使用的历史区间，回测结束日之后的数据不会影响本次结果，避免未来数据改变历史回测结论。
- 修正 `research-integration.test.js` 中用字符串拼接生成无效日期的测试夹具，改为真实日历日期。
- 新增 `tests/backtest-historical-quality-gate.test.js`，覆盖 OHLCV 错误、日期倒序、两类回测拒绝错误数据及回测区间外未来数据隔离。

## 验证结果

- `node --test tests/*.test.js`：409 项通过，0 失败，0 跳过。
- `npm run check`：通过。
- 专项：历史行情质量门禁新增 4 项通过；原有 walk-forward 22 项断言通过；账本回测 13 项断言通过；行情连续性/质量相关 Node 测试 24 项通过。

## 边界与未完成事项

- 本轮实现的是本地历史 K 线结构与日期质量门禁，不代表已验证上游行情供应商的真实性、授权状态或复权口径。
- 交易日历完整性仍需由可信交易所日历提供；本模块不自行猜测节假日。
- 实盘行情实时性、供应商故障切换和真实券商成交均未在本轮验收。
- 不修改 UI，不接入 CMR 或多模型，不连接真实券商自动交易。
