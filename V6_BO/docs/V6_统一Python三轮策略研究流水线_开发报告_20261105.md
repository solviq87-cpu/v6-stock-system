# V6 统一 Python 三轮策略研究流水线开发报告

日期：2026-11-05
基线：V6 样本外绩效统计增强版（474 项历史回归）

## 本轮修改

- `scripts/native-strategy-daily.js` 增加统一 `runResearch()` 流水线。
- 在明确提供可信 Python 脚本时，先通过受限原生桥逐股票、逐交易日执行；每次只传入截至当日的历史前缀。
- 将 Python 三轮证据直接传入既有 `runNativeDaily()`，与十四条、八字口诀、GPT 因子证据使用同一逐日研究报告、覆盖率、数据指纹和样本外归因链路。
- 未配置 Python 脚本时，报告明确标记 `not-configured`，Python 覆盖率保持 unknown，不伪造信号。
- Python 输出股票、日期、观察截止日、评估器版本、来源及三轮结论仍由既有验证器逐项校验；任何未来日期或结构不符均拒绝整份报告。

## 新增测试

`tests/native-strategy-pipeline.test.js` 共 3 项：
1. 未配置 Python 时仍可运行原生研究，且 Python 明确为未配置/unknown。
2. 配置可信 Python 脚本后，逐日证据被送入统一报告，三轮 unknown 原样保留。
3. Python 伪造未来日期时，流水线拒绝生成报告。

## 使用方式

```bash
node scripts/native-strategy-daily.js history.json [snapshots.json] [trusted-python-script.py] [python3]
```

不传 Python 脚本时，只执行已集成的原生研究流程，Python 状态为 `not-configured`。若传入脚本，必须是操作者明确提供并信任的 Python 策略程序。脚本必须按每次输入的 `symbol/date/observedThrough` 输出符合三轮证据结构的 JSON。

## 限制与未完成

- 本轮接通的是可审计执行管道，不代表用户原有 Python 三轮交易规则已被自动推断或重写。
- 示例/测试脚本三轮均返回 unknown，仅验证管道和拒绝未来数据能力，不代表策略有效。
- 真实 A 股授权历史数据、同日因子快照、四套策略真实样本外有效性、浏览器/真机 UI 对照和生产验收仍未完成。
- 不执行真实自动下单，不把纸面研究结果称为实盘收益。
