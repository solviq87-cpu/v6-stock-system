# V6 参考图首页真实数据联动修改报告

日期：2026-11-05
页面：`public/reference-dashboard.html`

## 本轮代码改动

1. 将参考图首页由纯静态占位内容改为读取现有服务端接口：
   - `GET /api/mobile-digest`：市场情绪、涨停家数、行情就绪/历史快照状态。
   - `GET /api/quant-picks?max=12`：候选数量、候选股票、价格、涨跌幅、评分及命中条件。
   - `GET /api/strategy/dashboard`：策略引擎市场评分和候选摘要。
   - `GET /api/kline?code=...&n=60`：点击排行榜股票后读取历史日K。
2. 排行榜数据在浏览器端进行文本转义；价格、OHLC、成交量等数值进行有限数值检查。
3. 依据真实K线生成SVG蜡烛图及MA5/MA10/MA20，并按K线成交量生成成交量柱。
4. 点击排行榜行可切换查看对应股票K线。
5. 诊断区改为展示接口返回的K线摘要，不生成买卖指令。
6. 四大指数当前没有接入经过核验的指数专用接口，页面明确显示“指数专用数据源未接入”，不伪造报价。
7. 没有候选或K线时明确显示无数据，不使用演示数字冒充真实行情。
