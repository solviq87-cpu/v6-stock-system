# V6 自动学习第十三阶段：严格研究 watch 自动预注册接力

## 目标与当前边界

第十二阶段已提供 `register-auto`：从已封存的**上一研究报告**提取训练期因子统计，生成有界的新影子候选，并在**新信号产生前**登记。此阶段把它纳入**运维显式开启**的 `watch` 研究循环，使自动学习进程在一个候选评价结束后能预先登记下一候选，随后等待新的冻结信号和5日成熟结果。

仅影子研究：不写四套正式策略、15因子正式权重、模拟盘账本、行情接口、电脑/手机主页或真实账户。研究进程是否在云端运行**尚未验收**。

## 新的可选命令

```sh
cd V6_BO
node scripts/factor-shadow-worker.js watch /private/manifest.json /private/shadow \
  --require-prereg --auto-prereg --interval 60000
```

- 必须明确提供 `watch` + `--require-prereg` + `--auto-prereg`，防止意外扩大已有 `once` 和非严格学习范围。单独的 `--auto-prereg` 会被拒绝。
- 研究循环的单次调用仍使用已存在的 `withResearchLock` 独占写入锁：扫描历史指纹和跨版本试验预算、创建唯一注册、等待未来信号、成熟后做样本外验证、封存报告，全程不允许两个并发研究写入者抢占一份档案。
- 没有**过去已经封存的研究模型/试验结果**时返回 `skipped-auto-prereg-needs-sealed-history`，不凭空创建训练证据或偷偷读取未成熟 H5 报告。首次研究启动需要经过既有受控研究引导、或已有合法历史档案。
- 如果当前血缘没有预注册，且没有衰减冷却、试验预算未耗尽，则仅从**冻结特征文件**和过去已封存的有效报告生成 `candidate-auto-preregistered`；本轮不读取对应 `reportFile`，不产生研究模型升级。
- 如果预注册已存在但尚无晚于注册时间的下一个冻结交易信号，返回 `skipped-awaiting-post-prereg-signals`；不打开旧 H5 观察、不把旧观察当作新样本外证据，也不重复登记。
- 当新增冻结信号及至少5个**全新、已成熟、样本外**测试日出现，沿用既有 `--require-prereg` 验证：先检查候选时点、源码/因子包指纹、父研究血缘、冻结前缀，再执行原有衰减冷却、训练/验证隔离、原始基准与逐因子反事实门禁。任何规则不通过不会修改正式资金和策略。
- 预算已耗尽时优先返回 `skipped-global-trial-budget-exhausted`；衰减冷却期间继续走原监控门禁，**不会以自动注册绕过冷却**。每次评估结束后，新血缘下一轮可以再注册，但不能复用已经见过的结果。

## 验证与风险

```sh
cd V6_BO
node --check scripts/factor-shadow-worker.js
node --test tests/factor-shadow-evolution.test.js
npm run check
npm test
```

新增端到端测试模拟：过去版本已合法封存、未来收益文件被故意移除时仍可成功注册；未有新冻结信号会安全等待且不重新读取旧结果；随后新增5日成熟观察后按事前候选验证；无历史记录、未启用严格模式、重复标志均拒绝产生虚假研究进展。

`watch` 是需要**人工启动并授权私有数据目录**的本地/受控进程入口，不会因为本次 GitHub 合并就在国内云端自启动，不采集未授权实时行情，也不是收益承诺。本地文件时间戳和SHA无法抵御具备全部磁盘与时钟权限的恶意操作者，仍需外部可信存证、独立备份和真实A股前瞻验收。回滚本PR合并提交，保留不可覆盖的私有研究历史。
