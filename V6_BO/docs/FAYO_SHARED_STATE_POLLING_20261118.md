# FAYO 同源状态刷新与行情时效边界

基线：`dev@294fea637df904ad0a1da1b87534fb052d22b48c`。本轮仅调整前端页面读取间隔、失败反馈和缓存/撤权安全，不修改后台采集、交易、模拟账户或发布流程。

可见页面每 5 秒只读 GET `/api/state`，慢请求单飞；隐藏时暂停，恢复可见立即读取；撤权、退出后停止计时器并阻止迟到响应。普通刷新不触发服务端重新抓取东财/腾讯/财联社，也不会修改原始报价时间。股票仍需以供应商报价时点和实际交易日判断新鲜度。

身份失败、角色降级时旧浏览器缓存不能回填上一账户数据。服务器配对提供的 `ztReviewPool` 和 `ztReviewPoolMeta` 不能分开复活。通过既有浏览器和 `fayo-polling.test.js`、`fayo-client.test.js` 全部专项与全量回归后才能合并。

特别说明：5 秒是网页**读取共享快照**间隔，不是行情源刷新间隔，不代表涨停/跌停自动更新或公网部署成功。
