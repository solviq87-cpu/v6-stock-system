## 本轮范围与边界

1. 新闻追加链按信号的原触发时刻选取当时本机已经记录的版本，以 `recordedAt` 防止晚导入
   伪装为当时已知。冻结来源、链接、版本与正文 hash、来源原时点和本地记录时点；同股关联
   只表示研究上下文，不认证利好、利空或关键词因果。摘要、撤稿、未知和容量限制仍显示缺失。
   旧信号不回填，不因后来修订或撤稿改写字节或 ID。
2. 新闻当前投影必须随修订跨情绪类别更新，旧利好不能在利空修订后继续提供支持。
   有界缓存须检测已有文件变化，缓存内容验证时点与当次引用验证明确区分；损坏不授予支持。
3. 自动模拟成交取同一完整原行的价格、量、前收盘价、名称和状态，不借另一旧行补执行字段。
   完整新鲜缓存行优先，否则使用完整新鲜列表原行；price-only 旧缓存仍可作为估值标记。
   成交决定使用的报价传至账户提交，缺执行证据时拒绝，失败按账户恢复，通知仅在成功后生成。
   保留现有缺状态默认政策，但来源证据明确记录 `defaulted`；公开适配器没有提供的停牌状态
   不能被表述为已认证。字段专属时点仍可能为 null，同一 wire row 不证明交易所同时性。
4. 共享治理门禁记录该次实际使用的融合值、有效门槛、豁免、D5、EV、额度/冷却前状态及结果，
   不为采证重复求值或改变分数、阈值、顺序和配额。治理实际时刻可以晚于原信号触发时刻，
   两者分别保存，不能倒写成触发时已知。占位通过不等于最终送达，后续回滚不改冻结决定。
5. 叠加 PR 的 `fix/**` 目标分支纳入原 CI 门禁，避免追加修复分支没有实际回归检查。

13 类生产者的 `conditionCoverage` 继续保持 partial。新增新闻与治理留痕不代表已展开
所有嵌套助手、模块额度、重复提醒或最终发送判断，也不认证收益和来源真实性。
