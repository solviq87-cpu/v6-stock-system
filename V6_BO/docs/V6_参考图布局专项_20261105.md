# V6 参考图布局专项开发记录

日期：2026-11-05

## 本轮交付

新增 `public/reference-dashboard.html` 与 `public/assets/v6-reference-dashboard.css`、`public/assets/v6-reference-dashboard.js`，作为独立的双端参考图布局页面。原有首页及手机 `/m` 页面、业务 JS、策略逻辑、账户权限和 API 未被替换。

### 桌面端布局
- 固定 64px 顶栏、208px 左侧功能栏。
- 主内容区按参考图分为六张指数/情绪/环境卡片。
- 第二行按四列展示 AI 综合选股、四策略信号、风控概览、策略表现。
- 下方按约 2.1:1 比例展示排行榜与右侧 K 线/AI 诊断。

### 手机端布局
- 移动顶部品牌区与横向主导航。
- 三列指数卡片；第二行情绪、环境、风险提示。
- AI 综合信号、横向可滚动排行榜。
- K 线与 AI 诊断在较宽手机视口并排，小屏自动改为纵向。
- 固定七项底部导航，并考虑 iOS safe-area。

## 数据真实性

该页面明确标记为“参考图布局预览”。指数、策略数量、风险指标、排行榜及 K 线均显示等待真实接口数据的状态，不复制参考图中的演示价格、涨跌幅或收益，不会将占位数据伪装成真实行情。

页面入口：`/reference-dashboard.html`。桌面端主系统快捷导航增加“参考图界面”入口。卡片导航链接指向现有 V6 业务页面或锚点。

## 验证

- `node --check public/assets/v6-reference-dashboard.js`：通过。
- `npm run check`：通过。
- `node --test tests/reference-dashboard-layout.test.js`：6/6 通过。
- HTTP `GET /reference-dashboard.html`：200，返回 7,592 字节页面。
- HTML 解析：`reference-dashboard.html`、`index.html`、`mobile.html` 均通过 Python HTMLParser。
- 浏览器自动截图：本环境 Chromium/Playwright 导航被执行环境策略阻止，未取得本轮浏览器截图；因此不宣称像素级验收通过。

## 与参考图仍存在的差异/限制

1. 当前为独立布局预览页，行情与排行榜尚未绑定实际 API，故以“等待数据”占位；不是已完成真实数据联动的生产首页。
2. 字体渲染、图标形态、K 线绘制、卡片细节仍可能因浏览器、设备 DPR 和系统字体产生差异。
3. 需要在用户实际 iOS/Android 与桌面浏览器上进行截图叠图对照，才能完成像素级验收。
4. 现有业务页面继续保留，未删除原模块。后续应将真实 API 数据映射接入该布局，再决定是否替换默认首页。
