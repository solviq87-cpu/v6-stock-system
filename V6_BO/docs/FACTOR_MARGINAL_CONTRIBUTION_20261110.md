# V6 自主学习第九阶段：逐因子调权反事实边际贡献

## 发现的问题

上一阶段已经加入训练期因子秩相关与共线性抑制，且研究模型整体必须经过训练/验证/新鲜保留集/原始基准三版本比较。然而，“新组合整体更好”不能证明**每一个因子权重调整**都对最终选股排序有独立增益，某个调权可能被其他更强的调权掩盖。

此阶段只处理影子研究模型每次提出的因子调权，不创建新生产因子、不改变已发布15因子包、四套核心策略、模拟盘、行情渠道或双端UI。

## 方法（影子研究，非真实绩效）

- 研究候选在查看验证/保留集之前，仍只根据历史训练期冻结证据与现有可靠性/冗余规则提出权重；本批**绝不根据样本外数据回头修改某个因子的候选权重**。
- 对每个与已接受影子权重不相等的因子，在其余所有候选因子权重不变时，只把这一项临时恢复为已接受研究权重，构成明确的**单项调权撤销反事实**。比较候选与这一反事实在**同一个冻结横截面和同一个成熟后5日收益**上的综合 Spearman IC。
- 分别记录训练集（至少15日）、已隔离验证集（至少5日）、**新增未碰过的样本外保留集**（至少5日）。如有历史衰减冷却恢复，则保留集只取 `recoveryDay` 之后的额外新日；不拿冷却恢复样本作为晋级证据。
- 每项调权输出 `acceptedWeight` / `proposedWeight`，训练/验证/保留集的可比日数、平均IC差、前后半段IC差、候选胜出/落后比例及最差单日差。平均改进大于0.002、≥60%有效日真正改善，且前后半段不明显恶化时记 `supported-unverified`；否则明确记 `increment-unconfirmed`，不得宣称独立新增预测能力。
- 若某项改变同时在验证集和新增保留集上**平均IC损失不小于0.01、至少60%的日落后、前后半段均损失至少0.002**，记录 `harmful-adjustment`，阻止本次影子模型晋级。如果任一反事实无法在规定样本下比较（缺失/平坦结果/天数不足），记录 `incomparable-evidence` 并拒绝晋级；不把未得到的日IC当0。
- 其余现有门禁仍适用：因子块状稳定性、权重边界、跨股/持有期去重、三版本原始基准比较、市场冲击暂停、衰减报警及双五日冷却恢复。

## 解释边界

这衡量的是**在其他候选权重已经确定的条件下，一项权重变化对组合IC的边际影响**，不是回归意义上完全去除了其他因子、行业、市值和市场风格，也不是现实可成交净收益或因果独立性证明。因此与训练期共线性诊断互补，而不是相互取代。

对某个因子没有证实额外增量，目前会保留可审计的 `increment-unconfirmed` 状态，不自动删除它；只用验证集+新鲜保留集均明显有害的结果阻止晋级。这样避免对既有原四策略/15因子基线形成无依据的负优化。
