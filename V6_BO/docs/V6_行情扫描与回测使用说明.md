# V6 行情扫描与研究回测（第二十六批）

新增独立命令行工具，避免改动既有生产 HTTP 服务与账户台账。

```bash
node tools/strategy-cli.js scan examples/strategy-demo.json
node tools/strategy-cli.js backtest examples/strategy-demo.json
node tests/feed-scan-backtest.test.js
```

输入 `stocks[]`：每只股票 `symbol`、`market`、`bars[]`（按日期升序的 open/high/low/close/volume）、`feed.source`（eastmoney/tonghuashun/akshare/simulated/imported）与 `feed.timestamp`（Unix 毫秒）。扫描模式可提供 `now`、`maxAgeMs`、`requireReal`。

**重要**：当前没有接入外部行情采集。`feed.source` 是调用方声明的标签，不能单凭标签证明数据真实；真实数据需要后续增加可信适配器、签名/来源审计。模拟数据明确标记。

回测只是基础无未来函数流程：第 d 日收盘筛选、第 d+1 日开盘买入并收盘卖出，估算双边手续费与滑点。未模拟涨跌停不可成交、真实委托、复权、分红、退市、成分股幸存者偏差，**不得据此推断实际收益**。现有连板识别也只是涨幅近似，不等同交易所官方涨停状态。
