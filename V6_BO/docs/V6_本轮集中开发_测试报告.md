# V6 集中开发：真实 HTTP 云鉴权修复与多模块回归

## 本次修复的真实缺陷
在 QD_CLOUD=1 模式下，正式服务外层数据门禁只从 URL 和 JSON 请求体取令牌，**没有使用前端已经发送的 Authorization: Bearer 令牌**，因此开发者持有效令牌调用研究 API 仍可能被门禁拒绝。现已统一使用 `req.__tok`（该字段在进入门禁前已解析 Bearer、URL 与请求体）。

## 真实 HTTP 验收
新增 `tests/research-live-http-isolated.test.js`，在临时目录复制运行所需代码，生成**临时测试密码哈希**，启动真实 `server.js`，设置 `QD_CLOUD=1` 并通过 127.0.0.1 发真实 HTTP 请求。验证匿名请求拒绝、开发者密码登录、Bearer 访问能力接口、上传选股/回测、上传数据供应商冒充拒绝、超大请求拒绝和空磁盘缓存拒绝。测试结束删除临时目录；不接触用户现有账户与持仓。
