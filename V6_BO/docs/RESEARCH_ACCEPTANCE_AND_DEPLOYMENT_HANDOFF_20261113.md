### 已接入的操作入口

`/research.html`提供个股采集、独立研究证据和板块选择。`GET /api/research/public-sectors`读取已存目录、选择和结果，`POST /api/research/public-sectors`采集目录或提交明确选择；两种方法均要求编辑者身份并返回`Cache-Control: no-store`。选择身份由`category`（`industry`或`concept`）及目录中的`BK`代码共同确定，显式选择1至6项，不默认挑选所谓最佳板块；选择持久化，后续采集沿用。真实同日且满足日历/成员/报价门禁的观察才能进入daily历史；跨日观察仍可展示当前成员重叠，不回填为旧日daily。

固定影子种子的操作从`V6_BO`执行：

```sh
node scripts/factor-shadow-worker.js register-seed /private/captures /private/models /private/seed.json
```

`/private/seed.json`为0600，捕获目录与模型目录为0700，二者不能重合或嵌套。配置示例：

```json
{
  "schemaVersion": 1,
  "mode": "v6-fixed-shadow-seed-config-v1",
  "researchOnly": true,
  "canTrade": false,
  "seedPolicy": "pack-order-alternating-two-percent-v1",
  "factorIds": ["sector_heat", "leader_strength"]
}
```

这只是固定选择的演示，不认定这两个因子或该种子最好。注册读取真实`registeredAt`之前已经冻结的特征，按固定规则一次性登记初始候选，不读取H5结果挑种子；已有试验血缘不能清空重置或重复登记来规避预算。未来表现成熟后才可评价，登记成功不改变生产权重。

自动观察默认关闭。仅在唯一主节点设置`V6_AUTO_STOCK_OBSERVATIONS=1`后，服务端monitor的tick才自动处理持续观察与目标日复访；副本不能同时启用真实通知和同一主调度。CLI可显式运行：

```sh
npm run research:stock -- watch /private/stock-observation-config.json
```

私有配置结构参照`config/stock-observation-monitor.example.json`，其中已包含观察、记忆、证据、价格事件、复访、持续观察和公开板块目录。CLI watch只在运行它的进程和开发环境存活期间有效，不能描述成已在指定主机提供24小时服务。
