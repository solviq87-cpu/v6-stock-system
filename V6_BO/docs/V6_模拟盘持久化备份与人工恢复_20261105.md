# V6 模拟盘账户备份与显式恢复

## 本轮新增功能
- 每次成功更新模拟账户版本前，将经过完整性验证的旧账户原子写入 `<账户文件>.bak`。
- 更新必须连续递增版本号，且保持配置与历史行情只追加约束；损坏的当前账户拒绝覆盖。
- 备份及账户目标禁止符号链接或非普通文件；临时文件以独占方式创建，文件写入后执行 fsync 与原子替换。
- 故障时提供显式检查和人工恢复，**不会静默回退**，恢复后需要重新导入行情推进账户版本。

## 操作
```bash
node scripts/paper-recover.js ./data/paper-account.json --check
node scripts/paper-recover.js ./data/paper-account.json --restore
```
仅在当前账户损坏或丢失、且备份通过哈希校验时允许恢复。若当前账户有效，拒绝旧版覆盖。受损文件在恢复时被重命名为 `.corrupt.<随机后缀>`，保留供调查。

## 限制
本地文件 SHA256 是意外损坏检测，不是防恶意篡改的密码学认证；备份仅保存上一版本，不能替代异地多版本灾备。模拟盘不连接券商，不执行真实交易；未完成生产部署、真实行情与长期连续运行验收。
