## 已实现与入口

在完整后端 `/research.html` 的“按代码采集并记住K线”中，沿用“采集并研究”和“读取已存历史”，新增同一股票的研究详情。沿用原有鉴权、数据源预算、归档与真实采集；详情本身不另发请求。

| 功能 | 本批实际行为 | 边界 |
| --- | --- | --- |
| 统一证据卡 | 日K、价格形态、日历、冻结上下文及原判断证据同屏，展示原时点/接收时点及哈希引用 | 缺失时间保留未知；日K不升级为实时可交易报价 |
| 判断变化时间线 | 从现有不可变假设/结果/修订档案投影，显示目标日、判断变化、新增/消失形态、首次结果及后续修订次数 | 复用原始日K C/O研究协议；不是新建通用交易信号账本。不同目标日差异不声称有因果关系 |
| 观察与复访 | 区分等待目标日、到期未获证据、已有首次评价；列出数据缺口和下次复访时间 | 没拿到结果不能算失败/成功，不改变现有调度及自动推送 |
| 条件分歧 | 单股36规则显示支持、反对、缺失及原有失效条件；四体系对照另增可读解释 | 八字维度pass只代表有评分证据，不转成看多票；评分不相加、不改排名 |
| 筛选过程 | 原有两条扫描器返回逐步数量、首次淘汰原因及最多5个样本；网页扫描结果直接展示 | 只对本次输入池；质量→风险→策略→原有资格。缺少判定单列unknown，不为凑数放宽条件 |
| 板块背景 | 同股票、同日并具备有效时点时才展示已存板块数值；真实0保留 | 缺少足够证据时个股角色/题材阶段保持未知，不凭涨幅宣布龙头 |
| 研究成绩单 | 展示既有冻结日K实验的评价数、独立目标日、匹配频率、Brier及样本门槛 | 不是四体系净收益排名、实盘收益或涨停概率 |
| 诊断与续接 | 汇总行情观察、档案引用、记忆、冻结判断和复访阶段；点击生成不超过4000字符的只读摘要 | 不含令牌、Webhook、来源URL查询参数；不调用模型，不改变平台上下文额度 |

历史时间线最多展示50条，保留总数与截断提示，原档案不删除。展示生成不写入任何研究、账户或交易记录。价格研究模块新增返回字段使源码指纹变化；旧假设保留原指纹，规则ID及统计计算未改，旧档按原哈希验证。

本批还修复相关页面边界：返回股票/明确来源与请求不符时拒绝展示；切换代码、令牌、输入及离线/离页清空研究详情；四体系请求有30秒上限、取消及迟到响应隔离。所有新内容用文本节点呈现，输入的HTML不执行。旧页面原有失败记录与旧测试保留；切股用例改为返回正确新股票，另由新校验拒绝错股。

## 继续核查其他缺口后的取舍

| 候选 | 本轮评估与处理 |

| 成长财务、现金流、相对强弱 | V6已有财务来源适配与36规则编译入口；本批直接消费既有条件，不复制一组同义策略。缺财报发布时点的结论仍未知 |
| 持仓防守、新闻修订、通知回执 | V6已有风险中心、持仓观察和私密发送/回执链；保留入口与权限。本轮按用户安排暂缓飞书现场连接，不把新详情当作送达验收 |
| 自动调权、多模型辩论 | 不接入默认生产调权或额外收费API；原影子验证与独立四体系保留。新增解释只陈述实际条件 |
| 全自动事件预期差/题材阶段/龙头识别 | 还需可靠的事件、财报可得时点与连续题材证据；仅有提示模板不能验证。当前以明确未知替代猜测，未宣称完成 |
| 原生Excel/OCR/跨市场个股 | 当前已有#213文本/CSV/TSV导入；新增解析或市场必须先解决证券身份和时区/日历/币种。此批不增加有误识别风险的自动写持仓入口 |
| 聊天滚动压缩 | 借鉴为确定性续接摘要；未接聊天模型或自动摘要存储，原始历史继续保留 |

这些取舍基于实际数据和现有模块；16项研究候选不等于16个全部缺失或已经上线的功能。
