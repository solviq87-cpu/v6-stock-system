# 全部候选直达与详细复盘 · 2026-11-17

## 问题与改变
原机会页默认只显示量化池；量化盘后没有冻结缓存时返回空，遮蔽其他已有候选。复盘和接力藏在多层导航，资产中的人工执行记录又被误认作市场复盘。

默认汇总有权限的全部既有池，股票按代码去重，保留逐池证据；报价来自同一完整源记录，不拼接价格与日期。即时展示 state，再异步加载远端池；失败保留已取得结果及错误信息。远端读取间隔60秒，展示上限及接口范围可查。盘中自动汇总不调用可能发送通知的旧洗盘扫描。

今日复盘使用 state.review，独立于私密 manual-loop。主线与梯队只统计报告样本，不杜撰全市场炸板率/晋级率。板块角色沿用 state.ztBySector，核对原始日期；次日计划保留原始价位、依据、风险、确认与失效条件，并检查生成日期和展示适用日期。详细接力卡区分封单/成交额与封单/流通市值，模型值不标为已验证胜率。缺失值不转零。
