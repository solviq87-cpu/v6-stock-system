# 学习运行检查 · 2026-11-14

续接[本地模型研究闭环](LOCAL_LEARNING_EVOLUTION_20261114.md)，在原研究页“学习闭环与回验”卡中增加两个手动动作：

| 操作 | 实际行为 |
|---|---|
| 检查运行条件 | 零写入、零网络的研究配置与当前输入预览；另列上次已校验记录 |
| 检查本地模型 | 相同预览，额外读取本机 Ollama `/api/tags`，核对模型名与固定摘要 |

页面打开不自动请求，检查不启动采集、推理、训练或持续进程。模型摘要匹配、输入可进入研究流程、研究版本已生成、进程仍在线是不同事实；本功能只证明它实际检查的部分。原“读取学习状态”“补验一批”和原互斥保留。

## 配置与命令

既有 `config/factor-research-agent.example.json` 提供研究配置结构。将真实配置保存在仓库外私有普通文件中（0600，最大64KiB）；无符号链接、公开目录或输出目录重叠。真实输入需要保持原来源、时点与因果性契约。配置不会自行生成输入或补造历史。

```sh
export V6_FACTOR_AGENT_CONFIG_FILE=/absolute/private/agent-config.json
export V6_FACTOR_AGENT_DIR=/absolute/private/agent-memory
# 两者的记忆目录必须与配置里的 outputDir 完全对应。
npm run research:learning:status
npm run research:learning:status -- --probe-model
```

`--probe-model` 仅在已设置 `V6_LOCAL_LEARNING_MODEL`、`V6_LOCAL_LEARNING_DIGEST` 后探测；端点用原 `V6_LOCAL_LEARNING_ENDPOINT`，默认 `http://127.0.0.1:11434`。接受固定64位小写摘要或 `sha256:` 前缀，报告统一输出64位摘要。仅允许带端口的字面回环HTTP地址 `127.0.0.1` / `[::1]`，不接受远程域名、凭据或查询参数；5秒总期限、响应最多64KiB，不跟随跳转、不发送聊天请求。

未启用本地模型时明确显示“未启用”，原确定性研究方式仍可预览。模型检查结果不持久化，后续普通读取重新显示“尚未检查”，避免把旧连接结果冒充当前结果。启用持续研究仍使用既有 `research:agent watch ... --apply` 及独立托管方式，本功能不创建新的调度器。

CLI输出同一份白名单JSON，退出码为：0表示可进入研究流程，2表示未配置/等数据/等模型检查，1表示阻断或请求无效。进程退出0不证明H5、预注册、独立验证、研究晋级或获利门禁全部通过。

## 接口与状态口径

- `GET /api/research/learning-runtime` 不接受查询参数或请求数据。
- `POST /api/research/learning-runtime` 仅接受 `{ "probeModel": true }`；请求最多256字节。客户端不能提供配置路径、端点、模型、命令或凭据字段。
- 使用原生会话/设备台账验证编辑者Bearer；查询或请求数据中的token不能授权。所有响应，包括前置登录门禁拒绝，设置 `Cache-Control: no-store`。原全局匿名登录门禁可能先返回HTTP200的 `locked` JSON；进入本接口后的身份拒绝返回403，页面两者都清理。
- 检查在独立worker线程执行，单次15秒、192MiB堆限制，同进程仅一项检查在途；主服务仍能响应其他请求。忙碌、错误或超时只给泛化提示，不返回私有路径、端点、提示词、原始输入或异常。

报告分为 `configuration`、`model`、`current` 和 `lastRun`。当前预览复用 `runAgent(apply:false)`，不调用研究执行或打开H5收益答案；历史记忆使用原哈希链验证。记忆目录不匹配、损坏或尚未核查的失败保持阻断。当前条件缺数与上次成功可以同时成立；未知数值保持null，不补零。重复状态另核对当前来源条件，不以旧成功代替当前条件。

`overall` 的主要状态为未配置、受阻、需要数据、等待模型检查、可进入研究流程。后者仅代表预检层可继续，不绕过原未来独立样本和试验预算。`lastRun` 永远标注“上次记录”，没有心跳依据时不声称后台仍在运行。

页面换身份、撤权、隐藏、离线或离开时清理私有状态，跨动作的迟到响应不能覆盖新状态。运行预检与原回验统计分区；中止只读预检不会取消可能仍在进行的旧补验。桌面当前条件/模型两列，窄屏单列，控件最小44px；两张锁定主页和原研究政策文件未改。
