# V6 第54批：行情数据中心（外部历史行情接入与可靠持久化）

## 开发范围
- 新增 `src/core/market-data-center.js`：HTTPS 历史行情抓取、超时与大小限制、来源及交易日校验、历史只追加约束、崩溃安全原子写入、失败保留上一份有效数据、同步状态。
- 新增 `scripts/market-data-sync.js`：可单次执行或通过 `V6_MARKET_SYNC_INTERVAL_MS` 设定至少一分钟的自动同步；不提供交易指令。
- 新增 `tests/market-data-center-e2e.test.js`：6 项真实执行的行为测试，包含与已有研究/模拟账户模块联动。

## 使用
数据供应方需提供符合 V6 `historical-validation.js` 结构的 JSON：`source: imported`、`provider`、`datasetId`、`asOf`、`stocks[].bars[]`，且必须含交易日期、OHLCV；不得以本模块生成缺失价格。

```sh
node scripts/market-data-sync.js 'https://your-provider.example/api/history' ./data/a-share-history.json your-provider dataset-2026
V6_MARKET_SYNC_INTERVAL_MS=60000 node scripts/market-data-sync.js 'https://your-provider.example/api/history' ./data/a-share-history.json your-provider dataset-2026
node scripts/paper-monitor.js ./data/paper-account.json ./data/a-share-history.json
```

生产环境需由运营方配置可信供应商、权限与网络策略；不应将未审核的任意外部 URL 当成可信行情来源。数据同步不会将 `verifiedLive` 标记为真，也不包含真实下单接口。
