## 用户原始公式
```
H1:=MAX(DYNAINFO(3),DYNAINFO(5));
L1:=MIN(DYNAINFO(3),DYNAINFO(6));
P1:=H1-L1;
阻力:L1+P1*7/8,COLOR00DD00;

DRAWICON(LONGCROSS(支撑,现价,2),支撑*1.001,1);

```

## 可确定的计算结构
- 以DYNAINFO(3)昨收、DYNAINFO(5)日内高、DYNAINFO(6)日内低为上下界；实际字段映射须按目标行情源校验。
- 支撑 = L1 + (H1-L1)/16（区间6.25%处）；阻力 = L1 + 7(H1-L1)/8（87.5%处）。
- LONGCROSS的具体周期、方向与是否要求此前连续低于/高于，需要以通达信原平台复核；不能直接以“碰线买卖”解释。

## 关键风险和验证门槛
1. **未来函数/数据穿越**：逐时点计算必须仅使用当时已知的日内高低，严禁用全天最终极值回测早盘信号。
2. **价格字段一致性**：昨收、最高、最低、现价需来自同一证券、交易日、复权口径；停牌、集合竞价、零成交和缺失时不产生信号。
3. **动态漂移**：盘中高低点扩展会移动支撑阻力；信号必须记录产生时的冻结阈值和原始报价时点，避免事后重绘误判。
4. **买卖方向**：向下穿越支撑可能是破位，不能把“-大胆买”直接当买入指令；阻力上穿亦非必然卖点。
5. **成本与有效性**：分牛熊震荡、不同波动率、涨跌停、跳空、成交量、滑点手续费做样本外评估，并与简单价格分位基线比较。
6. **与既有策略隔离**：先只读展示/研究信号，不写交易意图、账本或策略权重；验证通过才讨论接入。
