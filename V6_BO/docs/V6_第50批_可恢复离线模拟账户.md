# V6 第50批：可恢复、可增量更新的离线模拟账户

## 完成范围
- `src/core/paper-session.js`：可持久化的模拟账户会话；SHA-256 校验历史数据和模拟报告；不可更改既有K线和股票池；重复输入幂等；新增交易日触发完整重算；原子写入、临时文件清理和磁盘同步。
- `scripts/paper-session.js`：`init`、`append`、`status` 三个独立命令；原始历史数据限制30MB；禁止同文件覆盖。
- `tests/paper-session.test.js`：五项行为测试，覆盖保存恢复、追加、幂等、历史篡改、参数锁定和日期缺失。

## 使用方法
```bash
node scripts/paper-session.js init ./paper-account.json ./history-day1.json
node scripts/paper-session.js status ./paper-account.json
node scripts/paper-session.js append ./paper-account.json ./history-with-new-days.json
```
`append` 传入的是**保留全部旧K线并增加新交易日的完整历史数据**，不是只含新一天的片段。系统会拒绝删除或修改既有历史；模拟账户是离线历史回放，不是实时交易账户。
