# V6 统一主线：模拟盘新增开仓风控门禁

## 本轮完成
- `src/core/paper-replay.js` 新增可选 `maxDrawdownPausePct` 和 `maxDailyLossPausePct` 参数，严格限制为 (0,100] 的有限数字；默认 `null` 保持旧策略及旧模拟盘行为。
- 只依据前一日收盘净值、已记录的历史峰值和上一交易日净值计算门禁，避免使用当日收盘数据决定当日开仓。
- 达到门限时停止当日新增买单，已有持仓仍按原有止损及调仓规则处理；记录 `risk-paused` 审计事件及 `riskPauseDays` 指标。
- 测试增加两项：非法门限拒绝，以及无持仓时不伪造风险暂停或盈亏。
- 不连接券商，不执行真实下单；原有四套策略规则未改变。
