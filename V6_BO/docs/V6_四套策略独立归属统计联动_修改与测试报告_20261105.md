# V6 参考图首页：四套策略独立归属统计联动

日期：2026-11-05

## 本轮改动

1. 新增 `src/ui/reference-strategy-stats.js`：对候选池记录按显式 `strategy` / `strategyName` / `strategyKey` / `source` 字段做四套策略归属统计。
2. 新增只读接口 `GET /api/reference-strategy-stats`，读取现有 `S.candidatePool`，不触发全市场重算、不改变策略规则、不修改账户或交易状态。
3. 首页四套策略卡片改为读取该专用接口。只有明确归属的记录才计数；同一股票代码去重；无归属字段时显示“待独立统计”，不再从综合候选列表猜测数量。
4. 明确区分“候选归属数量”和“策略绩效/收益”：接口不声称提供胜率、收益率或回撤。
5. 更新页面脚本缓存版本，避免浏览器继续使用旧脚本。
