# V6 模型与策略研究

## 使用方法

在 v6_release 目录运行。普通扫描及原回测仅需原 Node 环境。模型命令另需 Python，实测版本是 Python 3.12.14、scikit-learn 1.8.0。可在隔离环境安装依赖，再用 V6_MODEL_PYTHON 指定解释器。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r tools/requirements-models.txt
V6_MODEL_PYTHON=.venv/bin/python node tools/research-runner.js models input.json > result.json
```

沿用 ledger JSON 格式。stocks 为股票数组，逐股提供 symbol、market、bars；每日必填 date（YYYY-MM-DD）、open、high、low、close、volume。股票池使用相同日历，每根交易日均需有效 OHLCV。source 可取 imported 或 simulated。splitDay 是首个评估交易日的零起始索引，end 可选。程序要求至少 61 根日线预热、至少 40 条训练记录、20 个不同训练信号日、至少 3 个留出交易日。此为计算门槛。实际研究宜用跨市场环境的更长历史。

## 结果怎么读

- latest 返回最后一天每个可研究标的的特征、模型分数及对照策略分数。ridge、extraTrees、histBoost 预测次日开盘到再次日开盘的价格回报，小数 0.01 表示模型估计 1%。这不是概率。负值也会进入相对排名。三个模型彼此独立训练，不自动选择过去表现最好的一个。
- 扫描结果的 researchFeatures 提供 5/20 日回报、跳过最近 5 日的 60 日动量、20 日收益波动率、相对前 20 日的量比、K 线实体、振幅和收盘位置。历史不足返回 null。特征可见不表示标的可交易，另看 tradable 与风险过滤。
- summaries 给出三个模型、动量、低波动及原 V6 排名在同一留出区间、初始资金和交易成本下的独立账本指标。动量按较高分排序，低波动按较低日收益波动率排序。默认仅做多、持有一个交易日，原有跌停续持及逐日估值生效。留出集不能反复用于选模型后再作为最终验证集。
- 可选 chinaValue 需要每根日线上与当日匹配的 marketCap（总市值）和 financials.ttmProfit（同币种的归母滚动年度净利润）、financials.publishedAt（含时区的实际披露时刻）。只使用该日北京时间 15:00 前公开的正利润；盘后公告最早下一交易日可用。当天技术与风险过滤后至少 10 个标的且市值完全覆盖，才按市值分位剔除最小约 30%，边界并列保留，然后按盈利收益率降序筛选。valueSignalDays 记录可产生候选的评估信号日数。数据不足则分数为空，没有可用信号日时不输出该组收益。该规则参考中国市场的研究，是股票池内的多头筛选，不复现论文的全市场多空因子。
- 训练标签为信号日后第 1 个与第 2 个开盘价之间的变动，要求对应日有成交。只纳入标签已经在 splitDay **之前**完整实现的样本；在训练集拟合标准化与模型参数。估值及价量数据必须由调用方提供点时快照，避免用今天的成分股、复权因子或重述利润回填过去。标签衡量价格变动，实际账本另计 T+1、受阻、滑点、税费。history 模拟标记和测试脚本中的合成股价不构成真实效果证据。

## 来源与适配

| 接入 | 用途与出处 |
|---|---|
| Ridge + StandardScaler | 建立带正则化的线性参照。[官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html) |
| ExtraTreesRegressor | 用随机树检验非线性因子组合。[官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.ExtraTreesRegressor.html) |
| HistGradientBoostingRegressor | 用浅层提升树检验非线性阈值；关闭随机提前停止，固定参数。[官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html) |
| 日线特征 | 参考 Microsoft Qlib 的归一化 K 线和滚动特征设计，V6 独立计算上述八项。[Qlib 实现](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py) |
| 动量对照 | 借鉴历史收益横截面排序，60/5 窗口为本项目设定，非论文原参数。[原始研究](https://doi.org/10.1111/j.1540-6261.1993.tb04702.x) |
| 中国市场价值对照 | 参考 Liu、Stambaugh、Yuan 对壳价值与盈利收益率的研究。[原始研究](https://www.nber.org/papers/w24458) |

## 验收范围及下一批

已验证导入格式、三种估计器真实训练和预测、同成本账本比较、截断未来数据、跨分割标签隔离、财报发布时间和 ST 风险隔离。缺少授权、含退市股票和历史成分的全市场点时数据；未检验真实 A 股样本外收益、行业暴露、因子容量及多市场周期稳定性。下一批应冻结数据版本和实验方案，按日期滚动分段评估，对照报告换手、行业偏离和成本敏感性，再决定哪些模型进入默认评分。新增模型仅通过本地研究命令调用，当前网页扫描接口只增加可解释特征。
