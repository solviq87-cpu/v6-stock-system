# V6 模拟盘账务时间戳严格校验续批报告

## 本轮修改
- `src/core/paper-account-reconciliation.js` 不再对流水时间戳使用 `Number()` 强制转换。
- 仅接受非负、安全整数型 JavaScript number；拒绝 null、空字符串、空白字符串、布尔值、小数、数字字符串及缺失值。
- 排序阶段采用同一严格规则，非法时间戳排在末尾并由校验明确拒绝，不会被隐式转换为 epoch 0。
- `tests/paper-account-reconciliation.test.js` 新增覆盖上述六类输入的回归测试，并更新原缺失时间戳断言。
