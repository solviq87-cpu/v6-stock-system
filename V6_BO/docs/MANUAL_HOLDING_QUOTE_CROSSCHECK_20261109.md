# V6 手动持仓报价双源差异核对 · 2026-11-09

## 目标与边界
现有本机私有持仓观察可根据用户输入成本/权重和15秒内声明来源报价，显示损失及集中度风险。本批新增**可选第二报价来源**，识别同一证券的两条报价是否显著冲突。
只在独立本机只读风险面板生效，不会修改模拟盘权威账本、原四套策略、交易风控、正式选股排名或真实/模拟资金。没有自动采集行情、真实推送或下单能力。

## 数据格式
在已有 `manual-holding-watch` 私有JSON中可选增加：

```json
{
  "crossCheckQuotes": [
    {
      "symbol": "600001",
      "price": 9.25,
      "quoteAt": 1794205800000,
      "quoteSource": "second-declared-provider"
    }
  ]
}
```

本示例价格和时间都是协议演示，不代表当前行情。原 `quotes` 是主来源，`crossCheckQuotes` 是可选来源；每个证券至多一条第二来源价格，总数不超过100。来源和价格必须**对应同一行**，不能借用抓取时间、其他股票或其他供应商的时间。读取时刻与报价都以北京时间交易日匹配并处于15秒有效窗口，未来、过期、模拟、代理、备份和停牌行不能参与比较。

## 处理原则
- 没有第二来源：主来源仍按照旧时效规则做只读未核验的成本变化观察，但显示“未提供双源核对”。
- 两个来源完全相同（大小写不敏感）、任一来源无效：不假装完成独立核验，保留原主源时效门禁；如果主源也无效，浮亏为未知。
- 两个来源标签不同且都有效，按 `10000 * abs(p1-p2) / max(p1,p2)` 计算对称价格差异（基点）。
- 差异不超过**50基点（0.5%）**：显示“声明数据相符，未核实”，可按原主源价格做只读浮亏观察；**不能认证行情真实性或商业转发许可**。
- 差异超过50基点：`crossCheckStatus=price-conflict`、`quoteStatus=source-conflict`，该证券本次价格、原时点、来源、基于成本浮亏均清空为未知，不触发亏损阈值报警；生成独立的“跨源报价冲突”观察提示，提醒核对。用户明确申报的仓位集中度风险仍保留。
- 第二来源不能作为主来源不可用时的静默替代；不得因为另一来源价格更好看而挑选任一价格。50基点仅为保守防误报门槛，并未经过市场阶段、证券类别和实际供应商质量校准。

## 部署与隐私
- 本次纯离线数据协议，不调用新的外部网络或发往第三方。
- `/api/paper/holding-risks` 仍是受本机访问令牌保护的只读GET；仅绑定回环地址。
- 两个来源自报标签不证明实际不同的数据供应商；即便价格接近，也没有完成交易所、授权和真实盘中连续采集验证。
- 不在GitHub保存个人持仓/账号/报价私有输入。相同JSON文件重读时重新计算，状态不跨文件改写继承。
