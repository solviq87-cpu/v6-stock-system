# 冻结预测与模型前向评测

本轮从已合并#224的`dev@aca2657fe713b7996f14e18f00545e3ecb242a7a`续接。上一批八项研究功能和24来源对照保留；本轮把Chronos/Moirai/Kronos等对照中可借鉴的“固定输入、分位数、简单基线、匹配样本”落实为研究页可用链路，没有安装模型、下载权重或调用模型API。

## 实际使用

完整后端`/research.html`→“研究记录与复盘”，读取或选择一个研究版本，展开“模型预测与前向评测”：

1. 导出该版本的闭合日K、日历、来源、输入指纹及**空结果模板**。模板预测值和生成时间为`null`，不能直接封存。
2. 由实际预测运行填写模型固定版本、实际生成时点和1/5/20/60交易日中的一个或多个结果，选择结果JSON。允许点值及可选分位数；没有分位数不会补出区间。
3. 明确点击“封存所选预测”。服务端校验证券/来源/观察日期/输入指纹、实际接收时间、目标日、训练截止期和分位数顺序。须在该观察日后的**下一交易日开盘前**收到，晚到拒绝，不能用客户端声称的旧时间倒填预测。
4. 原有采集后续获得同来源、同未复权口径的闭合日K时，在“策略成绩”查看预测误差、基线、区间及配对结果。未到15:10归入待到期，已到期没有价格归入缺后续行情；零成交或不能核对输入不计为成功样本。

没有自动调用模型的按钮，不执行上传代码，不将预测K线写入原始行情库、模拟账户、交易信号或通知。导入版本、权重哈希、训练截止期、随机种子、温度/采样及耗时均为声明信息，本系统未独立验证其真实性或模型执行；未知保持未知。

## 输入和输出契约

输入绑定原不可变run ID、原始观察哈希、证券、供应商、未复权/CNY、日K接收时点、显式交易日历及可核对的未来目标日，SHA256使用现有规范JSON排序计算。只导出截止时点已收到的闭合OHLCV，不带当前账户、持仓、成本、生产权重或其他股票资料。

JSON结果字段（结构示意，`null`必须由实际结果填写）：

```json
{
  "schemaVersion": 1,
  "inputFingerprint": "导出的完整64位指纹",
  "symbol": "导出的六位证券代码",
  "provider": "tencent",
  "originDate": "观察日YYYY-MM-DD",
  "generatedAt": null,
  "model": {
    "id": "M05",
    "revision": "实际模型固定版本",
    "weightsHash": null,
    "tokenizerRevision": null,
    "trainingCutoff": null,
    "seed": null,
    "temperature": null,
    "topP": null,
    "sampleCount": null
  },
  "forecasts": [{
    "horizon": 1,
    "targetDate": "模板给出的交易日",
    "point": null,
    "pointKind": "point",
    "quantiles": [{"level": 0.1, "value": null}, {"level": 0.9, "value": null}]

```

模型ID可用现有目录M01～M08或明确的自定义标识。固定版本必须填写；哈希、训练截止期和采样设置不可核实的保持未知。价格为非负有限CNY数值，零预测不是缺数；分位数水平严格递增且在(0,1)，值不能交叉。声明为中位数的点值须与提供的0.5分位数一致。训练截止期晚于输入观察日、未来生成时间、其他证券/来源、重复周期和错目标日均拒绝。文件最多60KB，HTTP操作最多64KiB。

## 如何看结果

- 点值误差使用首次实际收到的目标日闭合收盘价：绝对误差`|真实收盘−点预测|`；平均绝对误差MAE以元计。
- 前值基线始终预测输入最后收盘价。趋势基线用最多21根连续交易日的首尾对数变化率外推；历史缺口则不补趋势基线。
- 相对前值基线为`模型MAE / 前值基线MAE`；基线误差为零或没有样本时保持未知，不除零或宣称无限提升。
- 分位数损失为`max(q×(y−预测分位数), (q−1)×(y−预测分位数))`，分别计算后按提供水平取平均。不同分位数网格分组，不混作同一口径。
- 区间使用提供的最外两分位数；目标覆盖是两水平的差，不硬编码95%。同时展示区间宽度和损失，不能只用更宽区间提高覆盖就宣称更好；缺区间保持未知。
- 来源、周期、点值类型、模型固定版本/权重/tokenizer、训练截止期、种子及采样配置分别分组。各模型覆盖范围可能不同，不能按原始MAE跨股票池直接排名。
- “同输入配对”只取相同输入指纹、供应商、目标日和周期的交集，显示双方MAE与差值、匹配样本、信号日和股票数；不认证统计独立或收益。每个输入最多配16配置，整体最多256配对组合，超出明确提示，原记录仍保留。
- 同股同日同模型配置的重复导入不增加样本。完整显示总数、已成熟、待成熟、缺价、不可用、重复，以及不同股票/信号日/非重叠窗口；不足30成熟、10非重叠窗口、5只股票仍标样本不足。即使达到门槛也只有描述性结果，没有自动晋级或调权。
- 首次收到的闭合价格用于首次评价；后续价格修订单列，原价格和误差不被新版本覆盖。历史回放不能读取在该时点之后才接收的预测或价格。

这是**价格预测质量评价，不是可成交收益或盈利概率**。涨跌停、T+1、费用、滑点和仓位仍由原四策略与权威账本及上一批成本成绩单独处理。这里没有用价格MAE、情绪准确率或区间覆盖率替代投资结果。
