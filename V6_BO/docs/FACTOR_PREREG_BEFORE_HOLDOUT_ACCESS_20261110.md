# V6 自动学习：候选身份核验必须先于样本外结果读取（2026-11-10）

## 目标与边界

自动学习已有**研究沙盒专用**候选预注册与全局试验预算。旧 Worker 对于没有候选档案的严格模式会在读取收益前中止，但若已存在一个格式正确、SHA 也正确的**失效注册**（算法文件版本、冻结历史或父模型血缘不匹配），旧流程会先打开所有 `reportFile`，再进入核心模型的 `verifyPreregisteredCandidate`。这样虽然最终不会晋级，却仍提前接触保留集结果。

此外，`shadow-recovered` 恢复状态先前被误当作一般冷却对象，严格模式在没有新注册时也可能先读取远期报告。

## 调整

- 先读取**冻结特征文件**和只读私有模型/试验账本，核对全局试验额度（原有顺序）。
- 如果存在待使用的候选预注册，并已经出现它登记日期之后的首个冻结信号，则先核验注册报告指纹、当前算法签名、历史冻结前缀、模型/试验父血缘、预先注册权重及**注册时点必须早于首个新冻结信号**。校验通过才准读取远期价格结果文件。
- 无新增冻结信号时，不凭空生成虚拟未来证据；保留既有的无新训练窗口处理及核心审计。
- 冷却中（`paused-shadow-decay` / `paused-shadow-cooldown`）仍可按规则读取恢复监测结果；**已恢复**（`shadow-recovered`）不是冷却中的豁免条件，再试验必须事先注册。
- 核心 `evolveShadowFactors` 仍会根据实际成熟、去重后的5日保留集进行正式的第二次注册身份核验。预读取核验不是收益评价，不替代原本的门禁。

## 未解决的局限

私有文件的时间戳和 SHA 是本地研究证据，不构成可信第三方时间戳，也不能独立证明导入历史数据真的在过去生成。研究目录被整体丢弃后不能仅靠本地指纹证明试验没有重置；仍须离机完整备份、授权行情和前瞻样本核验。项目不接真实账户、不改变正式策略或模拟盘权重、不部署到外部主机。
