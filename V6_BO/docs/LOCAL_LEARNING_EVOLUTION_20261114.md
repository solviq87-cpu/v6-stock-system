# 学习回验与本地开源模型研究进化 · 2026-11-14

本批修复旧学习统计，并把可选本地模型接入原有前向研究闭环。研究页新增“学习闭环与回验”卡片；原“因子研究”“自适应报告”显示已记录的研究版本和模型身份。两张锁定主页不改。

## 实际闭环

1. 冻结原始信号、特征与数据身份，等待交易日结果成熟。
2. 仅从已封存的历史训练摘要提出候选。模型只能看到因子级统计，不接收账户、股票代码、价格文件、凭据或未来验证集。
3. 候选只包含已有因子的数值权重及一条标为假设的理由；每轮变动不超过原接受权重的8%，且限定在基础权重的0.5—1.5倍。
4. 先预注册，再等待注册之后产生的新信号与独立H5结果；继续使用原试验预算、隔离及前向验证门禁。达到原验收条件后才能生成新的研究版本；未通过则保留原研究版本。
5. 模型建议完全不变时，保存私有、带指纹的复核回执，不建立预注册或消耗新试验。相同封存来源、接受权重、固定模型配置与代码指纹复用该回执；新来源或配置触发新复核，回执损坏则停止。

这里的自主进化指研究参数和研究版本的受约束迭代。它不训练大模型本身的权重，不执行生成代码，不修改正式15因子基础权重，也不直接连接下单或通知。模型报错、超时、返回越界参数或摘要改变时停止，不静默换模型或伪装成功。未启用本地模型时，原确定性研究方式保留。

## 启用方式

运行环境自行安装 Ollama 并准备有明确许可的模型。程序不会自行下载模型，核心系统启动不依赖 Ollama。先使用原研究流程建立固定种子、真实冻结历史和已封存报告；没有这些证据时，模型不能补造训练历史。原前向链需要至少36个成熟H5信号日才能进入对应研究阶段。

在 `V6_BO/` 中运行原 worker，例如：

```sh
V6_LOCAL_LEARNING_MODEL=qwen3:0.6b \
V6_LOCAL_LEARNING_ENDPOINT=http://127.0.0.1:11434 \
V6_LOCAL_LEARNING_DIGEST=<本机已核对的64位模型摘要> \
npm run factor:shadow:watch -- /absolute/private/manifest.json /absolute/private/modeldir --require-prereg --auto-prereg --interval 900000
```

尖括号项必须替换为实际摘要。生产研究入口要求显式固定摘要，避免同名标签更新后误用旧复核。也可通过原 `factor:daily:cycle` / `research:agent` 运行，相关CLI和独占锁会等待异步推理结束；watch 不并发重入。

仅接受带端口的字面量回环HTTP地址 `127.0.0.1` / `[::1]`；禁止远程地址、凭据、查询参数。使用 Ollama 原生 `/api/tags` 和 `/api/chat`，无新SDK或付费接口。每次推理前后核对模型摘要，总期限30秒，输入/响应各64KiB，非流式JSON schema输出，本地再次校验。小模型在冷启动或机器繁忙时可能超过期限；部署机器的资源与模型质量仍须独立验证。

模型理由、复核、预注册及研究档案仅写仓库外私有目录。页面摘要只公开既有授权用户可读的状态、模型名/摘要、版本、下一步；不公开提示词、私有假设、文件路径或端点。

## 旧学习链路修复

- 缺失收益不再进入均值分母；历史回测、事后涨停样本与真实前瞻样本分开。小于10个有效样本时不再因跌停比例触发原惩罚分支。
- 次日回验必须命中交易日历中的下一交易日，具备完整正值OHLCV、已知价格口径与来源，并在收盘后取得；跨停牌/缺失日期的邻接K线不能冒充次日。默认日历范围为2026年，可用 `V6_TRADING_CALENDAR_FILE` 指定已核对日历；范围外保持未知。
- 旧结果保留在历史字段，未经新规则验证的结果不继续冒充有效学习证据；补验成功后才计入。事件结果缺失时仍可独立展示已有质量诊断，未知与观察到的零分开。
- 手动补验、定时学习和初始化共用运行互斥；统计变化同步清理标定缓存。启动重算不因无效旧数据直接调整旧策略阈值。
- `GET /api/learn-status` 只读；卡片手动“补验一批”通过编辑者Bearer权限的POST触发，限制1—60只股票并返回实际尝试、成功获取及新增结果。重复运行、写入失败、全部获取失败有明确回执，响应不缓存。
- 因子/自适应旧面板补充令牌变更清理、世代校验、取消与超时；上传文件读完后重新核对身份，迟到响应不能复活旧数据。浏览器取消不表示后台任务已取消，需再次读取服务器状态。

回验命中率和涨停事件不是可交易净收益，不包含完整成交约束、费用与滑点。此修复不能证明获利能力提升。

## 来源与真实运行证据

[来源与隔离模型实测记录](LOCAL_LEARNING_SOURCES_20261114.json)固定 Ollama、Qwen3、RD-Agent 官方来源；借鉴原生结构化输出及“假设—实验—评估—版本保留”方法，没有复制上游代码或安装其代理框架。Ollama软件为MIT；模型权重许可单独核对。

本环境隔离安装了官方 Ollama v0.40.16 的CPU运行文件，并下载 `qwen3:0.6b`（751.63M、Q4_K_M），核对发布包摘要、模型摘要及随模型返回的Apache-2.0许可。仅以合成的两因子封存摘要运行，未读取真实账户或行情。真实推理最终返回合法JSON并建议保持1.3/1.3原权重，程序接受“无需变更”；没有打开真实验证集或生成生产版本。冷启动/并行测试时曾超时，另有早期候选校验失败，均保留原版本；不把HTTP成功等同于候选通过。实测不是模型金融能力评测，也不是对真实市场自主学习已完成的宣称。
