# 36 种实验策略：现有观察链路与财务数据接入

基线：`3ef08a2c8704e5e4e511fc54ccd8a04b24fe3434`（PR #194 合并后）。增量修改，未删除功能、旧测试或历史文件；两张主页保持原字节。恢复可回退本批提交，原始观察档案采用原有追加式格式，不改写历史证据。

## 使用与行为变化

在现有 `/research.html` 输入六位股票代码，点击“采集并分析股票”。服务端使用现有受限观察任务、行情供应商预算与私有不可变档案，不需要先人工制作 JSON。保留原 JSON 导入、36项独立配置和历史研究入口。必须具有编辑权限；页面不自动轮询、不保存令牌、不下单、不通知。切换股票、文件、权限、离线或离开页面会清空旧结果并拒绝迟到响应。

`POST /api/research/strategy36/observe` 仅接受 symbol/provider/historyDays/config，64KB上限，历史27–500条，配置先校验再采集。默认120条。不可提交自定义URL、路径、生产参数或交易命令。既有55秒任务边界、忙碌拒绝与供应商限制继续有效，采集失败不回填虚构结果。

## 连接的数据及口径

- 原观察档案的未复权日线：严格交易日历连续性、OHLCV、同来源、原始已知时点检查。缺口不静默删除。收盘时刻只是覆盖期终点；本地15:10之后收齐数据不是供应商最终结算认证。技术指标沿用36规则实现，补充带宽比、前日弱收盘、前期突破回踩的固定研究假设。
- 个股资金：原响应哈希、同代码、人民币单位、连续5个交易日；0与未知分开。正流入天数为截至末日连续天数；供应商按订单大小估计，不表示真实机构身份。
- 相对强弱：20/60交易日个股收益减上证指数收益，严格同日期窗口。不是行业超额收益，也不是全市场基准。
- 东方财富F10财务：固定公开端点，按报告期与单季分别采集，每份最多12行、512KB，不作无限重试。端点结构参照 AKShare 原始实现：`https://github.com/akfamily/akshare/blob/main/akshare/stock/issue/stock_finance_sina.py`。只支持已核对沪深代码，其他证券缺财务仍可保留其他研究结果。
- 财务输出：报告期累计ROE、上年同报告期ROE、资产负债率、单季利润同比、单季营收同比、相邻季度利润同比增速之差。ROE不擅自年化。上年同期ROE容许550天的报告期年龄，否则120天门槛会系统性拒绝正确的同比证据；当前ROE仍保留原门槛。目录版本更新 `research36-20261113-v1-data1`，ROE策略 `1.1.0`。
- 单季接口缺公告日期和币种，必须关联同股票同报告期的完整财报响应；双原始哈希共同进入字段依据。公告/更新日期保留日精度，实际可得时间一律使用本次版本的采集时间。不得据当前下载回填历史公告日，后续重述不能污染早期回测。
- 现金流比率、自由现金流、筹码、竞价、龙虎榜、新闻情感等尚未核实的字段不伪造。全部36策略继续 experimental，canTrade=false、canNotify=false、预测概率null；“命中”仅表示给定证据满足研究条件。

## 仍需独立验收

36规则的数据覆盖不等于36种策略已获样本外验证。需要持续形成实际可得时点档案、退市与公司行为资料、独立样本外及市场分段验证，才可能讨论晋级。现有静态托管目标不能运行Node/Python后端，本批没有将静态页面成功等同完整系统上线。

本环境另一次完整联网观察返回 unavailable：历史日线未取得可归档结果，分析与交易均未生成。不能用财务子接口成功声称全采集链已实网通过。浏览器默认安装路径缺可执行文件，另以系统 Chromium/CI 验证；环境失败单独保留。
