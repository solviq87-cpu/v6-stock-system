# V6 开源策略与大盘—板块—个股联动扩展 · 2026-11-09

## 范围
保持原四套选股体系及既有15因子、候选观察池、模拟盘、权限和风控完全不改。新增**3条独立研究条件**与**5个逐股可计算的历史特征**。命中从历史日线计算，数据不满足时写明 `insufficient_data`，不虚构股票、行情、资金或上涨原因。

## 公开研究思路与独立实现
1. **唐奇安20日放量突破**：当日收盘突破*前20个完整交易日最高价*；当日成交量至少是前20日均量的1.4倍。当前K线不能参与“此前20日最高价”。参考公开通道突破研究：https://github.com/JamesRPowell/Donchain-Breakout 。不使用项目代码，也不沿用其绩效结论。
2. **窄幅蓄势后放量启动**：此前10日最高价与最低价区间/最低价≤8%；当日收盘突破此前10日最高价；当日成交量≥此前10日均量1.3倍。参考窗口因子和均量思路：https://github.com/quantopian/zipline/blob/master/zipline/pipeline/factors/basic.py 。8%与1.3倍为V6本地研究假设，不是来源项目的获验证阈值。
3. **大盘—板块—个股20日相对动量**：个股20个交易日涨幅≥5%；板块同区间涨幅超过境内主指数至少2个百分点；个股涨幅超过板块至少2个百分点。参考公开动量筛选思路：https://github.com/pmorissette/bt/blob/master/bt/algos.py 。V6必须同时提供同一交易日、完整且严格对齐的**21个历史收盘价**，才允许判定；没有指数或板块数据则未知，不把未知当零。
4. 研究风格与回测设计另参考 Qlib Alpha158 特征、Zipline Returns/Volume 思路：https://github.com/microsoft/qlib/blob/main/examples/benchmarks/README.md 。这里只借鉴可验证的设计思路，不复制项目文件。

## 五个有条件的研究特征
- `ret20`：个股20日涨跌幅（历史派生）。
- `vol20`：历史日收益波动率（历史派生）。
- `volume_ratio20`：当日成交量/此前20日均量。
- `donchian_gap20`：当日收盘与此前20日最高价的距离。
- `sector_excess20`：板块20日涨幅减境内指数20日涨幅；**缺同日指数/板块数据时必须是未知**。

前三条研究条件与原4套策略分离、只读，全部输出通过/未通过的具体条件。前两条都属于突破/量价族 `breakout-volume`，即使同时命中，也**不当作两项独立策略家族加权**；相对动量属 `market-sector-relative`。

## 历史联动数据协议（仅研究）
原有 `POST /api/research/complete-run` 里选填的 `market` 对象，可增加：

```json
{
  "factorContexts": {
    "600001": {
      "schemaVersion": 1,
      "source": "imported",
      "provider": "声明来源标识",
      "asOf": "2026-11-06",
      "market": {
        "id": "shanghai",
        "source": "声明来源标识",
        "bars": [{"date": "实际交易日", "close": 10.0}]
      },
      "sector": {
        "name": "实际板块名",
        "source": "声明来源标识",
        "bars": [{"date": "实际交易日", "close": 10.0}]
      }
    }
  }
}
```

其中 `market.bars`、`sector.bars` 各必须完整提供**21条真实、同日对齐的历史收盘记录**；上面仅为结构说明，并非足够可计算的示例。指数只支持上证、深证或创业板作为本批比较基准。A50 可作市场侧独立参考，不强行代替境内基准。上述 `source` 是导入者声明，**未由交易所独立核验**；缺数据不发明来源，也不会用一个股票的板块数据替代另一个股票。

## 个股界面与观察池
- `src/core/research-explanation-projection.js`：只有真实命中的研究条件才加入 `selection.rules`；原四套体系的命中原因和模拟账本不改。
- `public/assets/complete-workbench.js`：股票详情显示新的因子、同日大盘/板块/个股20日收益及来源可信度；股票理由继续区分“入选证据”与“上涨的可能相关因素”，不擅自确定上涨因果。
- 缺日期、异常OHLCV、ST/停牌、退市风险、无涨跌幅限制、零成交均阻止新研究信号；系统性急跌不会因短期亏损直接自动调参，但风控保持有效。
