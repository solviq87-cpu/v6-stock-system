# V6 模拟盘事务输入边界加固报告

日期：2026-11-05

## 本轮修改

1. 在事务协调器入口和事务日志读取路径统一执行订单、成交及交易日期校验。
2. 订单 ID、成交事件 ID 限定为安全字符集，避免日志身份字段包含路径分隔符或控制性格式。
3. 订单总量和单笔成交量必须为正整数且符合 A 股 100 股整手约束；单笔成交不得超过订单总量。
4. 成交价格必须为正有限数，费用必须为非负有限数。
5. 交易日期执行真实日历日期校验，拒绝如 2026-02-30 这样的伪日期。
6. 对历史事务日志执行相同的结构校验，避免仅凭可重算的哈希指纹接受语义非法数据。
7. 新增3项边界专项测试，覆盖超量成交、非法整手数量、安全标识符。

## 测试结果

- 模拟盘专项测试：40/40 通过。
- 全工程测试：537/537 通过，0失败、0跳过。
- 全量命令：`node --test tests/*.test.js`
- 本轮全量耗时：约34.1秒。

## 边界说明

本轮加固的是事务协调器的输入与日志验证。当前 HTTP 订单写入入口尚未全部迁移到该协调器；因此不能据此宣称所有在线订单入口均已获得统一事务保护。此功能仍是离线模拟盘，不连接券商，不产生真实交易。

UI 按用户要求停止修改。
