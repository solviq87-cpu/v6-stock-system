# V6 参考图首页刷新与K线竞态修复

日期：2026-11-05

## 本轮改动

1. 参考图首页新增手动刷新按钮，支持用户主动重新读取行情摘要、选股候选和策略看板。
2. 刷新期间按钮进入禁用状态并显示“刷新中”，避免连续点击造成重复请求；后台60秒自动刷新与手动刷新共用同一互斥状态。
3. 顶部数据状态增加最近一次成功刷新时间，三个接口分别显示连接状态；行情数据源不可用时不伪造数字。
4. 修复快速点击不同股票时，较早发出的K线请求可能晚返回并覆盖当前选中股票的问题。采用请求序号，只允许最新一次请求更新图表和诊断区。
5. 更新参考图页面 CSS/JS 缓存版本，避免客户端继续使用旧资源。
6. 新增3项专项测试：手动刷新可访问状态、K线请求竞态保护、窄屏刷新控件样式。
