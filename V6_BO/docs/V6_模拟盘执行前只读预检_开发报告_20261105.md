# V6 模拟盘执行前只读预检开发报告

日期：2026-11-05

## 本轮目标
在既有“策略信号 -> 模拟盘委托计划”之后增加独立的执行前检查层。该层只读取策略计划、同日行情快照和模拟账户摘要，不提交委托、不修改资金/持仓、不连接券商。

## 新增内容
- `src/core/paper-execution-preflight.js`：校验策略计划模式及数据指纹、行情快照日期与指纹、股票代码唯一性、停牌/不可交易/涨跌停标记、行情完整性与过期标记、计划参考价偏离、A股整手数量及现金预算。
- `scripts/paper-execution-preflight.js`：命令行只读预检入口，拒绝符号链接输入及超过100MB文件。
- `tests/paper-execution-preflight.test.js`：4项行为测试。
- `package.json`：新增 `npm run paper:preflight`。

## 使用方法
```bash
npm run paper:preflight -- intent-plan.json market-snapshot.json paper-account-summary.json
```

行情快照必须明确提供可信的 `complete`、`stale`、`tradable`、`suspended`、`atUpperLimit`、`atLowerLimit` 状态。缺少关键状态时不得把该记录视为可执行；当前实现对停牌、不可交易、涨跌停、陈旧和不完整状态进行拦截。现金预算按计划价重新估算，并保留佣金估算。

## 安全边界与已知限制
- 返回 `canTrade:false`、`executed:false`、`accountMutated:false`，是只读预检结果，不是真实模拟撮合。
- 佣金使用保守估算下限，不代表完整费率；正式模拟撮合还需纳入印花税、过户费、滑点及账户费率配置。
- T+1 在本轮作为卖出前置约束提示，真正执行卖出时仍需按持仓批次验证可卖数量。
- 涨跌停/停牌依赖可信行情源提供状态，不自行从价格猜测。
- 真实行情授权、完整交易日历和生产账户验收仍未完成。
