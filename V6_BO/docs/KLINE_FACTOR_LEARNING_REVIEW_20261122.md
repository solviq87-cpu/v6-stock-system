## CSV 输入表头示例（仅表头，不含假行情）

文件为 UTF-8 CSV，支持中文字段或文档内英文别名；单文件最大 6MiB，最多 90000 行；股票代码保留前导零。四种 CSV 用下述列名：

**日K（必须）**：

```csv
代码,名称,日期,周期,开盘价,最高价,最低价,收盘价,成交量,成交额,换手率,量比,涨停价,停牌,所属板块,来源,数据截至,黑天鹅,可重复标准样本,监管风险,高拥挤,利空公告,流动性风险,周期错配,筹码峰,上方套牢盘占比,筹码交换程度
```

**板块（日K同期）**：

```csv
板块,日期,收盘价,成交额,题材阶段,板块梯队,助攻数量,题材启动天数,来源,数据截至
```

**全A（日K同期）**：

```csv
日期,收盘价,成交额,全A趋势,上涨家数,下跌家数,支撑压力位,来源,数据截至
```

**分时（可选，不能用5m冒充1m）**：

```csv
代码,日期,周期,分时日期时间,开盘,最高,最低,收盘,成交量,来源
```

`数据截至` 必须是合法、带时区、上海当日收盘后且不晚于当前时间的声明，如 `YYYY-MM-DDT15:10:00+08:00`。来源或同期市场/板块缺失，以及未明确排除黑天鹅和未确认可重复的样本，都进「待复核」，**不进入研究权重**；`黑天鹅=是` 独立汇总并在导出报告的 `blackSwanSamples` 中单列。

## 研究口径与边界

- 日K算法根据**信号日及以前**的数据标注，后续 1/2/3/5 日结果单独计算。后续日期以导入全A日期序列为准，股票停牌/缺对应日期则保持未知；未使用权威交易日历独立复核。
- 历史获利、观察胜率、收益分布都以**信号当天收盘价**为观察基准，不代表次日可买到、不含T+1/成本/滑点/涨跌停不可成交的真实回测；最大回撤值仅为每个样本后续收盘序列的峰谷回撤，并非真实组合最大回撤。
- K线量价阈值用于**研究候选**。例如涨停后首板、连板、首阴、反包、弱转强、二波、半路、低吸、尾盘形态等尚未由原生战法完整评估器认证，不得显示为已通过正式校验。封单、核按钮、二波等缺少逐笔/封单证据的结果保留 `null`。
- 首次完整导入时按日期 80:20 确定训练/观察边界，并在当前会话冻结；追加、纠错和切换期限不会将原样本外日期移入训练。训练末与样本外间隔 5 个日期，仅终点在训练截止前的成熟样本用于训练。因子结果给出 Wilson 95% 胜率区间、观察盈亏比、收益分布、低尾亏损与**shadowWeight**，不改写生产权重。
- 人工修正记录只在当前浏览器会话临时保存，导出时包含每次修正动作、理由和时间，永远不能代替人工交易样本的服务端可审计日志；**不是服务器样本数据库**。
- CSV/板块/全A的来源声明和日时点由客户端校验格式与日期，**没有完成对真实供应商的独立认证**。筹码、新闻、监管标签只接受提供的源字段，不凭空合成。
