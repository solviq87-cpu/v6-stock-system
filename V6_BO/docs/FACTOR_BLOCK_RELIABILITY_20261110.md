# V6 因子自动学习第三阶段：5交易日分块一致性与单点异常保护

## 背景

既有 `factor-shadow-evolution` 会冻结当时因子、等待5交易日观察成熟、按交易日训练并经验证/新鲜保留集评估；`factor-learning-reliability` 设有有效交易日数量、整体/近期IC、每日方向和市场环境保护。该研究链仍是 **shadow-only**，不修改四套正式策略、15因子包、模拟盘资金或任何网页首页。

有两种容易漏检的“看起来在进步”情况：

1. 先前多个正向交易日把总体均值与最近半段均值撑为正，但最近一段已出现持续反转；仅检查最近半段平均IC可能漏过。
2. 一天的异常超高IC抬高总体和最近半段平均值，其他交易日并没有足够稳定的信息量。

## 本次实现

- 对按信号交易日排列的成熟日IC，以 **每5个交易日为一个完整、互不重叠的顺序块** 统计。最后不足5日的尾块不用于分块一致性认证，仍纳入常规每日统计。该分块主要是与5日持有观察窗口的相关性风险相匹配的保守代理，并不证明各分块完全统计独立。
- 与整体均值方向一致的完整块必须达到 **75%**。最近一个完整块若方向反转或归零则暂停该因子调权。拒绝码 `unstable-five-session-block-direction`、`latest-five-session-block-reversal`。
- 去掉**绝对IC最大的一天**重新计算训练均值；新的均值必须在总体方向保持至少 **0.02** 的有向IC，否则判 `single-day-influence-dominates`。这是单点影响排查，不是从数据中选择最优删除点重新拟合。
- 通过已有稳定性门禁的因子，研究调节信心再乘以分块方向一致比例与异常点剔除后/原均值的保守比例；保留原有每轮研究权重调整不超过 ±8%、相对正式权重 50%-150% 的边界。**没有足够证据时保持权重，不追求强制升级**。
- 报告新增只读字段 `fiveSessionBlockDays`、`completeBlockCount`、`blockDirectionConsistencyPct`、`latestBlockMeanIC`、`outlierRemovedMeanIC`，方便解释“为何没有进化”。既有版本号、签名、回滚及保留集规则不变。

## 真实能力界限

分块依据可验证的有序成熟交易日序列，不等同于独立验证每个窗口的实际股票相关性；每5交易日相关性可能跨块延伸，行业/市值中性、可成交收益、滑点、成本、真实来源许可、多次研究选择偏差均未在本批验证。相同样本的持续调参仍存在过拟合风险。新门禁是更保守的因子候选筛选，不能承诺赚钱或已经在云端持续跑。

不会接真实券商、行情服务或自动部署研究进程。
