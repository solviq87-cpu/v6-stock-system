## 3. 电脑整个换了 / 硬盘挂了（完整重建）

### ① 装 Node.js（≥ 18）

官网装完，命令行 `node -v` 有版本号就行。  
**这个项目零第三方依赖，不用 `npm install`。**

### ② 拿代码

网页：打开 `https://gitee.com/nine-heavens-qi/lianghuakanpandaima` → 「克隆/下载」→「下载 ZIP」  
命令行：`git clone https://gitee.com/nine-heavens-qi/lianghuakanpandaima.git`

### ③ 把数据从线上拉回来

在项目目录里执行：

```bash
python _fetch_online_data.py --replica
```

会提示输入开发者口令，然后自动拉回：持仓、飞书配置、模拟盘、命中率统计、新闻归档、全 A 学习库、推送流水、登录凭据。

- `--replica` 会把 `config.json` 改成 `pushRole=replica`  
  → **第二台机器上必须加**，不然两台都往你手机发推送。
- 已有长期令牌可以直接 `--token e4_xxx`，跳过输密码。

### ④ 跑起来

```bash
node server.js
```

浏览器开 `http://127.0.0.1:8787`，用开发者口令登录。

### ⑤ 补一件事

登录凭据里的「**找回手机号**」出于隐私不导出，恢复后请在面板「开发者锁」里重新绑定一次，  
否则「忘记密码」功能用不了。

## 4. 口令忘了

1. 打开线上地址 → 登录页点「**忘记密码**」
2. 输绑定的手机号 → 验证码推到你的飞书机器人
3. 设新口令

> 前提：面板绑定过手机号。**所以开发者口令请自己记一份在密码本/手机备忘录里**，  
> 这是唯一一个连这份文档也救不回来的东西。

## 7. 几个常见误解

- ❌「删了对话代码就没了」→ 不会，代码在 Gitee，数据在线上。
- ❌「仓库里怎么没有我的持仓和口令」→ **故意的**。仓库是去凭据的，  
  就算哪天仓库权限出问题，你的口令和持仓也不会跟着泄露。
- ❌「改个版本号而已，不用备份」→ 每次发版都会自动生成一份完整源码包  
  （`量化看盘平台_源码_<版本>.zip`），**建议定期把最新那份复制到 U 盘/私人网盘**，  
  那一份是含配置和持仓的，别放到公开地方。
