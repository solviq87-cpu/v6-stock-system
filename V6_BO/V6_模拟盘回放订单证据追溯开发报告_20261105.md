# V6 模拟盘回放订单证据追溯开发报告

日期：2026-11-05

## 本轮范围

仅修改离线模拟盘回放，不修改 UI、不接入模型服务、不启用真实交易。

## 修改内容

- 每个离线回放信号生成确定性 `signalId`，绑定信号日期、执行日期、候选集合、数据源和完整数据集 SHA-256 指纹。
- 每笔回放订单（包括被停牌/无量或一字涨跌停拦截的订单）写入 `provenance`，引用对应前一交易日收盘产生的信号。
- 订单证据明确标记 `kind=offline-replay-decision`、`canTrade=false`，不冒充原生策略信号证据，也不授权交易。
- 回放报告新增汇总 `provenance`，可核对带信号引用的订单数量及数据集指纹。
- 数据集内容或来源改变时，数据集指纹及信号 ID 随之改变。

## 重要边界

此改动为历史数据离线回放订单增加可追溯链路，不代表真实策略评估器的证据已经接入所有 HTTP 订单入口。当前 `paper-service` 仍是只读接口；本轮没有创建下单 API，也没有启用实盘交易。
