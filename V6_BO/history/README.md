# 历史内容与来源

本目录保存本次248个资料库ZIP中识别到的工程内容，按SHA-256去重保存。packages.json记录原包名称、ID、ZIP指纹和识别出的工程根目录；versions.json记录相对路径、内容指纹、大小及来源包索引；objects/<SHA256>是该版本的完整原始字节。编码异常的路径经过规范化，具体内容以哈希校验。无工程根目录的任务包原ZIP位于task-packages。

当前可运行工程在上一级v6；历史内容不参与加载、自动部署或测试发现。旧版资金写入器、过时K线适配器、发布脚本与历次报告保留在此，不自动覆盖现行修复或改成正在使用的功能。依赖缓存node_modules、Git内部文件与macOS元数据不纳入源码目录，原始ZIP继续保留在资料库。

按versions.json找到文件路径和目标哈希，从objects复制即可取回相应版本；导出到独立目录，不直接覆盖运行账户。历史报告中的通过数和收益不代表本次验证结果。
