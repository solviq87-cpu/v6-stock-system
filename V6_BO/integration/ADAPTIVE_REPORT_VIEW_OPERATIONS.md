# 自动研究最新报告查看（20261106at）

已有本地监视器与研究页面通过只读GET /api/research/adaptive-latest连接。页面的“查看自动研究最新报告”按钮只读取，不计算、不联网抓行情、不写报告/索引/主账户，不自动晋级规则。沿用开发者身份检查，匿名、只读和撤权设备不能获取报告。客户端不能指定服务器路径或来源名单。

## 配置和使用

1. 用已有 scripts/adaptive-monitor.js 对完整输入运行 --once 或自行启动监视进程，输出至指定目录。
2. 服务启动前设置 V6_ADAPTIVE_RUNS_DIR 为同一输出目录的绝对路径；未设置时页面显示尚未配置，不创建目录。不要指向用户无意共享的研究目录。
3. 可选 V6_ADAPTIVE_PROVIDERS 为逗号分隔的已配置供应商名称；只有 imported 来源且名称匹配才标“来源已配置，未经供应商认证”。模拟输入始终标模拟，其他来源或未列入的名称标未知。该名单不构成授权凭证或供应商认证。
4. 可选 V6_ADAPTIVE_MAX_AGE_DAYS，整数1～365，默认7个自然日。按上海日期减报告asOf衡量数据年龄，超过阈值标过期；不是交易日或预测有效性保证。未来或无效日期拒绝显示。
5. 在 /research.html 输入现有开发者令牌（本机直连沿用现有授权规则），点击“查看自动研究最新报告”。展示修订、数据日、过期/来源状态、四指数经验概率、学习版本及现有模拟摘要和详细JSON。过期/未知/模拟结果可以只读查看，但始终非实时、不可交易。

## 完整性和失败行为

沿用as保存协议，核验manifest及其全部引用历史，所有指纹、顺序、来源版本、大小和路径约束均检查；直接从这次核验的最后一份记录返回快照，不在核验后重读另一份内容。并发发布只能看到当次已提交索引的版本；不承诺请求结束时一定含最新提交。

损坏、缺段、丢索引、路径符号链接、超界或无效配置返回422且无报告；非GET返回405。所有响应禁止缓存。前端读取开始先清空旧结果，失败不继续展示上次有效结果；凭据/输入改变会废弃迟到响应，手动运行与保存报告共用互斥并明确切换上下文。不会修复或删除坏历史。

只读句柄不创建目录、reports或锁，runOnce被禁止。保存协议ENGINE_VERSION仍为20261106as，应用与缓存版本为20261106at，无需改写旧报告。SHA指纹仅核验内部一致性，有权限重写整套数据者仍可重新计算指纹，不是防伪签名。

## 验证与边界

12项新增核心回归包含只读字节不变、不造目录、只读禁止运行、自然日/上海时区边界、模拟/未知/配置来源、坏历史阻断最新、丢索引拒绝孤段、符号链接、未来/无效日期与配置拒绝。隔离HTTP脚本新增权限、方法、损坏和只读账户检查。真实Chromium在1536和390宽连接隔离服务验证卡片、过期/模拟提示、坏结果清空、迟到响应隔离和账户/索引未改。浏览器环境缺中文字体，截图汉字显示为方框，未验证中文字体视觉质量；DOM文字断言通过，需目标设备验收。

没有启动常驻服务或外部定时任务；没有生产数据或真实设备验收。全量和干净副本最终数字见TEST_REPORT.md。仍待：原四套逐日证据自动适配、研究参数晋级/回滚、离线归档恢复、供应商持续输入及六类外部现场验收。
