# 本轮集中修复记录

1. 初次小容量自动轮换专项9项中1项失败：活动段阈值与整个索引容量混用，索引增长后错误拒绝新记录。修复为活动事件软阈值、索引8MiB硬限制分开；同一压力用例及后续全量通过。
2. 验证命令原先只检查.audit.json，账户不存在也可能返回空审计verified。新增真实账户校验及CLI行为测试，缺账户拒绝。
3. dangling symlink不能被existsSync当作不存在而重置历史。改用lstat判断，并保留O_NOFOLLOW普通文件读取和目录类型校验。
4. 分页验证不累积全部历史事件到内存，按段校验并只收集请求页；历史总量与快照容量设置明确上限，超限拒绝而非删记录。
5. 恢复分段目录后补目录fsync，发布前验证重建后账户及审计链；缺段/篡改/非空目标/活动写锁均拒绝，不覆盖原账户。

13项新增行为测试包含在746项总数中。SIGKILL测试不是物理断电证明；本次未部署到真实云电脑。
