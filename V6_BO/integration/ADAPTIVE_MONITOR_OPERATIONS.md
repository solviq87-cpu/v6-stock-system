# 本地自适应研究自动运行与恢复（20261106as）

## 范围

本地JSON输入变化后自动运行四指数/回避/学习研究，保留不可覆盖的报告和可核验索引；不抓取外部行情、不配置系统定时任务、不监听网络、不写主权威账户或发订单、不自动晋级生产规则。启动监视进程只作用于指定本地路径，没有云端部署。

```bash
node scripts/adaptive-monitor.js /safe/adaptive-input.json /safe/adaptive-runs --once
node scripts/adaptive-monitor.js /safe/adaptive-input.json /safe/adaptive-runs --verify
node scripts/adaptive-monitor.js /safe/adaptive-input.json /safe/adaptive-runs --poll-ms 60000
```

`--once`运行一次；`--verify`只核验索引及全部已引用报告，二者不可同时使用。不带这两个参数则监视输入，默认60秒，支持1秒至24小时；SIGINT/SIGTERM停止下一轮，并等待已经开始的一轮在worker时限内结束。不会替用户后台常驻启动或安装系统服务。

## 输入和幂等

输入仍为ADAPTIVE_MARKET_OPERATIONS.md的完整JSON、最多8MiB。数据生产者应先写临时文件再原子替换输入，避免半文件被观察到。观察到计算期间输入字节变化时不发布这一轮；此后发生的新变化由下一次轮询识别。无效输入或研究失败不会覆盖最后一个有效模型。

输入JSON内容相同（忽略空白，暂不忽略对象键顺序）不重复计算/写入。相同provider+version+asOf不能对应不同内容；改旧数据须显式新version。日期倒退或重回旧模型版本被拒绝，不能用旧输入替换当前版本。新报告可自动更新成熟标签研究权重，不表示其收益已认证。

## 保存、锁与恢复

输出目录仅有monitor.guard、manifest.json及reports/<输入SHA256>.json和未引用临时文件。文件SHA指纹和结果datasetFingerprint同时绑定输入，索引引用报告指纹；SHA校验不是供应商签名，不能抵抗有权限者重写整套历史。

所有报告发布、索引切换共用Linux flock，文件描述符跨整个异步worker计算保持，异常退出自动释放，不删除未知旧锁来强抢。先fsync报告并以硬链接不可覆盖发布，再原子替换索引。中断在报告发布后、索引前时重试复用确切报告；索引发布后重试不增加版本。已执行真实子进程SIGKILL与内核锁恢复测试。

索引存在时核验所有已引用报告；坏指纹、缺段、错版本均阻断，不能删坏文件放行。索引缺失时，仅在目录有唯一且与当前输入完全匹配的有效孤报告时恢复；多报告目录缺索引拒绝重置。未引用孤段和临时目录不自动删除，需离线核验处理。

输入、输出和引用路径拒绝符号链接。单报告最多16MiB、最多1000条索引记录、已引用历史在线核验最多128MiB；达到上限停止新增，需要在保留完整目录备份后离线规划归档/新目录。不是无限留存，也未做长期大规模性能验收。目录保存协议版本为ENGINE_VERSION=20261106as，未来更改学习/报告协议应评估迁移或使用新输出目录，不单独篡改旧索引版本。

## 备份与剩余边界

停止监视进程后，连同manifest.json、reports目录、原始输入及来源版本记录完整备份，再在新目录运行--verify。不是主账户与审计的一致备份替代，也没有自动跨机同步/全站恢复；后者仍使用既有运维工具并待跨机验收。

本轮本机定向覆盖幂等、追加学习、版本/日期回退、输入变更、报告/索引中断恢复、SIGKILL、并发、损坏/缺文件、符号链接、CLI once/verify及实际watch轮询停止。不是断电、磁盘故障、远程文件系统或真实云端长期运行证明。真实供应商自动输入生产、监视报告的页面读取/通知和研究版本的生产晋级/回滚仍待后续开发。
