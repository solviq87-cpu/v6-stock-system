# V6 模拟盘三方账务只读对账 — 本轮报告

日期：2026-11-05

## 本轮改动

- 新增 `src/core/paper-account-reconciliation.js`：独立只读对账器。
- 新增 `tests/paper-account-reconciliation.test.js`：7 项自动化测试。
- 从逐笔成交按时间顺序重算现金流、已实现盈亏和 FIFO 持仓批次成本。
- 与账户快照逐项比较现金、已实现盈亏、持仓股数和成本基准。
- 缺少手续费、交易方向损坏、卖出超过可追溯买入数量、非法数值均 fail-closed。
- 对账只生成报告，不修改账户、成交或持仓。

## 范围与限制

本轮新增的是可复用的独立只读对账模块，尚未接入生产模拟盘启动流程或 HTTP 管理接口。现有线上账户结构、历史成本口径和旧流水缺字段需要先做适配与影子运行，不能直接用本模块自动修账。当前模块只适用于包含完整手续费字段、可按 FIFO 成本追溯的流水集合。
