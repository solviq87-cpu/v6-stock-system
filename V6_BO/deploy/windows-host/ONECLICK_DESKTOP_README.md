# 天枢智策 V6｜Windows 一键安装与中文服务器管理

> 2026-11-16 首批交付：这是对既有 Windows/WSL 本地后台的**管理入口**，不是凭此就完成原账户迁移、新版 FAYO UI 部署、手机 HTTPS 或实盘上线。

## 你只需要点击

1. 从 GitHub Actions 的 **V6 Windows One-Click Desktop** 工作流下载 `TianShuV6-Windows-OneClick` 构建产物，并解压 ZIP。请只使用本仓库构建且已通过 Windows 校验的产物。
2. 进入 `tian-shu-windows-host` 文件夹，**双击 `TianShu-Install.cmd`**。它先验证整包 `SHA256SUMS.txt`、来源 SHA 及文件清单，不通过就停止。
3. 安装成功后桌面出现 **天枢智策 V6（本机服务器）**。以后点击这个图标即可查看状态、启动、停止或打开本机页面，不用再键入命令。
4. 如需 Windows 登录后自动启动，在中文管理窗口里手动勾选该项并确认。仅创建当前用户的登录启动快捷方式，不需要管理员权限，不会在用户未登录时作为系统服务运行。

## 已有 V6 安装会怎么样？

- 原安装位于 WSL 用户主目录（默认 `~/.tian-shu-local`）；安装器只复制签出并校验的**应用运行包和控制器**到 Windows 当前用户的 `%LOCALAPPDATA%\TianShuV6\current`，不会覆盖 WSL 的原账户、订单、持仓、策略、密码、私有运行状态或备份。
- 既有安全启动器 `windows-host.ps1` 继续负责服务身份、代码/清单哈希、replica 模式、端口和账户保护。状态检查失败时拒绝贸然启动。
- 新窗口的**检查更新**是只读的，**绝不自动应用更新**。账户迁移、正式升级和异常回滚仍须经过现有备份与安全门禁。
- 再次安装新入口时，旧的 Windows 控制器包保存在 `%LOCALAPPDATA%\TianShuV6\previous-*` 中。它不是原账户备份；正式账本备份仍须单独核验。
- 全新 WSL 安装仍需系统具备 Ubuntu 24.04 / Node 22.6+ / Python3 / curl / flock，并在可信运行包中**明确选择**初始化新账户。本工具**不会自动初始化空账户**，以免出现双账本。
- 本机运行不要求 VPN 持续在线，但 GitHub 的后续更新检查及数据提供方可能需要正常网络；服务运行期间电脑须开机、联网且 Windows 用户已登录。

## 和手机 App、WorkBuddy 的关系

该入口已把电脑端服务管理变成点按式操作，但**手机远程连接需要单独完成 Tailscale 私网 HTTPS + 设备认证**；不会自动启用 Funnel 或公开 8787 端口。当前 WorkBuddy 站点是独立的静态托管页，不能将其当成已经接通同一套本地账本的证据。

现有 Windows/WSL 安全操作见 `README.zh-CN.md`、仓库根目录 `ZERO_COST_HOST_DEPLOYMENT.md` 和 `SAFE_AUTO_UPDATE_OPERATIONS.md`。
