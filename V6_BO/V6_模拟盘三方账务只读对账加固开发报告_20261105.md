# V6 模拟盘三方账务只读对账加固开发报告

日期：2026-11-05

## 本轮目标

在上一轮独立只读对账器基础上，收紧流水排序、唯一性和账户快照完整性校验；不修改账户、成交或持仓数据，不自动修账。

## 实际修改

- 每笔成交必须提供合法的非负安全整数时间戳；缺失或非法时间戳直接判定不完整，不再静默按时间 0 排序。
- 对存在的 `tradeId`、`trade_id` 或 `id` 做唯一性检查，重复流水 ID fail-closed。
- 要求账户快照显式提供 `positions` 对象，避免缺少持仓快照被当成空持仓。
- 持仓股数必须为非负安全整数，成本基准必须为有限非负数；拒绝小数股数、负数和畸形持仓对象。
- 重放买入后现金若低于容差范围，报告负现金异常。
- 对账仍为只读；任何异常只输出差异和错误，不自动修复账务。

## 范围限制

- 本模块仍是独立只读对账器，尚未接入生产模拟盘启动流程或 HTTP 管理接口。
- 只适用于手续费字段完整、成交流水可按 FIFO 追溯的账户数据；旧流水缺字段时应标记不完整，不能猜测费用或自动修账。
- 尚未完成真实历史账户影子对账与业务口径确认。
