# §9 · d) 非 kline 类「采纳」外部数据源盘点

- 背景：gr/gs 台账约一半「采纳」条件依赖外部数据（北向/两融/期权/期指/财报/宏观/舆情/龙虎榜/筹码分布），本地 `.kline_cache` 算不出。
- 纪律（项目既有）：算不出一律标「缺数据」≠「不符合」；上游不可达诚实降级、不造假；付费源按用户「付费不要」跳过。
- 时间：2026-10-15

## 一、外部数据源现状（按接入状态分三类）

### ✅ 已接入（免费可达，已在用）
| 类别 | 来源 | 用途 |
|---|---|---|
| 北向/南向资金 | `external_data.js` hk2sh/hk2sz/sh2hk | 北向类因子 |
| 商品（金油银） | `external_data.js` | 外围/避险 |
| 财报 | `external_data.js` RPT_LICO_FN_CPD | 基本面类 |
| 外围指数 | `em.fetchGlobal` | 外围市场卡 |
| 板块主力净流入 | `em.fetchSectorFlow` | 板块异动/强度 |
| 龙虎榜 | `lhbMapCached`（东财，18:00 后回退 T-1，缓存 30min） | 席位/资金 |
| 新闻利好/利空 | `news.json` → `S.news.goodCodes/badCodes` | 利好催化 +10、利空过滤 |
| 涨停题材/原因 | `ztReasonCached`（同花顺，9/30 实测 52/52 覆盖） | 每只涨停票说清「因为什么涨」 |

→ **多数外部因子其实已接**。d) 的「需外部源」大头已在跑，不是空白。

### ⚠️ 诚实降级（上游不可达，标记 error，不假实现）
| 类别 | 现状 |
|---|---|
| 两融（融资融券） | 东财 datacenter reportName「报表配置不存在」 |
| 解禁 / 增减持 | 同上 |
| 机构调研 | 同上 |
| 舆情 | gtimg 汇率 none_match / 舆情源不可达 |
| 汇率 | gtimg none_match |

→ 这些是**真·挂起**的外部因子：接口变动/失效，非逻辑问题。**需换一个可达的免费端点**才能启用。

### ⛔ 付费不要（用户明确跳过）
| 类别 | 说明 |
|---|---|
| 期权 / 期指 | 付费/注册源 |
| 筹码 L2 / 盘口逐笔 | 付费 |
| 另类 U/V 组 | 付费 |

→ 除非用户改「付费不要」口径，否则不进。

## 二、待用户决策（d) 的核心）

降级类（两融/解禁/增减持/机构调研/舆情/汇率）要启用，只有两条路：
- **A. 换免费端点**：调研同花顺/腾讯/新浪等可达替代源（免费、需验证覆盖与限流）。工作量中等，无成本。
- **B. 接付费源/Connector**：如 tdx-connector（通达信 MCP，可能含两融/龙虎榜明细）、westock 等。违背用户「付费不要」口径的需先确认。

## 三、结论与建议

- **现状健康**：免费可达的外部源已全部接入并在用；不可达的诚实挂起，没有假装判过——符合项目一贯纪律。
- **建议（默认）**：走 **A（换免费端点）**优先，从「舆情/两融」这两个对涨停预测最相关的入手；启用前先小样本验证覆盖与稳定性，再决定是否进模型。
- ⛔ 不加无 edge / 无数据的外部因子（与 b/c 同源：提高准确率 ≠ 堆因子）。

> 待用户在下方决策表勾选：① 是否投入换免费端点（先做哪些：舆情/两融/解禁/增减持/机构调研/汇率）② 是否破例允许某个付费 Connector ③ 其余维持挂起。
