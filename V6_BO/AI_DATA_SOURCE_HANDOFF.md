# 国内行情接口接入交接说明（V6）

当前版本默认沿用项目现有数据源适配层，不把模拟数据伪装成真实行情。后续接入者应先阅读 `em.js`、`external_data.js` 与 `server.js` 中对应调用点，再实现适配器。

## 接入边界
- 保持业务层调用接口稳定；数据源切换只发生在 adapter 层。
- 每条数据必须携带 `source`/`src`、`fetchedAt`、`tradeDate` 和 `isMock`（或等价元数据）。
- 模拟数据必须明确标记 `isMock: true`，界面与日志不得显示为实时行情。
- 真实接口失败时允许按配置降级；不得用模拟值覆盖真实数据缓存，也不得把旧缓存标成实时。
- 请求设置超时、重试上限、指数退避和熔断；错误要保留 HTTP 状态、供应商错误码及接口名。

## 推荐标准化结构

```js
{
  ok: true,
  source: 'provider-name',
  isMock: false,
  fetchedAt: Date.now(),
  tradeDate: 'YYYYMMDD',
  data: []
}
```

## 后续接入检查
1. 明确供应商授权、频率限制、复权口径、成交量单位（股/手）及交易日字段。
2. 为快照、K线、涨停池、板块资金流分别实现 adapter，不要把不同口径混成一个接口。
3. 用固定 fixture 做字段/单位/边界测试，再用真实接口做连通性测试。
4. 验证超时、空响应、限流、字段缺失、日期错位、重复数据和熔断恢复。
5. 在运行状态页展示数据源、更新时间、交易日和 mock/real 标记。

## 当前验证边界
本次 V6 本地测试不要求连接真实国内行情供应商。真实接口连通性、授权和稳定性留待接入环境验证；未验证前不得宣称真实行情已接通。
