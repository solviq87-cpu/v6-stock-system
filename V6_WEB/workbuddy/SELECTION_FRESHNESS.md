# 当前候选与历史快照分界（2026-11-13）

基线：`8b3664686676faf6f52b2888e39e3bf7b51dab36`。本次修复静态页面的选股消费与缓存失效，不宣称已部署完整后端或已经取得线上当前选股清单。

## 已复现的问题

参考源码的 `_online_state.json` 是 2026-10-13 的归档，不能证明当前目标站仍使用该归档，也不能当作当天股票推荐。本次独立代码检查发现：四策略和43战法的公共过滤没有充分检查报价年龄；同一源版本的筛选、市场广度和页面结果缓存会随时间继续有效。四策略还可能消费 V6Core 补入的整批时间，持仓退出提示存在绕过一般过滤的路径。

## 修复行为

- 使用逐股 `providerTime` 和逐股 `receivedAt/fetchedAt`，不借用整批时间。日期未知、时间逆序、未来时间、来源标记旧报价时待更新。
- 盘中仅允许当日、年龄不超过120秒的研究报价；精确边界120秒允许，超过1毫秒即过期。这是研究候选门槛，原模拟成交15秒门槛不变，`canTrade=false` 不变。
- 午休与竞价间隙只保留同日120秒内的观察；盘外候选计算要求有限交易日历内最近已结束交易日、源时间不早于15:00的报价。结果携带 `quoteObservation.current=false` 和数据日期，不能算新盘中信号。没有收盘报价时，旧报价仍可查阅，但不进入当前候选。
- 四策略、43战法、持仓退出规则、指数/市场广度和因子分位排除过期行。时钟变化失效策略、评分、市况及页面缓存；异步扫描完成前再次检查，跨过时效边界的结果整批作废。
- 前台每5秒仅重判显示有效性，不请求行情、不发送消息、不启动战法任务。网络失败或手动暂停时，旧卡片也会失效；编辑输入框时沿用既有延迟渲染保护。后台浏览器可能暂停计时，恢复前台时由既有生命周期重新检查。
- 开盘采集、手机/电脑独立恢复、休市停扫、源预算、403/429退避及共享账户协议不变。没有加入第二发布者、常驻服务或客户端Webhook。
