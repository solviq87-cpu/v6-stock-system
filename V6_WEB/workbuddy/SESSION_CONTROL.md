# 交易时段自动扫描｜2026-11-13

用户要求休市停止扫描、只在开盘时间自动扫描。本变更接续限频候选 `32d5fd4`，保留后续 dev 的表格横向滑动保护；未执行线上发布。

## 排程与用户意图

首次通过原带分享参数的页面打开，应用 `startMarket` 默认启用交易时段自动意图。原始市场模块加载不会自行发请求；没有分享参数的应用启动不启用采集。`collectionRequested` 表示已启用的意图，`collectionEnabled` 表示当前确实允许扫描，二者分开。

北京时间半开区间：竞价 **09:15≤时间<09:25**；上午 **09:30≤时间<11:30**；下午 **13:00≤时间<15:00**。09:25–09:30、午休、15:00起、周末与日历列出的法定休市日暂停报价、日线补取和自动战法计算；仅显示原缓存和原数据时点。15:00以后显式刷新也不能绕过门禁。竞价结束到连续交易开盘的间隙停止扫描。

已启用且页面保持前台时，休市保留意图并预约下一开盘，自动恢复受预算约束的采集。手动暂停保存独立偏好 `v6:scan-auto-preference:v1`，跨时段和重新打开仍暂停，直至显式继续。页面隐藏或断网立即停止；回到前台、恢复联网或 pageshow 时读取原自动偏好并恢复。手动暂停仍保持，隐藏和断网不冒充用户永久取消偏好。持久偏好损坏或存储不可用会拒绝启用。

## 日历与剩余边界

排程从现有 `V6_BO/config/research-calendar-2026.json` 的365天显式开闭表派生，源码记录原文件SHA256；测试逐天核对表一致性。该资料保留 `verifiedExternal=false` 和 `tradeEligible=false`，仅用于保守减少扫描，不能授予供应商许可、认证交易所实时状态或真实成交资格。上游日历未认证的范围继续未知，不以本修改冒充完成外部验收。

只有2026年被覆盖；范围外或时钟无效时停止扫描并显示日历待更新，不靠“工作日默认开市”放行未来日期。`previousTradingDate` 与 `latestClosedDate` 只提供该有限排程下的日期标签，不证明当日日线已结算、数据完整或复权正确。日线原有15:30闭合数据门槛保留，缓存目标及下次补取窗口同样跳过显式休市日；例如国庆后10月8日开盘目标为9月30日，而非10月7日。成功/无进展缓存至下一真实开盘窗口；日历末端只有保守24小时冷却，独立时段门禁仍保持未知年份停扫，不据冷却推断未来开市。

## 采集与计算边界

时间门禁在排队前、取得跨标签锁后、等待预算后与响应读取后检查；收盘会取消活动请求和排队任务，旧任务在下次开盘也不会复活。1.05秒同供应商家族间隔、单在途、403/429与Retry-After冷却、每日预算和逐股历史退避不变。用户已经启用意图时，休市显式请求非报价/非K线的研究、公告或财报仍走共享预算；默认未初始化、手动暂停或隐藏则全部拒绝公开采集。

自动战法循环遵守相同开盘门禁；`scanAsync` 每批检查取消信号，跨收盘结果丢弃，不发布为新的研究快照。手动模拟订单与研究快照的最后写入前还会即时检查时段，防止定时器延迟执行时越过15:00。原四策略、43战法规则、账户账本序列化和成交提交协议未改变。

接口：`V6Market.sessionAt(at)` 返回 `date/kind/open/label/timeZone/nextChangeAt/nextOpenAt/calendarSupported/previousTradingDate/latestClosedDate`；`status.marketSession` 是当前投影。`initializeAutoCollection()`用于应用首次启动；`subscribeSession(fn)`在有效开关边界即时通知，便于取消CPU任务。

离线验证：新增 `workbuddy-market-session.test.js` 34项；采集32项及模拟成交14项共同80/80通过。旧采集测试将虚拟时钟放入交易时段，并把盘外补历史的旧预期改为下一开盘；没有放宽生产门禁。实际远端CI、整合版全量及浏览器验收由主分支另行记录，不以这份专项说明代替。
