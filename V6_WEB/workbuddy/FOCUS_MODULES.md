# 四个独立观察模块（2026-11-13）

`V6FocusModules.compute(state, snapshot, options)` 与 `render(...)` 只读现有公开快照和已取得的证据。
没有 HTTP、定时器、队列、账户写入、通知或新增自动交易；原四策略和43战法的函数、阈值和参数不变。
它们是独立观察视图，不是四套已认证的新交易策略。

## 输入与日期

- 优先读取原始 `snapshot.stocks`，不经会丢失专门字段的核心股票归一化。
- 专门证据来自 `snapshot.strategyData.bySymbol[symbol]`，或已存在的 `V6StrategyData.snapshot`。
- 闭合日K来自 `snapshot.strategyBars[symbol]` 或只读 `V6Market.getStrategyBars(symbol)`。
- 排程来自 `V6Market.sessionAt()`；测试可显式注入 `now`、`marketSession`、`sessionAt`、`tradingDates`、
  `getBars`、`strategyData`、`checkStock`。`options.battleResult` 可提供原b41的完整扫描证据。
- 先复用 `V6Battle.checkStock` 的通用筛选与主推偏好，未就绪时保持待核。ST、退市、停牌、无涨跌幅限制
  或不可交易状态不进入观察。有效普通报价或专门竞价报价不等于供应商已获授权。
- `sourceTime` 保留原时点；只有日频日期时显示“仅交易日”。评估时刻与收到时刻均不代替原时点。
  当前时段标记还要求已知开放交易日、对应时段及原报价15秒内；竞价专门证据为60秒内。
  午休、收盘、周末及未知日历只能展示标明日期的缓存历史观察，不能冒充当前信号。

## 竞价强势票

只消费逐票 `strategyData.bySymbol[symbol].auction`，含独立 `source`、`tradeDate`、`previousClose`
及 `snapshots`。每个tick要有同一 `source`、`symbol`（或`code`）、原始 `quoteAt`、`receivedAt`、
`indicativePrice`、非负整数 `indicativeMatchedVolume`。时点限09:15–09:25:59，收到不早于原始时点、
滞后不超过60秒，不能引用评估之后的记录；重复时点、来源/证券不一致保持待核。

复用既有BO竞价研究条件：

1. 09:20–09:25至少两次独立快照且间隔至少60秒，虚拟量单调不降、后/前≥1.1，虚拟价全段回落不超过1%，
   前收涨幅0.5%–6%。明确它是虚拟匹配量，不是实际成交量。
2. 09:25之后有原始 `executed:true` 和 `executedAmount`≥300万，且不低于独立 `dailyAverageAmount20` 的3%，
   高开0.5%–3%。普通盘中累计金额不代替实际竞价成交额。
3. 原始9:25实际撮合、`previousFirstBoardVerified:true`、板块 `sectorRank`前5、高开1%–6%、实际额≥500万。

明显的早盘虚拟高报随后回落、接近已知涨幅上限等风险覆盖看涨观察。只输出只读研究观察；没有完整竞价字段
时显示资料待核，不从普通开盘价、日K或普通报价造竞价证据。

## 一进二 / 二进三

消费 `limitHistory:{source,rows:[{date,isLimitUp,...}]}` 真实日标志。需要未复权、无已知缺口、合法OHLCV，
以及明确的 `completedRowCount`、`completedThroughDate`，当前未闭合K不计。最近三个闭合交易日须与
排程日历连续（存在排程API时优先，证据内日期表不能覆盖矛盾），无排程API时才使用显式日期表；且各日涨停标志齐全。最近闭合日未知、重复/未来/制度特例保持待核。提供 `knownAt` 时必须合法且
不晚于本次评估。明确的历史ST、无涨跌幅限制、新股豁免、公司行为特例不作为普通接力记录。

尾部连续1日涨停与2日涨停分别进入一进二和二进三，更高连续板不混入。原始资料日期旧于排程的最近闭合日，或
当前报价过期，仍只能显示“历史 / 过期观察”。不从涨幅>9.9%、日K条数、今天股票名称或今天板块倒填历史制度。
这些来源自报的涨停记录未经过交易所独立认证，历史分层也不证明未来能晋级。

当前公开日K缓存没有全部历史制度/专门日标志，因此缺这些资料的股票会保持待核；不为填满模块放宽数据要求。

## 盘中强势票

两种既有规则分别披露，保持原阈值：

- 原b41：真实标准化盘中量比>3、有独立来源，原时点09:30–10:00；必须与当前原始报价行时点一致。
  可复用同证券、同原时点的原b41扫描证据，不让新报价刷新旧信号。
- 原量价动量：20交易日涨幅≥6%、日K量比≥1.2，且历史无缺口、日K依据与报价交易日一致。
  标明“日K量比，非标准盘中量比”，不能充作竞价量比。

这些结果是观察，未收盘时不升级为原43规则的确认候选或买入共振。

## 页面联动与验收

四个section有稳定 `data-module-id`，供统一折叠控件使用；股票使用原 `data-focus` 联动。
“查看原战法与证据”链接到 `#scanner`，附 `data-focus-module-group="opening"` 供主应用设置对应组。
CSS单独作用在 `.v6-focus-*`，不包裹或改动原表格 / `V6TableScroll` 的节点结构。

`V6_BO/tests/workbuddy-focus-modules.test.js` 直接执行实际inline模块，全部使用内存合成证据，无供应商、线上账户或发布调用。
专项通过不代表真实竞价字段已接通、实机验收、策略收益或生产部署完成。主集成还需运行完整回归和浏览器检查。

性能边界：复用一次批量分类及既有checkStock分类参数，按生产者版本/偏好缓存通用筛选元数据；原始时点、15秒新鲜度、当前时段每次重新检查，不缓存新鲜度结果。数字格式器复用，避免每行重复创建Intl格式器。本机5000行合成测量仅表明本实现开销，不代表手机或生产性能认证。
