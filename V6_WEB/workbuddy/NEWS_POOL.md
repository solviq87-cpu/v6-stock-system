# 页面新闻池与消息面规避

基线 `8b3664686676faf6f52b2888e39e3bf7b51dab36`。此前 BO 有新闻功能，但独立 WorkBuddy
HTML 没有全局快讯新闻池，也没有把消息面加入页面主推过滤。本文件描述新增独立模块的
数据契约，主推入口、共享 records 和生命周期接线由整合分支完成。没有因此部署 BO 后端。

## 来源、时点与预算

沿用 BO 已使用的东方财富7×24端点 `np-weblist.eastmoney.com/comm/web/getFastNewsList`，
栏目101和104各取最新一页，每页最多100条。所有请求只走 `V6Market.publicFetch`，继续受
供应商家族锁、单路请求、启动间隔、403/429和Retry-After限制；没有独立 fetch 旁路。
本模块不设循环定时器，应用协调器负责前台调度。单次刷新共享一个任务，任何 force 参数
均不能绕过五分钟间隔；只有前台且用户已开启采集意图时取新闻。休市可更新新闻，不取盘面。

每个响应最多2MiB，单栏目最多100条，每条stockList最多100个；格式或覆盖异常保持待核。
列表保留近72小时最多500条，不补历史分页，不声称完整覆盖所有新闻。源正常空页不等于
既有新闻撤稿；最新失败保留旧资料，但不沿用旧的“已检查”许可。

`showTime` 按严格上海本地时间解析，保留原字符串、规范原发布时间和实际本页接收时点。
非法日期、缺日期或未来原时点显示待核，不借接收或读取缓存的时间伪装原发布时间。
发布时间未知/未来的条目只用**原接收时间计算保留期限**，没有把它认证为发布时间。

## 分类和关联

利空优先，复用 BO 原词表及“出售已回购股份”等语义组合。利好不能抵消同股利空。
仅公开摘要和规则关键词倾向，未使用外部模型，也不是新闻真实性、因果影响或投资效果认证。
超出有界摘要处理范围保持待核，不截掉尾部后授予正面结论。

直接证券关联只读源 `stockList`，核对其交易所前缀与A股代码制度：沪60/68、深00/30、
北43/83/87/92；例如 `1.000001` 不会误当成深圳000001。没有代码时不猜公司简称。

行业关联必须已有带来源及真实更新时间的股票行业分类，并在新闻中明确出现完整行业名
及“板块/行业/产业/全行业”等表述；公司名中带“银行”不扩散成全银行，
“电力设备行业”不吞为“电力行业”。间接关联明确显示待人工核实，不是确认整个行业受损。
已批量取得的 `classification.industry` 可传给 `riskFor`，不在每只股票上重新遍历全市场。

## 更新、撤稿与缓存

相同源事件ID更新现有版本，不能同时保留旧利好与新利空；原发布时间更旧的栏目副本不覆盖
较新的报道。同一轮两个栏目给出同原时点但内容冲突的版本保持待核。
只有源明确给出的 `retracted:true`、`isDeleted:true` 或 `status=retracted/withdrawn`
才算撤稿声明。撤稿原时点仍须有效；未知/未来撤稿不能清掉旧利空或授予已检查状态。

hydrate接收未认证共享/本地缓存，严格校验字段、大小和原时点，重算分类与本地指纹。
不修改原 fetchedAt/receivedAt，不允许旧包倒退版本。缓存不能单独授予 checked；
其有效负面可保守阻断，但不能清除已有负面，须本页直接源出现有效修订才能解除。
下一轮成功空feed也不会把缓存伪造的“撤稿/利好”变成清空旧利空的许可。

`versionHash` 是本地变化指纹，不是加密签名、源认证或外部存证。网页共享 records 的访问控制
不等于新闻来源签名。浏览器本地存储失败不伪造持久成功，显示数据仍保留原边界。

## API 与主推接线约束

`V6NewsPool` 提供 `refresh({signal})`、`serialize()`、`hydrate(payload)`、
`riskFor(stock,{now,classification})`、`cacheKey(now)`、`render(state,snapshot,{filter,now})`、
`subscribe(fn)` 和只读 `snapshot` 投影。序列化载荷固定为schemaVersion1、
kind=`workbuddy-news-pool`、source=`eastmoney-fast-news`、policyVersion=`news-keywords-v1`；
包含两栏目状态、原完整取数/尝试时间、最多500条标准化事件及最后错误。

`riskFor` 返回 `blocked/checked/unknown`、理由、关联条目、版本键和范围。
blocked为本有限池内有效利空的直接/间接关联；checked仅表示本页两栏目十分钟内成功检查、
股票行业资料已核对且当前有限池未命中利空，绝不表示无风险或完整覆盖；其余unknown。
完整原始发布时间超72h的影响退出本池，未知时间条目在原接收后72h退出。

主推必须排除 blocked，unknown保留待核，利好不绕过原有价格、策略、流动性或偏好门禁。
Policy及页面上层缓存都须纳入 `cacheKey(now)`，此键同时反映源失败、十分钟鲜度、
72小时条目窗口和本页复核状态，不能只在下次网络更新时才使旧checked失效。

渲染为独立 `section[data-module-id=news-pool]`，复用全页折叠。筛选按钮使用
`data-news-filter=all/bad/good/neutral/unknown/retracted`，刷新为 `data-news-refresh`，
股票代码保留 `data-focus`。直接关联显示已有名称及代码；明确行业关联从已载入真实分类中一次建索引，最多列12只及总数并排除直接重复。默认显示最近20条、摘要预览180字，完整已取有界摘要放details；分类仍使用完整已取摘要。链接只允许无凭据的东方财富HTTPS地址；无原文URL时明确标来源接口。
源码不读真实账户、不发送飞书、邮件或通知。页面主推过滤与真正后端外发必须分别接线和验收。

## 验证

新增测试从实际 inline marker 提取模块，以虚拟时钟、内存Response和合成分类运行；
没有真实供应商、线上页面或账户调用。覆盖源失败/时点/修订撤稿/行业误关联/缓存绕过/
预算/暂停/有界大小/XSS等边界。最终实际用例数及完整集成、浏览器和CI结果以整合交接为准。
回退可撤销本新增模块、CSS与其接线，不恢复旧共享账户或改动两张BO锁定主页。
